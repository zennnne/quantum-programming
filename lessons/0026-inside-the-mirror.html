Quantum Programming · Lec 06 · บทที่ 0026 (บทปิดคาบ)

ข้างใน mirror — สะท้อนทุกค่ารอบ “ค่าเฉลี่ย”

สามบทที่ผ่านมา (0023–0025) เราใช้ mirror เป็นกล่องดำมาตลอด แล้วจดตัวเลขประหลาดไว้เต็มไปหมด: 6.25% → 47.3% → 90.8% · m = N/4 ได้ 100% · m = N/2 ไม่ขยับเลย · บทนี้เปิดกล่องดูด้วยภาพเรขาคณิตง่ายๆ ภาพเดียว แล้วทุกตัวเลขนั้นจะคำนวณได้ด้วยมือ

ทำไมต้องเรียนบทนี้ — จับหลัก 4 อย่าง: ① mirror = สะท้อนทุกค่าผ่านจุดค่าเฉลี่ย · ค่าใหม่ = 2 × avg − ค่าเดิม ② ค่าเฉลี่ยไม่ขยับ → mirror สองครั้ง = กลับที่เดิม ③ ค่าที่เฟสแปลกแยก (oddball) อยู่ไกลค่าเฉลี่ย → โดนเหวี่ยง (slingshot) ออกไปไกล = magnitude โต ④ วงจรจริงทำ สะท้อน + พลิกเฟสทุกวง ซึ่งวัดผลได้เหมือนกันเป๊ะ

ส่วนที่ 1 · กฎของ mirror: หาค่าเฉลี่ย แล้วสะท้อน

ก่อนอื่น: จุดในวงกลม = ตัวเลข 2 มิติ [x, y]

สไลด์ (p35) บอกว่าจะไม่ไล่ทีละ gate แต่จะมอง “ผลรวม” ของ mirror บน circle notation แทน · เคล็ดคือ ให้มองแต่ละวงเป็นระนาบ x–y แล้วค่า amplitude ของวงนั้นคือจุด 1 จุด: ห่างจากศูนย์กลางเท่ากับ magnitude ไปในทิศของเข็ม (phase)

refresher: แปลง magnitude + phase → [x, y] (convention ของเรา: 0° = ชี้ขึ้น, บวก = ทวนเข็ม)
x = −mag · sin θ   ·   y = mag · cos θ
ตัวอย่าง mag 0.707 เฟส 120°: sin 120° = 0.866, cos 120° = −0.5 → [−0.612, −0.354] (ชี้ซ้ายล่าง) · วงว่าง = [0, 0] · (ใครเคยเรียนจำนวนเชิงซ้อน: จุดนี้ก็คือจำนวนเชิงซ้อนบนระนาบนั่นเอง แค่หมุนแกนให้ 0° ชี้ขึ้น)

ตัวอย่างจากสไลด์ (Figure 6-20): state 2 qubit

|ψ⟩ = 0.707|0⟩ + 0.707·ei·120°|3⟩

ขั้นที่ ① หาค่าเฉลี่ย — เฉลี่ย x กับ y แยกกัน (นับวงว่างด้วย!)

x (0 + 0 + 0 + (−0.612)) ÷ 4 = −0.153
y (0.707 + 0 + 0 + (−0.354)) ÷ 4 = 0.088
→ average = [−0.153, 0.088] · หารด้วย 4 ไม่ใช่ 2 เพราะวงว่าง |1⟩ |2⟩ ก็นับเป็น [0, 0] (p37–38)

ขั้นที่ ② สะท้อนทุกจุดผ่านค่าเฉลี่ย

สะท้อนผ่านจุด ●เดินจากจุดเดิมไปถึง ● แล้วเดินต่อไปอีกเท่าเดิมในทิศเดิม → ● อยู่กึ่งกลางระหว่างค่าเดิมกับค่าใหม่พอดี
=
ค่าใหม่ = 2 × avg − ค่าเดิมทำแยกทีละแกน x และ y · avg อยู่ตรงกลาง จึง avg − เดิม = ใหม่ − avg
|0⟩ 2×[−0.153, 0.088] − [0, 0.707] = [−0.306, −0.530] → mag 0.612 เฟส 150°
|1⟩ 2×[−0.153, 0.088] − [0, 0] = [−0.306, 0.177] → mag 0.353 เฟส 60°
|2⟩ เหมือน |1⟩ ทุกอย่าง = [−0.306, 0.177]
|3⟩ 2×[−0.153, 0.088] − [−0.612, −0.354] = [0.306, 0.530] → mag 0.612 เฟส 330°
Figure 6-24 — วงว่าง |1⟩ |2⟩ โผล่ขึ้นมา · |0⟩ |3⟩ หดลง · ความต่างของเฟสกลายเป็นความต่างของ magnitude แล้ว (รวมยัง = 100%)
⚠️ ระวังคำซ้ำ — ชื่อรูป Figure 6-23 ในสไลด์คือ “Flipping about the average” คำว่า flip ตรงนี้แปลว่าสะท้อน ซึ่งเป็นงานของ mirror · คนละเรื่องกับขั้น flip ของ AA (พลิกเฟส 180° ให้ค่าที่ mark) · ถ้าข้อสอบถามว่า “ขั้นไหนสะท้อนรอบค่าเฉลี่ย” ตอบ mirror
ลองคำนวณเอง — state 2 qubit ที่มีแค่ |0⟩ = 1.0 เฟส 0° (อีก 3 วงว่าง) · หลัง mirror วง |1⟩ อยู่ที่พิกัดไหน? (หา avg ก่อน อย่าลืมหารด้วยจำนวนวงทั้งหมด)
ถูกค่ะ! avg = [0, 1.0/4] = [0, 0.25] → |1⟩ = 2×0.25 − 0 = 0.5 · ส่วน |0⟩ = 2×0.25 − 1 = −0.5 (ชี้ลง) · ทุกวง mag 0.5 = 25% เท่ากันหมด
ยังไม่ใช่ค่ะ — avg = [0, (1+0+0+0)/4] = [0, 0.25] · |1⟩ เดิมอยู่ [0, 0] → ใหม่ = 2×avg − เดิม = [0, 0.5] · ([0, 0.25] คือ avg เอง ยังไม่ได้สะท้อน · [0, −0.5] คือของวง |0⟩)

ข้อสังเกตสำคัญ: ค่าเฉลี่ยไม่ขยับ

หลังสะท้อน ลองเฉลี่ยค่าใหม่ทั้ง 4 วง: x = (−0.306 −0.306 −0.306 + 0.306)/4 = −0.153 · y = (−0.530 + 0.177 + 0.177 + 0.530)/4 = 0.088 → ได้ [−0.153, 0.088] เท่าเดิม (p40–41)

ถ้าเอา state ใน Figure 6-24 ไป mirror ซ้ำอีกครั้งทันที (ไม่มี flip คั่น) จะได้อะไร?
ใช่ค่ะ — avg ตัวเดิม สะท้อนผ่านจุดเดิมสองครั้ง = กลับที่เดิม · mirror จึงเป็น inverse ของตัวเอง · นี่คือเหตุผลเบื้องหลังที่บท 0023 บอกว่า “mirror ซ้ำโดยไม่ flip = ย้อนกลับ” · ต้อง flip ใหม่ทุกรอบ เพื่อย้ายค่าที่ mark ออกไปอีกฝั่ง ค่าเฉลี่ยจะได้เปลี่ยน
ลองคิดใหม่ค่ะ — ค่าเฉลี่ยของ state ใหม่ยังเป็นจุดเดิม · สะท้อนผ่านจุดเดิมอีกครั้ง จุดทุกจุดก็เดินย้อนทางเดิมกลับไป → ได้ state ตั้งต้นคืน (mirror เป็น inverse ของตัวเอง)

ส่วนที่ 2 · ทำไม oddball ถึงโต — slingshot

ตัวอย่างใน Figure 6-20 เฟสต่างกันแบบสุ่มๆ ผลเลยไม่น่าตื่นเต้น · ทีนี้ลองนึกถึง state ที่ค่าส่วนใหญ่เฟสเหมือนกัน แต่มีตัวแปลกแยก (oddball) ตัวเดียวที่เฟสต่างไป 180° (Figure 6-25 · p42) — ซึ่งก็คือหน้าตาหลัง flip นั่นเอง

⚠️ สไลด์ p42 เขียนป้ายผิด — ป้ายในรูปเขียน average: [0.25, 0.00] แต่คำนวณจริง ([0, 0.5] + [0, 0.5] + [0, 0.5] + [0, −0.5]) ÷ 4 = [0.00, 0.25] (x กับ y สลับกัน) · จุดดำที่วาดในรูปก็อยู่เหนือศูนย์กลาง (y = +0.25) ตรงกับของจริง · สอบให้ตอบตามสไลด์ถ้าเขาถามป้าย แต่รู้ไว้ว่าของจริงคือ [0, 0.25]
ทายก่อนเลื่อนลงไป — avg = [0, 0.25] · หลัง mirror วง |3⟩ จะมี magnitude เท่าไร?
เป๊ะค่ะ! 2×0.25 − (−0.5) = 1.0 → |3⟩ = 100% · ส่วนสามวงแรก 2×0.25 − 0.5 = 0 → หายเกลี้ยง
ลองแทนสูตรค่ะ: |3⟩ อยู่ที่ y = −0.5 → ใหม่ = 2×0.25 − (−0.5) = 0.5 + 0.5 = 1.0 · (ระวังเครื่องหมายลบซ้อนลบ) · สามวงแรก 2×0.25 − 0.5 = 0

ทำไมถึงเป็นแบบนี้ — ภาพหนังสติ๊ก

ค่าส่วนใหญ่ “ดึง” ค่าเฉลี่ยเข้าหาตัวเองพวกมากลากเสียง → ● อยู่ใกล้พวกมัน สะท้อนแล้วพวกมันขยับนิดเดียว (หรือหดลง)
→
oddball อยู่ไกล ● มากระยะไป ● ยาว → สะท้อนแล้วก็ไปไกลเท่ากันอีกฝั่ง = ถูกเหวี่ยงแบบหนังสติ๊ก (slingshot) จน magnitude โดดเด่น (p43)

ย้อนตอบตัวเลขของบท 0023–0025 ด้วยมือ

ตอนนี้กลับไปที่ register 4 qubit (16 วง) ที่ mark ค่า 3 · หลัง flip: 15 วงอยู่ที่ +0.25 และวง |3⟩ อยู่ที่ −0.25 (ทุกจุดอยู่บนแกนตั้ง ใช้แค่ y ก็พอ)

① avg = (15 × 0.25 + (−0.25)) ÷ 16 = 3.5 ÷ 16 = 0.21875
② |3⟩ ใหม่ = 2 × 0.21875 − (−0.25) = 0.6875 → 0.6875² = 47.3% ✓ (บท 0023)
③ วงอื่นใหม่ = 2 × 0.21875 − 0.25 = 0.1875 → 0.1875² ≈ 3.5% ✓
ทำซ้ำ (flip แล้วสะท้อน) อีก 2 รอบด้วยวิธีเดียวกันจะได้ 90.8% และ 96.1% ตรงกับบท 0024 ทุกหลัก (หนูรันตัวเลขยืนยันแล้ว) · รอบหลังๆ ค่าเฉลี่ยเข้าใกล้ 0 → เหวี่ยงได้น้อยลงแล้วเกินเลย → คลื่นแกว่ง
บท 0025 เห็นว่า mark 8 จาก 16 แล้ว AA ไม่ขยับเลย (50% ตลอด) · ภาพเรขาคณิตอธิบายว่ายังไง? (ลองหา avg ของ 8 วงที่ +0.25 กับ 8 วงที่ −0.25 ก่อน)
ใช่ค่ะ — avg = (8×0.25 − 8×0.25)/16 = 0 · สะท้อนผ่านศูนย์กลาง = แค่กลับหัวทุกจุด (ใหม่ = −เดิม) → magnitude เท่าเดิมทุกวง · ไม่มีใครเป็น oddball เพราะสองฝ่ายเท่ากัน
ลองคำนวณค่ะ: (8×0.25 + 8×(−0.25))/16 = 0 → avg อยู่ศูนย์กลางพอดี · สะท้อนผ่านศูนย์กลาง magnitude ไม่เปลี่ยน เฟสแค่กลับ 180° ทุกวง (ซึ่งวัดไม่ได้)

💡 และ Figure 6-25 ที่เพิ่งทำไป คือ mark 1 จาก 4 = m = N/4 → เหวี่ยงทีเดียวได้ 100% · อธิบายกรณีพิเศษของบท 0025 ได้ด้วยภาพเดียวกัน

ทำไม flip ต้องเป็น 180° และเคล็ดตอน implement จริง (p44)

  • งาน AA เกือบทั้งหมดในหนังสือ ตัวที่ใช้แทน flip จะสร้างความต่างเฟส 180° พอดี ระหว่างค่าที่ mark กับค่าอื่น → ตัวอย่าง slingshot ข้างบนตรงกับของจริง (180° = ทิศตรงข้าม = อยู่ไกล ● ที่สุด)
  • ในวงจรจริง การทำ “สะท้อนรอบค่าเฉลี่ย” เฉยๆ ยาก · ทำ สะท้อน + พลิกเฟสทุกวง ง่ายกว่า · วงจร mirror ที่เห็นในบท 0023 (H → ⊕ → CZ 4 ขา → ⊕ → H) ก็คือแบบหลังนี้ (ได้ ค่าเดิม − 2×avg แทน 2×avg − ค่าเดิม)
  • ใช้แทนกันได้สนิทเพราะ วัดได้แต่ relative phase (บท 0003) — พลิกทุกวงพร้อมกัน ความต่างระหว่างวงไม่เปลี่ยน
ต่างกันแค่เข็มของ |3⟩ ชี้ขึ้น/ลง · READ ได้ |3⟩ 100% เหมือนกัน
สรุปทั้งคาบ Lec 06 (p45) — AA คือ core operation ของแอป QPU จำนวนมาก · มันแปลงความต่างของเฟส (ข้อมูลที่ READ ตรงๆ มองไม่เห็น) ให้เป็นความต่างของ magnitude ที่อ่านออกมาเป็นคำตอบได้ · และกลไกทั้งหมดก็แค่ flip ให้คำตอบเป็น oddball → mirror เหวี่ยงมันออกมา · พลังเต็มๆ จะเห็นในคาบถัดๆ ไป
ทดสอบความจำ (ปิดหน้าจอก่อนแล้วตอบ)
  1. mirror ทำอะไรกับ circle notation ในเชิงเรขาคณิต (2 ขั้น)?
    ① เฉลี่ย x, y ของทุกวง (วงว่าง = [0,0]) ② สะท้อนทุกจุดผ่านค่าเฉลี่ย
  2. สูตรค่าใหม่หลัง mirror?
    2 × avg − ค่าเดิม (ทำแยกแกน x และ y)
  3. แปลง mag 0.707 เฟส 120° เป็น [x, y]
    x = −0.707·sin120° = −0.612 · y = 0.707·cos120° = −0.354
  4. Figure 6-20 หลัง mirror วงไหนโผล่ วงไหนหด?
    |1⟩ |2⟩ โผล่เป็น 0.353 · |0⟩ |3⟩ หดจาก 0.707 เหลือ 0.612
  5. ทำไม mirror สองครั้งติดกันจึงกลับที่เดิม?
    ค่าเฉลี่ยไม่เปลี่ยนหลังสะท้อน → สะท้อนผ่านจุดเดิมซ้ำ = inverse ตัวเอง
  6. state 0.5 เฟส 0° สามวง + 0.5 เฟส 180° หนึ่งวง: avg และผลหลัง mirror?
    avg [0, 0.25] (สไลด์เขียนผิดเป็น [0.25, 0]) · oddball = 1.0 ที่เหลือ 0
  7. “slingshot” คืออะไร?
    ค่าเฉลี่ยอยู่ใกล้พวกมาก ไกล oddball → สะท้อนแล้ว oddball ถูกเหวี่ยงไปไกล magnitude โต
  8. คำนวณ 47.3% ของ AA รอบแรก (16 วง mark 1 ค่า) ด้วยมือ
    avg = 3.5/16 = 0.21875 · 2×0.21875 + 0.25 = 0.6875 · ยกกำลังสอง = 47.3%
  9. mark 8 จาก 16 ทำไม AA ไม่ขยับ?
    avg = 0 → สะท้อนผ่านศูนย์กลาง magnitude ไม่เปลี่ยน
  10. วงจร mirror จริงทำอะไรต่างจาก “สะท้อนเฉยๆ” และทำไมใช้แทนกันได้?
    สะท้อน + พลิกเฟสทุกวง · วัดได้แต่ relative phase จึงผลเหมือนกัน

สรุปบทนี้

  • มองแต่ละวงเป็นจุด [x, y] = [−mag·sinθ, mag·cosθ] · mirror = เฉลี่ยทุกจุด (รวมวงว่าง) → สะท้อนผ่านค่าเฉลี่ย
  • ค่าใหม่ = 2 × avg − ค่าเดิม · ค่าเฉลี่ยไม่ขยับ → mirror เป็น inverse ของตัวเอง (ต้อง flip ทุกรอบ)
  • ความต่างของเฟส → ความต่างของ magnitude · oddball ที่ต่าง 180° อยู่ไกล avg สุด → slingshot
  • ตัวเลข 47.3% / 90.8% / 96.1% · m = N/4 → 100% · m = N/2 → avg = 0 ไม่ขยับ = คำนวณได้ด้วยกฎเดียว
  • วงจรจริง = สะท้อน + พลิกเฟสทุกวง (ผลวัดเท่ากันเพราะ relative phase)
  • ⚠️ สไลด์: p42 ป้าย avg สลับแกน (จริง [0, 0.25]) · “Flipping about the average” = งานของ mirror ไม่ใช่ขั้น flip
