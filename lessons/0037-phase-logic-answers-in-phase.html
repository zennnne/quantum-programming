phase logic: เก็บคำตอบไว้ใน phase

ตอนเรียน AA (บท 0023–0026) เราใช้วงจร flip ที่พลิก phase ของค่าที่รู้อยู่แล้ว ซึ่งเป็นแค่ตัวแทนชั่วคราว เพราะถ้าเรารู้คำตอบอยู่แล้วก็ไม่ต้องค้นหา · คาบนี้จะเติมชิ้นที่ยังขาดไป คือ flip ที่สร้างจากเงื่อนไขทางตรรกะ เช่น "พลิกทุกค่าที่ทำให้ a OR b เป็นจริง" · เครื่องมือที่ใช้ทำเรื่องนี้เรียกว่า phase logic (ลอจิกบนเฟส)

ทำไมต้องเรียนบทนี้: จับหลัก 4 อย่าง ① Quantum Search (QS) = AA + flip ที่สร้างจาก logic ② phase logic รับ input เป็นค่าในรีจิสเตอร์ แต่เก็บ output ไว้ใน phase โดยพลิก phase ของทุกค่าที่ทำให้เงื่อนไขเป็นจริง ③ อ่านผลด้วย circle notation (Figure 10-1) ④ สร้าง phase logic 6 แบบจาก gate จริง (Figure 10-2) · ข้อ ④ ออกสอบสัญลักษณ์วงจร และหนูเพิ่มวงจรทั้ง 6 ลงชีตแล้ว

ส่วนที่ 1 · phase logic ทำอะไร: มองผ่านวงกลม (p1–10)

1.1 Quantum Search = AA + flip ที่มาจาก logic

ทวนนิดนึง: AA เปลี่ยนความต่างของ phase ให้กลายเป็นความต่างของ magnitude ซึ่ง READ แล้วเห็นได้ (p2) · แต่ AA ต้องมีคนส่ง subroutine flip มาให้ก่อน ว่าจะ mark ค่าไหน · Quantum Search (QS, การค้นหาเชิงควอนตัม) คือเทคนิคสร้าง flip นั้นขึ้นมาจาก boolean logic ดังนั้น QS จึงเป็นแค่ "การนำ AA ไปใช้" โดยใส่ subroutine ที่ mark คำตอบไว้ใน phase (p3)

QS = flip ที่สร้างจาก logic (phase logic) + mirror · วนซ้ำ NAA รอบ

ตัวอย่างที่ชัดที่สุดคือค้นหาในฐานข้อมูล: ให้ฟังก์ชันคืน 1 เฉพาะเมื่อ input เป็นตัวที่ตามหา · การใช้งานต้นแบบนี้ชื่อ Grover's search algorithm ซึ่งใช้ query เพียง O(√N) ครั้ง ขณะที่วิธีคลาสสิกต้องใช้ O(N) (p3) · ข้อจำกัดคือ Grover สมมติว่าเป็น unstructured database (ฐานข้อมูลไม่มีโครงสร้าง) ซึ่งในชีวิตจริงเจอไม่บ่อย · แต่ QS ยังใช้เป็น subroutine เร่งงานอื่นได้อีกมาก ตั้งแต่ AI ไปจนถึง software verification (p4)

⚠️ สไลด์ p3 พิมพ์ตก: บนสไลด์เขียนว่า "using only O N database queries" โดยไม่มี √ และไม่มีวงเล็บ (หนูซูมดูแล้ว) · ของจริงคือ O(√N) ถ้าเป็น O(N) ก็จะไม่เร็วกว่าคลาสสิกเลย · ถ้าข้อสอบถามความเร็วของ Grover ให้ตอบ O(√N)

1.2 นิยาม: input อยู่ในค่า output อยู่ใน phase

logic ที่เรียนใน Lec 05 (บท 0022) ทำงานกับ superposition ได้ก็จริง แต่ทั้ง input และ output เป็นค่าในรีจิสเตอร์ (เช่น |2⟩, |5⟩) โดยมักเขียนผลลงใน scratch qubit · เราจะเรียก logic แบบนี้ว่า magnitude logic เพื่อแยกจากแบบใหม่ (p5)

นิยาม (p5–6): วงจร phase logic แทน logic operation หนึ่งตัว (AND, OR, …) โดย พลิก phase ของทุกค่าในรีจิสเตอร์ที่ operation นั้นให้ผลเป็น 1 · input ที่ทำให้ได้ 1 เรียกว่า input ที่ satisfy (ทำให้เป็นจริง) operation นั้น → พูดสั้นๆ ได้ว่า phase logic พลิก phase ของทุกค่าที่ satisfy
phase logicเอาปากกาหมึกล่องหนไปขีดทุกบรรทัดที่ตรงเงื่อนไขในรายชื่อ · ขีดได้ทีเดียวหลายบรรทัด แต่ถ้ามองด้วยตาเปล่า (READ) จะไม่เห็นรอยขีดเลย

AA (mirror)คือไฟ UV ที่ทำให้รอยหมึกล่องหนเรืองแสงขึ้นมา · phase logic ทำหน้าที่ mark ส่วน AA ทำให้เห็นสิ่งที่ mark ไว้ ต้องใช้คู่กัน

ทำไมต้องเป็น superposition? ถ้ารีจิสเตอร์มีอยู่ค่าเดียว การพลิก phase ของค่านั้นก็เท่ากับคูณทั้งรีจิสเตอร์ด้วย −1 ซึ่งเป็นแค่ global phase ที่ไม่มีผลต่ออะไรเลย · แต่ถ้าเป็น superposition การพลิกบางวงจะสร้าง relative phase (เฟสสัมพัทธ์) ซึ่ง AA ดึงออกมาได้ (p6)

1.3 phase logic ตัวแรกที่เรารู้จักมานานแล้ว: PHASE(180)

ลองดู PHASE(180°) บน qubit เดียว: มันพลิก phase เฉพาะ |1⟩ ซึ่งก็คือ "พลิกเมื่อค่าของ qubit เป็น 1" · ตรงกับนิยามพอดี เราจึงมอง PHASE(180) ว่าเป็น phase logic ที่เขียนค่าตรรกะของ qubit ลงใน phase ของตัวเอง (p7)

หมายเหตุ: สไลด์ p7 ขึ้นต้นว่า "When acting on a single qubit, it simply writes…" โดยไม่บอกว่า "it" คืออะไร และไม่ได้เขียน 180 ไว้ (ตัดมาจากหนังสือ) · หนูอนุมานจากประโยคถัดไปว่าหมายถึง PHASE ที่มุม 180°

ส่วนที่ 2 · phase logic สร้างยังไง: มองผ่านวงจร (p11–13)

ส่วนที่ 1 ดูว่า phase logicทำอะไร ส่วนนี้จะดูว่าสร้างจาก gate พื้นฐานยังไง (Figure 10-2) · ชิ้นส่วนที่ใช้มีแค่ 3 ตัวที่รู้จักกันอยู่แล้ว:

  • PHASE(180) บน a → พลิกเมื่อ a = 1 · เขียนเป็นตัวคูณได้ (−1)a
  • CZ ระหว่าง a กับ b → พลิกเมื่อ a = 1 และ b = 1 (บท 0010) → (−1)ab · CZ คือ phase AND อยู่แล้ว
  • X (NOT) → สลับ 0 กับ 1 เอาไว้ "กลับเงื่อนไข" ก่อนพลิก แล้วสลับคืนหลังพลิก
ทวนคณิต: นับจำนวนครั้งที่โดนพลิก · พลิก 180° หนึ่งครั้ง = คูณ −1 · ถ้าวงหนึ่งโดนพลิกคี่ครั้ง ผลรวมคือ −1 (ถูกพลิก) · ถ้าโดนคู่ครั้ง ผลรวมคือ +1 (เหมือนไม่โดนเลย) · เทคนิคนี้ใช้ตรวจวงจรทุกตัวในส่วนนี้ได้

ตัวคูณรวมคือ (−1)a · (−1)ab · (−1)b · ลองนับดูทีละวงว่าแต่ละวงโดนพลิกกี่ครั้ง ก่อนกดเฉลย:

③ ในวงจร phase OR วง |3⟩ (a = 1, b = 1) โดนพลิกทั้งหมดกี่ครั้ง แล้วผลออกมาเป็นยังไง
ถูกค่ะ φ บน a + CZ + φ บน b = 3 ครั้ง (คี่) → −1 · ถ้าไม่มี CZ จะได้ 2 ครั้ง (คู่) แล้ว |3⟩ จะกลับมาเป็น + ซึ่งผิด · CZ จึงทำหน้าที่แก้ให้ |3⟩
ไล่ทีละ gate: φ บน a (a=1 ✓) · CZ (a=b=1 ✓) · φ บน b (b=1 ✓) · ได้กี่ครั้ง แล้วเป็นเลขคู่หรือคี่?
|0⟩ a=0, b=0 → 0 ครั้ง → +
|1⟩ a=1, b=0 → φ(a) 1 ครั้ง → −
|2⟩ a=0, b=1 → φ(b) 1 ครั้ง → −
|3⟩ a=1, b=1 → 3 ครั้ง → − · ตรงกับ Figure 10-1 แถว OR (|1⟩ |2⟩ |3⟩) ✓

2.3 phase NOR และ phase NAND: เอา X ไปครอบ

ทั้งสองตัวใช้ De Morgan ที่เรียนใน Lec 05: ใส่ X ทั้งสองสายก่อนเพื่อกลับ input แล้วใส่ X อีกครั้งเพื่อคืนค่า

  • NOR = NOT(a OR b) = (NOT a) AND (NOT b) → X ทั้งสองสาย + phase AND + X คืน · 00 ถูกแปลงเป็น 11 ชั่วคราวแล้ว CZ พลิก → พลิก |0⟩
  • NAND = NOT(a AND b) = (NOT a) OR (NOT b) → X ทั้งสองสาย + phase OR + X คืน → พลิก |0⟩ |1⟩ |2⟩
④ ลองออกแบบเอง: อยากได้ phase logic ของ a AND (NOT b) (พลิกเฉพาะ |1⟩ คือ a = 1, b = 0) ต้องใช้วงจรไหน
ถูกค่ะ กลับเฉพาะ b ทำให้ |1⟩ (a=1, b=0) กลายเป็น 11 ชั่วคราว → CZ พลิก → X คืน · เป็นแบบเดียวกับ NOR แต่ครอบ X แค่สายที่มี NOT
หลักคือ "กลับเฉพาะสายที่มี NOT แล้วใช้ phase AND" · ค่าที่อยากให้ถูกพลิกคือ a=1, b=0 ต้องกลับสายไหนถึงจะกลายเป็น 11?

2.4 phase XOR: ใช้ scratch qubit ที่อยู่ใน |−⟩ + phase kickback

phase XOR ต่างจากตัวอื่นตรงที่ใช้ scratch qubit เพิ่ม 1 ตัว ซึ่งใน phase logic ต้องเตรียมให้อยู่ใน |−⟩ เสมอ (p11) · สไลด์เขียนว่า "initialized3" เลข 3 เป็นเชิงอรรถจากหนังสือ ไม่ได้มีความหมายอะไร

เตรียม WRITE 0 → X → H : |0⟩ → |1⟩ → |−⟩
kickback |−⟩ เมื่อโดน NOT จะกลายเป็น −|−⟩ คือตัวมันเองหน้าตาเดิม แต่มี −1 ติดออกมา · −1 นั้นไปเกาะกับค่าของ input ที่เป็นตัวควบคุม (บท 0010)
นับ CNOT จาก a พลิกเมื่อ a = 1 · CNOT จาก b พลิกเมื่อ b = 1 → (−1)a+b · พลิกคี่ครั้งเมื่อ a ≠ b พอดี = XOR → |1⟩ |2⟩ ✓
คืน H → X : |−⟩ → |1⟩ → |0⟩ · scratch กลับเป็น 0 เหมือนตอนเริ่ม
ประโยคสำคัญ (p12): scratch qubit ไม่ entangle กับรีจิสเตอร์ input เพราะใช้ phase kickback · ตลอดเวลา scratch ยังเป็น |−⟩ หน้าตาเดิม มีแค่ −1 ที่ถูกส่งไปให้ input → จึงไม่ต้อง uncompute ทั้ง phase-logic gate (ต่างจาก magnitude logic ในบท 0021b ที่ scratch เก็บผลไว้เป็นค่าจริงจึงต้อง uncompute)
⑤ H กับ X สองตัวท้ายบน scratch ของ phase XOR ทำหน้าที่อะไร
ถูกค่ะ แค่ย้อนขั้นเตรียม (X → H) กลับทาง · ไม่ใช่การ uncompute เพราะ scratch ไม่ได้ entangle อะไรเลย และผลก็ยังอยู่ใน phase ต้องใช้ AA ถึงจะ READ ได้
ลองดูว่า scratch อยู่ใน state อะไรหลัง CNOT ตัวที่สอง (ยังเป็น |−⟩) แล้ว H → X ทำให้ |−⟩ กลายเป็นอะไร
⚠️ อย่าให้ชื่อหลอก (p13): input ของ phase logic เข้ารหัสอยู่ในค่าของรีจิสเตอร์ (เช่น |2⟩, |5⟩) · มีแค่ output เท่านั้นที่อยู่ใน relative phase · phase logic ไม่ได้รับ phase เป็น input · ข้อนี้คือเหตุผลที่เราต่อ phase logic สองตัวเข้าหากันตรงๆ ไม่ได้ ซึ่งจะเป็นเรื่องของบทหน้า
เกร็ดที่หนูเติมเอง (ไม่ได้มาจากสไลด์ และไม่ออกสอบ): ถ้าใช้ PHASE(180) บน a แล้วตามด้วย PHASE(180) บน b ก็จะได้ (−1)a+b ซึ่งเป็น phase XOR เหมือนกัน (หนูเช็กด้วย numpy แล้ว) · หนังสือน่าจะเลือกใช้ scratch + kickback เพื่อปูเทคนิคนี้ไว้ก่อน เพราะในปริศนาบท 0039 จะใช้ kickback แบบเดียวกันนี้ · เวลาสอบให้วาดตาม Figure 10-2 (แบบมี scratch)
