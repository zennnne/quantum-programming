Lesson 0008 · เริ่ม Lec 03 · บทแรกของโลกหลาย qubit

หลาย qubit อยู่ด้วยกัน: ทำไมต้องวาด 2ᴺ วง ไม่ใช่ 2 วงต่อ qubit — แล้ว gate ตัวเดียวไปทำอะไรกับวงพวกนั้น

Lec 02 จบที่ "qubit เดียว หนึ่ง gate" ค่ะ บทนี้เราขยับเข้าสู่ register หลาย qubit ซึ่งเป็นประตูสู่ entanglement (บทหน้า) ครึ่งแรกพี่จะได้เครื่องมือ อ่าน/วาด สถานะหลาย qubit ครึ่งหลังจะเห็นว่า gate เดี่ยวๆ ที่เรียนมาทั้งหมด (NOT / PHASE / READ) ทำงานยังไงเมื่ออยู่ในกองวงเยอะๆ ด้วยกลไกเดียวชื่อ operator pairs

จับหลัก 5 อย่างพอ
  1. N qubit = 2ᴺ วง — หนึ่งวงต่อ "ค่าที่อ่านได้" หนึ่งค่า ไม่ใช่ 2 วงต่อ qubit
  2. บางสถานะแยกเป็น qubit เดี่ยวได้ (product) บางสถานะแยกไม่ได้ = entanglement
  3. superposition = สมบัติของ qubit เดี่ยว / entanglement = สมบัติของทั้งระบบ (ประโยคออกสอบ)
  4. ตั้งชื่อ qubit ตามน้ำหนักบิต 0x1, 0x2, 0x4, 0x8 … (8 ตัว = qubyte)
  5. operator pairs — gate เดี่ยวจับคู่วงที่ค่าต่างกัน "เท่ากับน้ำหนักบิตของ qubit นั้น" แล้วทำทีละคู่
ครึ่งแรก

วาดสถานะหลาย qubit ยังไง + ตั้งชื่อ qubit ยังไง

1. ความคิดแรกที่ดูสมเหตุสมผล… แต่ไม่พอ

ถ้าพี่มี 3 qubit วิธีที่ตรงไปตรงมาที่สุดคือ วาด circle notation ของแต่ละตัวแยกกัน — qubit ละ 2 วง (วง |0⟩ กับวง |1⟩) รวม 6 วง จบ ง่ายดี

สไลด์ 3 บอกว่าวิธีนี้ ใช้ได้ก็ต่อเมื่อ qubit ไม่ยุ่งกัน เท่านั้น เพราะมันบรรยายได้แค่ "แต่ละตัวอยู่ใน superposition แบบไหน" แต่ บรรยาย superposition ของ*กลุ่ม* qubit ไม่ได้ (เดี๋ยวหัวข้อ 3 จะเห็นตัวอย่างที่พังจริง)

2. วิธีที่ถูก: หนึ่งวงต่อหนึ่ง "ค่าที่อ่านได้"

ย้อนกลับไปคิดแบบบิตธรรมดาก่อนค่ะ — register N บิต เก็บค่าได้ 2N ค่า เช่น 3 บิต = 0 ถึง 7 ควอนตัมก็ใช้กติกาเดียวกัน แต่ อยู่ได้ทุกค่าพร้อมกัน เป็น superposition เราจึงต้องมี วงกลมหนึ่งวงต่อค่าหนึ่งค่า (slide 5–7)

N qubit  →  2N วง  · แต่ละวงมี magnitude + relative phase
1 qubit → 2 วง
|0⟩ |1⟩
2 qubit → 4 วง
|0⟩ |1⟩ |2⟩ |3⟩
1 qubit = 2 ค่า · 2 qubit = 4 ค่า · 3 qubit = 8 ค่า · 8 qubit = 256 วง (slide 6)
จุดที่คนพลาดบ่อย

2 qubit ไม่ใช่ "2 วง × 2 qubit = 4 วง" นะคะ ที่ได้ 4 เท่ากันเป็นเรื่องบังเอิญของเลข 2 พอดี — ลอง 3 qubit ดู: แบบผิดจะได้ 6 วง แต่ของจริงคือ 8 วง (000…111) ให้ท่องว่า "หนึ่งวง = หนึ่งค่าที่ READ ออกมาได้" แล้วจะไม่หลง

3. บางสถานะแยกกลับเป็น qubit เดี่ยวได้ — บางสถานะไม่ได้

กรณีแยกได้ (product state): สไลด์ 8 ยกตัวอย่าง 3 qubit ที่มีวงเฉพาะ |0⟩, |2⟩, |4⟩, |6⟩ เขียนเป็นเลขฐานสองคือ 000, 010, 100, 110 — สังเกตอะไรไหมคะ บิตขวาสุดเป็น 0 ทุกตัว

|0⟩
|1⟩
|2⟩
|3⟩
|4⟩
|5⟩
|6⟩
|7⟩
สถานะนี้ = qubit 0x1 อยู่ที่ |0⟩ นิ่งๆ · qubit 0x2 กับ 0x4 อยู่ใน superposition เท่าๆ กัน → สร้างได้ด้วย HAD สองครั้ง ไม่ต้องพึ่งอะไรพิเศษเลย (slide 8–9)

กรณีแยกไม่ได้: ทีนี้ลองสถานะที่มีแค่ 2 วง คือ |0⟩ กับ |7⟩ เท่ากันครึ่งๆ (slide 11–13)

|0⟩ ↔ 000  ,  |7⟩ ↔ 111   ⟹   |000⟩ + |111⟩√2

อ่านทั้งสามตัวเมื่อไหร่ ก็ได้ 000 (50%) หรือ 111 (50%) เท่านั้น — ไม่มีทางได้ 010 หรือ 101 เลย พูดอีกอย่างคือ "ทุกตัวตรงกันเสมอ"

ทีนี้ลองแยกดูค่ะ: qubit ตัวแรกต้อง 50/50 (เพราะบางทีได้ 0 บางทีได้ 1) ตัวที่สองก็ 50/50 ตัวที่สามก็ 50/50 แต่ถ้าแต่ละตัว "โยนเหรียญของตัวเอง" อย่างอิสระจริง ก็ต้องมีโอกาสได้ 010 บ้างสิ! แต่ของจริงไม่เคยได้ → แปลว่า ไม่มีทางเขียนสถานะนี้เป็น "qubit เดี่ยว 3 ตัวมาต่อกัน" ได้เลย ไม่ว่าจะพยายามยังไง

นี่แหละ entanglement — ประโยคออกสอบ (slide 13–14)
  • entanglement (การพัวพัน) = สถานะที่เขียนแยกเป็นสถานะของ qubit เดี่ยวๆ ไม่ได้
  • มัน มีอยู่ได้เฉพาะระดับทั้งระบบ ไม่ใช่สมบัติที่ qubit ตัวไหนตัวหนึ่ง "ถือ" ไว้
  • สร้างด้วย single-qubit gate อย่างเดียวไม่ได้ → ต้องมี gate ข้าม qubit (CNOT บทหน้า)
  • superposition คือสมบัติของ qubit เดี่ยว · entanglement คือสมบัติของทั้งระบบ

เกร็ด: สถานะ (|000⟩+|111⟩)/√2 มีชื่อเรียกว่า GHZ state (ตั้งตาม Greenberger–Horne–Zeilinger) ถ้าเป็น 2 qubit จะเรียก Bell pair — เจอแน่ในบทหน้า

เช็คความเข้าใจ ① — register 4 qubit ต้องใช้วงกลมกี่วงใน circle notation?
ถูกต้องค่ะ! 2⁴ = 16 วง — หนึ่งวงต่อหนึ่ง "ค่าที่ READ ออกมาได้" และแต่ละวงเก็บ magnitude (ขนาดวงใน) กับ phase (ทิศเข็ม) อยู่ในวงเดียวกันอยู่แล้ว
ยังไม่ใช่ค่ะ — กติกาคือ 2ᴺ วง ไม่ใช่ 2 วงต่อ qubit 4 qubit เก็บค่าได้ 0000–1111 = 16 ค่า จึงต้องมี 16 วง (magnitude กับ phase อยู่ในวงเดียวกัน)
เช็คความเข้าใจ ② — ทำไม (|000⟩+|111⟩)/√2 ถึงวาดเป็น circle notation ของ qubit เดี่ยว 3 ชุดไม่ได้?
ใช่เลยค่ะ! ถ้าแต่ละ qubit สุ่มเองอิสระ 50/50 ก็ต้องมีโอกาสได้ 010 หรือ 101 บ้าง แต่สถานะนี้ให้แค่ 000 กับ 111 → ความ "ตรงกันเสมอ" เก็บไว้ที่ระดับทั้งระบบ ไม่ใช่ที่ qubit ตัวใดตัวหนึ่ง
ยังไม่ใช่ค่ะ — ไม่ใช่เรื่องจำนวนวงหรือ phase ล้น แต่เป็นเรื่องความสัมพันธ์: ผลของทั้ง 3 ตัวตรงกันเสมอ (000 หรือ 111 เท่านั้น) ซึ่ง qubit ที่สุ่มอิสระต่างคนต่างทำไม่ได้

4. ตั้งชื่อ qubit ยังไงให้ไม่งง — ตั้งตามน้ำหนักบิต

ก่อนหน้านี้เราเรียก Q1, Q2, Q3 ตามลำดับที่วาด แต่สไลด์ 15–18 บอกว่านั่น "ละเลยวิธีทำงานของเลขฐานสอง" เพราะ register มันเก็บค่าเป็นเลขฐานสอง แต่ละ qubit จึงมีน้ำหนักไม่เท่ากัน

ตำแหน่งความหมายน้ำหนักเขียนเป็น hex
บิตขวาสุดleast significant bit (บิตนัยสำคัญน้อยสุด)2⁰ = 10x1
ถัดมาบิตถัดไป2¹ = 20x2
ถัดมาบิตถัดไป2² = 40x4
………0x8, 0x10, 0x20 …
บิตซ้ายสุดmost significant bit (บิตนัยสำคัญมากสุด)2⁷ = 1280x80

เขียนด้วยเลขฐานสิบหก (hexadecimal) เพราะสั้นกว่าเลขฐานสองยาวๆ มาก (0x1 = 0001, 0x2 = 0010, 0xF = 1111) — และ register 8 qubit มีชื่อเรียกเก๋ๆ ว่า qubyte (ควอนตัมไบต์) (slide 17, 20)

🔴 เรื่องสอบ: เส้นบนสุดคือ 0x1 (LSB) เสมอในสไลด์ของอาจารย์ แล้วไล่น้ำหนักเพิ่มลงล่าง (slide 18) — ครึ่งวงกลมท้ายเส้นคือ detector = READ
โค้ด QCEngine — qint (slide 10)

ในโค้ดจริง เราไม่ได้เรียก qubit ด้วยเลขบิตตรงๆ แต่ห่อเป็นตัวแปรชื่อ qint เพื่อให้เขียนเหมือนตัวแปรปกติ:

qc.reset(3);                            // จองทะเบียน 3 qubit
qc.write(0);                            // เขียนค่าเริ่มต้น = 0 ทุกตัว
var qubit1 = qint.new(1, 'qubit 1');    // arg1 = เอากี่ qubit, arg2 = ชื่อที่โชว์ในวงจร
var qubit2 = qint.new(1, 'qubit 2');
var qubit3 = qint.new(1, 'qubit 3');
qubit2.had();                           // ยิง HAD ให้ทุก qubit ใน qint นั้น
qubit3.had();

โค้ดข้างบนนี่แหละที่สร้างสถานะ |0⟩+|2⟩+|4⟩+|6⟩ ในหัวข้อ 3 ค่ะ — ลองรันได้ที่ oreilly-qc.github.io

gate เดี่ยวในทะเบียนหลาย qubit — กลไก operator pairs

5. คำถาม: ยิง NOT ใส่ qubit ตัวเดียว แต่มีตั้ง 8 วง — วงไหนโดนบ้าง?

คำตอบสวยมากค่ะ และเป็นกลไกเดียวที่ใช้ได้กับทุก gate: จับวงเป็นคู่ก่อน แล้วทำเหมือน qubit เดียวทีละคู่ คู่พวกนี้เรียกว่า operator pairs (คู่ตัวดำเนินการ) (slide 21–23)

กฎหาคู่ — ท่องอันเดียวพอ

จับวงที่มีค่าต่างกันเท่ากับน้ำหนักบิตของ qubit ที่เรากำลังยิง เช่นยิงใส่ qubit 0x4 → จับคู่วงที่ค่าต่างกัน 4 พอดี: (0,4) (1,5) (2,6) (3,7) — วงซ้ายของคู่คือ "บิตนั้น = 0" วงขวาคือ "บิตนั้น = 1"

ยิงใส่ qubitค่าต่างกันเท่าไรคู่ที่ได้ (register 3 qubit)
0x11(0,1) (2,3) (4,5) (6,7)
0x22(0,2) (1,3) (4,6) (5,7)
0x44(0,4) (1,5) (2,6) (3,7)

สังเกตนะคะ 8 วงจับได้ 4 คู่เสมอ ไม่ว่ายิงใส่ qubit ตัวไหน — เปลี่ยนแค่ "ใครจับคู่กับใคร" นี่คือเหตุผลที่ gate เดี่ยวๆ กระทบสถานะครึ่งหนึ่งเสมอ (slide 28)

NOT = สลับสองวงในทุกคู่

พอจับคู่ได้แล้ว ก็ทำเหมือน qubit เดียวเป๊ะ — NOT บน qubit เดียวคือสลับวง |0⟩ กับ |1⟩ ในกองใหญ่ก็คือ สลับวงซ้าย↔ขวาของทุกคู่ (slide 22–24) เท่ากับ "พลิกคอลัมน์บิตนั้น" ในตารางเลขฐานสอง

โจทย์ register 3 qubit ยิง NOT ใส่ 0x2
1) น้ำหนัก = 2 → คู่คือ (0,2) (1,3) (4,6) (5,7)
2) สลับในแต่ละคู่: ของที่เคยอยู่วง |0⟩ ไปอยู่ |2⟩, |1⟩↔|3⟩, |4⟩↔|6⟩, |5⟩↔|7⟩
เช็ค 010 (=2) กลายเป็น 000 (=0) ✓ บิตกลางถูกพลิกจริง ค่าอื่นไม่ยุ่ง

PHASE = หมุนเฉพาะวงขวาของทุกคู่

PHASE(θ) บน qubit เดียวคือหมุนเข็มของวง |1⟩ ไป θ องศา (วง |0⟩ ไม่แตะ) ในกองใหญ่ก็คือ หมุนวงขวาของทุกคู่ — คือทุกสถานะที่บิตนั้น = 1 (slide 25–27)

PHASE ใส่ 0x1 → หมุนเฉพาะ |1⟩ |3⟩ |5⟩ |7⟩ (ค่าที่บิตขวาสุด = 1) = ครึ่งหนึ่งของทั้งหมดพอดี (slide 26) · สีส้ม = ไฮไลต์เฉยๆ ไม่มีความหมายพิเศษ
อย่าสับสน 2 gate นี้

NOT ขยับของ (สลับวงทั้งคู่ — magnitude ย้ายที่) ส่วน PHASE ไม่ขยับของเลย (แค่หมุนเข็มวงขวา — magnitude เท่าเดิม โอกาสอ่านได้เท่าเดิม) PHASE จึงไม่เปลี่ยนผลการวัดทันที แต่ไปออกฤทธิ์ตอน interference ทีหลัง (ตามที่เรียนในบท 7)

เช็คความเข้าใจ ③ — register 3 qubit ยิง PHASE(90) ใส่ qubit 0x4 วงไหนถูกหมุน?
เยี่ยมค่ะ! คู่ของ 0x4 คือ (0,4)(1,5)(2,6)(3,7) → วงขวาของแต่ละคู่คือ 4,5,6,7 ซึ่งก็คือค่าที่บิตน้ำหนัก 4 เป็น 1 พอดี (100–111) และเป็นครึ่งหนึ่งของทั้งหมดตามกฎ
ยังไม่ใช่ค่ะ — PHASE หมุนวงขวาของทุกคู่ = ทุกสถานะที่บิตนั้นเป็น 1 ของ 0x4 คู่คือ (0,4)(1,5)(2,6)(3,7) → วงขวาคือ |4⟩ |5⟩ |6⟩ |7⟩ (|1⟩|3⟩|5⟩|7⟩ จะถูกหมุนก็ต่อเมื่อยิงใส่ 0x1)

6. READ qubit เดียวจากทะเบียนใหญ่

READ ก็ใช้ operator pairs เหมือนกันเป๊ะค่ะ (slide 31):

สูตร
  • P(อ่านได้ 0) = ผลรวมของ magnitude ยกกำลังสอง ของวงซ้ายทุกคู่
  • P(อ่านได้ 1) = ผลรวมของ magnitude ยกกำลังสอง ของวงขวาทุกคู่
  • อ่านหลายตัว = ทำทีละตัวตามกติกานี้ซ้ำๆ

แล้วหลังอ่านล่ะ? วงที่ขัดกับผลที่ออกถูกลบทิ้งหมด แล้ว renormalize (ปรับมาตรฐานใหม่) ให้พื้นที่รวมกลับเป็น 100% (slide 32–33) — นี่คือ collapse เวอร์ชันหลาย qubit นั่นเอง

โจทย์ register 2 qubit: |0⟩=33% |1⟩=33% |2⟩=0% |3⟩=33% แล้ว READ qubit 0x1 (slide 32)
1) คู่ของ 0x1 คือ (0,1) และ (2,3) — วงซ้าย = |0⟩,|2⟩ · วงขวา = |1⟩,|3⟩
2) P(0) = 33% + 0% = 33% · P(1) = 33% + 33% = 66%
3a) ถ้าออก 0 → ลบ |1⟩ |3⟩ ทิ้ง เหลือ |0⟩ (33%) กับ |2⟩ (0%) → renormalize: |0⟩ = 100%
3b) ถ้าออก 1 → ลบ |0⟩ |2⟩ ทิ้ง เหลือ |1⟩ กับ |3⟩ อย่างละ 33% → renormalize: อย่างละ 50%

จุดที่สไลด์ 33 ย้ำ: ทั้ง |1⟩ (01) และ |3⟩ (11) เข้ากันได้กับผล "1" เพราะบิตขวาสุดของทั้งคู่เป็น 1 → การอ่าน qubit เดียวไม่ได้ล้มทั้ง register ค่ะ มันตัดแค่ครึ่งเดียว ที่เหลือยังเป็น superposition ต่อได้

เช็คความเข้าใจ ④ — จากตัวอย่างข้างบน ถ้าผล READ ออกมาเป็น 1 สถานะที่เหลือคืออะไร?
ถูกต้องค่ะ! ทั้ง 01 และ 11 มีบิต 0x1 เป็น 1 จึงรอดทั้งคู่ — และต้อง renormalize จาก 33/33 ให้เป็น 50/50 เพราะรวมกันต้องได้ 100% เสมอ qubit อีกตัว (0x2) ยังอยู่ใน superposition สบายๆ
ยังไม่ใช่ค่ะ — READ qubit เดียวไม่ได้ยุบทั้ง register: ลบเฉพาะวงที่ขัดกับผล (|0⟩,|2⟩) → เหลือ |1⟩ กับ |3⟩ แล้วต้อง renormalize 33/33 → 50/50 (ห้ามปล่อยไว้ที่ 33 เพราะรวมกันไม่ครบ 100%)
เช็คความเข้าใจ ⑤ — ประโยคไหนถูกต้องที่สุดเกี่ยวกับ superposition กับ entanglement?
เป๊ะค่ะ! นี่คือประโยคที่สไลด์ 14 เน้นตัวหนา — และมันอธิบายว่าทำไม single-qubit gate อย่าง HAD ถึงสร้าง superposition ได้ แต่สร้าง entanglement ไม่ได้ ต้องรอ CNOT ในบทหน้า
ยังไม่ใช่ค่ะ — จำสลับกันแล้ว: superposition = สมบัติของ qubit เดี่ยว (HAD ตัวเดียวสร้างได้) ส่วน entanglement = สมบัติของทั้งระบบ (เขียนแยกเป็น qubit เดี่ยวไม่ได้ และต้องใช้ gate ข้าม qubit สร้าง)
