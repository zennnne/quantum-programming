Lesson 0008½ · เซสชันโจทย์ล้วน · คู่กับ บท 0008

ซ้อมมือ register หลาย qubit — คิดเองก่อน แล้วค่อยกดเฉลย

บทนี้ไม่มีเนื้อหาใหม่เลยค่ะ มีแต่โจทย์ให้ลงมือคำนวณ/วาดเอง จากบท 0008 ทั้งดุ้น เพราะพี่บอกว่า "เข้าใจตอนเรียนแล้ว แต่กลัวลืมถ้าไม่ได้ลองทำ" — นี่แหละตัวช่วย: การดึงจากความจำ (retrieval) คือสิ่งที่เปลี่ยน "เข้าใจชั่วคราว" ให้เป็น "จำได้ยาว" จริงๆ ค่ะ

วิธีใช้เซสชันนี้ให้ได้ผลสุด
  1. อย่าเพิ่งกดเฉลย! อ่านโจทย์ → คำนวณ/วาดในหัวหรือในกระดาษให้จบก่อน → ค่อยกด "ดูเฉลย"
  2. ข้อที่เป็น quiz กดเลือกได้เลย มันเฉลย+อธิบายให้ทันที (ถ้าพลาดจะบอกว่าพลาดตรงไหน)
  3. ไล่ ง่าย → ยาก ปิดท้ายด้วยข้อ BOSS ที่รวมทุกทักษะไว้ในข้อเดียว
  4. จดไว้ว่าข้อไหน "ต้องเปิดเฉลยถึงทำได้" — พวกนั้นคือจุดที่ยังไม่แน่น บอกหนูมาได้เลย
กฎที่จะใช้ตลอดบท (แปะไว้ให้เหลือบดู)
  • N qubit → 2ᴺ วง · วง |k⟩ = เขียน k เป็นเลขฐานสอง (ขวาสุด = 0x1)
  • operator pairs ของ 0xW = จับคู่วงที่ค่าต่างกัน W พอดี · วงซ้าย = บิตนั้น 0 · วงขวา = บิตนั้น 1
  • NOT สลับวงในทุกคู่ (ขยับของ) · PHASE หมุนเฉพาะวงขวาของทุกคู่ (ไม่ขยับของ)
  • READ: P(0)=Σ magnitude²ฝั่งซ้าย, P(1)=Σฝั่งขวา → ลบวงที่ขัดผล → renormalize ให้รวม 100%
เซ็ต 1 · อุ่นเครื่อง

นับวง & อ่านค่าวงเป็นเลขฐานสอง

ข้อ 1ง่าย

register 6 qubit ต้องวาดวงกลมกี่วงใน circle notation? แล้ว register กี่ qubit ถึงจะได้ 256 วง?

ดูเฉลย

6 qubit → 2⁶ = 64 วง · และ 256 = 2⁸ → 8 qubit (ก็คือ 1 qubyte พอดี)

กับดัก: อย่าเผลอตอบ "6×2 = 12" กติกาคือ 2ᴺ ไม่ใช่ 2×N — หนึ่งวง = หนึ่งค่าที่ READ ออกมาได้

ข้อ 2ง่าย

ใน register 6 qubit วง |42⟩ แทนเลขฐานสองอะไร? และในเลขนั้น qubit ตัวไหนบ้าง (บอกเป็นชื่อ hex) ที่มีค่าเป็น 1?

ดูเฉลย

42 = 32+8+2 → 101010 (6 บิต)

0x20=10x10=00x8=10x4=00x2=10x1=0

qubit ที่เป็น 1 คือ 0x2, 0x8, 0x20 (2+8+32 = 42 ✓)

ข้อ 3 (ง่าย) — ใน register 5 qubit เลข 19 เขียนเป็นวง |19⟩ ตรงกับเลขฐานสองข้อใด?
ถูกต้องค่ะ! 19 = 16+2+1 = 0x10 + 0x2 + 0x1 → 10011 (บิตขวาสุด 0x1 = 1, ถัดมา 0x2 = 1, บิตซ้ายสุด 0x10 = 1) เช็คกลับ: 16+2+1 = 19 ✓
ยังไม่ใช่ค่ะ — แตกน้ำหนักบิตดู: 19 = 16+2+1 = 0x10+0x2+0x1 เขียนจากซ้าย(0x10)ไปขวา(0x1) ได้ 10011 อย่าลืมว่าบิตขวาสุดคือ 0x1 เสมอ
เซ็ต 2 · หัวใจของบท

จับ operator pairs ให้คล่อง

ข้อ 4ปานกลาง

register 3 qubit (8 วง) ถ้ายิง gate ใส่ qubit 0x4 — จับคู่วงได้กี่คู่ และคู่ไหนบ้าง? (บอกให้ครบ พร้อมระบุว่าวงไหนคือ "วงขวา")

ดูเฉลย

0x4 → น้ำหนัก 4 → จับวงที่ค่าต่างกัน 4: (0,4) (1,5) (2,6) (3,7) → 4 คู่

วงขวา (บิต 0x4 = 1) คือ 4, 5, 6, 7 — ก็คือครึ่งหลังของแถวพอดี (8 วงจับได้ 4 คู่เสมอ ไม่ว่ายิงตัวไหน)

ข้อ 5ปานกลาง

ขยับสเกลขึ้น: register 4 qubit (16 วง) ยิงใส่ qubit 0x8 จะได้กี่คู่? และวงขวาของแต่ละคู่คือวงไหนบ้าง?

ดูเฉลย

16 วง → ได้ 8 คู่ เสมอ (ครึ่งหนึ่งของจำนวนวง)

น้ำหนัก 8 → คู่คือ (0,8)(1,9)(2,10)(3,11)(4,12)(5,13)(6,14)(7,15)

วงขวา (บิต 0x8 = 1) = 8, 9, 10, 11, 12, 13, 14, 15 — คือครึ่งบนของเลขที่มากกว่าหรือเท่ากับ 8 นั่นเอง

เซ็ต 3 · ประโยคออกสอบ

product state หรือ entangled?

เคล็ดตัดสินเร็ว

มองว่าเซตของวงที่ "มีของ" (magnitude > 0) เป็นตารางของบิตได้ไหม — ถ้าแต่ละบิต "เลือกอิสระ" ได้ (0 หรือ 1) โดยไม่บังคับกัน → product (แยกได้) ถ้าบิตไหน "ล็อกกัน" (ต้องตรง/ต้องต่าง) → entangled (แยกไม่ได้)

ข้อ 6ปานกลาง

3 qubit สถานะมีของเท่าๆ กันที่วง |0⟩ |1⟩ |4⟩ |5⟩ (ที่เหลือว่าง) เป็น product หรือ entangled? ถ้า product ให้บอกด้วยว่าแต่ละ qubit อยู่สถานะไหน

ดูเฉลย

เขียนเป็นเลขฐานสอง: 000, 001, 100, 101 — ไล่ดูทีละบิต:

0x1 : 0 หรือ 1 (อิสระ)0x2 : 0 เสมอ0x4 : 0 หรือ 1 (อิสระ)

product ค่ะ — 0x1 อยู่ superposition, 0x4 อยู่ superposition, ส่วน 0x2 นิ่งที่ |0⟩ → สร้างได้ด้วย HAD ใส่ 0x1 กับ 0x4 (ไม่มีบิตไหนบังคับกันเลย)

ข้อ 7ยาก

3 qubit สถานะมีของเท่าๆ กันที่วง |0⟩ |3⟩ |5⟩ |6⟩ (ก็คือ 000, 011, 101, 110) — อันนี้ product หรือ entangled? ลองพิสูจน์ให้ตัวเองดู

ดูเฉลย

ทั้งสามบิต "ขยับหมด" (ไม่มีตัวไหนคงที่) → ถ้าจะเป็น product แท้ๆ ที่ทุกบิตอิสระ ต้องมีของครบ 2×2×2 = 8 วง แต่นี่มีแค่ 4 → ไม่ใช่ตารางเต็ม → entangled

ดูให้ลึกอีกนิด: 000, 011, 101, 110 คือเลขที่ "จำนวน 1 เป็นเลขคู่" ทุกตัว (even parity) — พูดอีกอย่างคือ "บิตที่สาม = XOR ของสองบิตแรก" นี่คือความสัมพันธ์ที่ล็อกกันไว้ การสุ่มอิสระของแต่ละ qubit ทำไม่ได้ → พัวพันกันทั้งระบบ (ญาติของ GHZ นั่นเอง)

ข้อ 8 (ปานกลาง) — ประโยคใดต่อไปนี้ ถูกต้อง ที่สุด?
ใช่เลยค่ะ! superposition = สมบัติ qubit เดี่ยว (HAD ตัวเดียวก็สร้างได้) แต่ entanglement = สมบัติทั้งระบบ ต้องมี gate ข้าม qubit (CNOT บทถัดไป) — single-qubit gate ล้วนๆ ทำไม่ได้
ยังไม่ใช่ค่ะ — ที่ถูกคือ "single-qubit gate สร้าง superposition ได้ แต่ entanglement ไม่ได้" (สลับคำ superposition/entanglement กันอยู่ในตัวเลือกอื่น) และของครบทุกวงเท่าๆ กัน = product เต็มขั้น ไม่ใช่พัวพัน
เซ็ต 4 · ลงมือกับ gate

NOT — สลับวงในทุกคู่

ข้อ 9ปานกลาง

register 3 qubit เริ่มที่วง |5⟩ เต็ม 100% (ที่เหลือว่าง) แล้วยิง NOT ใส่ 0x2 — ผลลัพธ์ของไปอยู่วงไหน?

ดูเฉลย
1) น้ำหนัก 2 → คู่คือ (0,2)(1,3)(4,6)(5,7)
2) |5⟩ จับคู่กับ |7⟩ → NOT สลับ → ของย้ายไป |7⟩
เช็ค 5 = 101, พลิกบิต 0x2 (บิตกลาง): 101 → 111 = 7 ✓
ข้อ 10ยาก

register 3 qubit สถานะ (|0⟩ + |3⟩)/√2 (000 กับ 011 อย่างละ 50%) ยิง NOT ใส่ 0x4 — ได้สถานะอะไร? แล้วสถานะใหม่ยัง entangled อยู่ไหม?

ดูเฉลย
1) น้ำหนัก 4 → คู่ (0,4)(1,5)(2,6)(3,7)
2) |0⟩→|4⟩ · |3⟩→|7⟩ → ได้ (|4⟩ + |7⟩)/√2 = (100 + 111)/√2
3) 100 กับ 111: บิต 0x4 = 1 ทั้งคู่ (คงที่) แต่บิต 0x1,0x2 ต้องตรงกัน (00 หรือ 11) → ยัง ล็อกกัน

ยัง entangled ค่ะ — NOT แค่ "ขยับของ" ทั้งก้อน ไม่ได้แก้ความสัมพันธ์ระหว่าง qubit สถานะพัวพันจึงยังพัวพันอยู่ (single-qubit gate ทำลาย entanglement ไม่ได้ เหมือนสร้างไม่ได้)

เซ็ต 5 · gate ที่ไม่ขยับของ

PHASE — หมุนเฉพาะวงขวา

ข้อ 11 (ปานกลาง) — register 3 qubit ยิง PHASE(180) ใส่ 0x4 วงไหน "ถูกหมุน"?
ถูกต้องค่ะ! คู่ของ 0x4 คือ (0,4)(1,5)(2,6)(3,7) → วงขวา = 4,5,6,7 = เลขที่บิต 0x4 เป็น 1 (100–111) พอดี และเป็นครึ่งหนึ่งของทั้งหมดตามกฎ
ยังไม่ใช่ค่ะ — PHASE หมุน "วงขวาของทุกคู่" = ทุกสถานะที่บิตนั้นเป็น 1 ของ 0x4 คู่คือ (0,4)(1,5)(2,6)(3,7) → วงขวาคือ |4⟩|5⟩|6⟩|7⟩ (|1⟩|3⟩|5⟩|7⟩ จะโดนก็ต่อเมื่อยิง 0x1)
ข้อ 12ยาก · กับดัก

register 2 qubit สถานะ 4 วงเท่าๆ กัน (อย่างละ 25%) ยิง PHASE(180) ใส่ 0x1 แล้ว READ 0x1 ทันที — โอกาสอ่านได้ 0 เท่ากับกี่เปอร์เซ็นต์? (คิดให้ดีก่อนตอบ!)

ดูเฉลย

PHASE หมุนวง |1⟩,|3⟩ ไป 180° — แต่ ไม่ขยับของ magnitude ทุกวงยัง 25% เท่าเดิม!

READ 0x1: คู่ (0,1)(2,3) · วงซ้าย |0⟩,|2⟩ · P(0) = 25% + 25% = 50%

💡 กับดักคือ PHASE ไม่เปลี่ยนโอกาสวัดทันทีเลย (มันไปออกฤทธิ์ตอน interference ทีหลังเท่านั้น) ถ้าใครตอบ 0% หรือ 100% แสดงว่าเผลอคิดว่า phase = magnitude

เซ็ต 6 · วัดแล้วยุบ

READ + collapse + renormalize

ข้อ 13ปานกลาง

register 2 qubit 4 วงเท่าๆ กัน (อย่างละ 25%) ยิง READ 0x2 (ก) P(0) กับ P(1) เท่าไร? (ข) ถ้าผลออกมาเป็น 1 เหลือสถานะอะไร?

ดูเฉลย
คู่ 0x2 → (0,2)(1,3) · วงซ้าย |0⟩,|1⟩ · วงขวา |2⟩,|3⟩
ก) P(0)=25+25=50% · P(1)=25+25=50%
ข) ผล 1 → ลบวงซ้าย (|0⟩,|1⟩) ทิ้ง เหลือ |2⟩,|3⟩ อย่างละ 25%
→ renormalize 25/25 ให้รวมเป็น 100% → |2⟩ = 50%, |3⟩ = 50%

qubit 0x1 ยังอยู่ใน superposition สบายๆ — READ ตัวเดียวตัดแค่ครึ่ง ไม่ล้มทั้ง register

ข้อ 14ยาก · ของโปรด

register 2 qubit สถานะ Bell (|0⟩ + |3⟩)/√2 (00 กับ 11 อย่างละ 50%) ยิง READ 0x1 ได้ผล 0 — แล้วถ้ายิง READ 0x2 ต่อ ผลจะเป็นอะไร? มั่นใจแค่ไหน?

ดูเฉลย
READ 0x1 คู่ (0,1)(2,3) · ซ้าย |0⟩,|2⟩ = 50%+0% · ขวา |1⟩,|3⟩ = 0%+50%
ผล 0 → ลบ |1⟩,|3⟩ เหลือ |0⟩ (50%) กับ |2⟩ (0%) → renormalize → |0⟩ = 100%
READ 0x2 ตอนนี้มีแต่ |0⟩ = 00 → บิต 0x2 เป็น 0 แน่นอน → ได้ 0, 100% ชัวร์

💥 นี่คือหน้าตาของ entanglement: อ่าน qubit แรกได้ 0 ปุ๊บ qubit ที่สองถูกกำหนดทันที ให้เป็น 0 ด้วย (ตรงกันเสมอ) — ความสัมพันธ์นี้เก็บอยู่ที่ระดับทั้งระบบ ไม่ใช่ที่ qubit ตัวใดตัวหนึ่ง (เดี๋ยวบท 0009 จะเห็นว่า CNOT สร้าง Bell pair แบบนี้ได้ยังไง)

ข้อ BOSS 🐉

รวมทุกทักษะในข้อเดียว — ค่อยๆ ไล่ทีละสเต็ป

BOSSยากสุด

register 3 qubit เริ่มที่ |0⟩ (000) ทั้งหมด แล้วทำตามลำดับนี้:

① HAD 0x1② HAD 0x2③ NOT 0x4④ PHASE(180) 0x2⑤ READ 0x1 → ได้ 1

คำถาม: หลังจบสเต็ป ⑤ เหลือวงไหนบ้าง วงละกี่ % และวงไหนมี phase 180°? (ลองไล่ทีละสเต็ปในกระดาษก่อน แล้วค่อยเทียบ)

ดูเฉลยแบบไล่ทีละสเต็ป
① HAD 0x1: |0⟩,|1⟩ อย่างละ 50%
② HAD 0x2: กระจายเป็น |0⟩|1⟩|2⟩|3⟩ อย่างละ 25% (000,001,010,011 — บิต 0x4 ยังเป็น 0)
③ NOT 0x4: คู่ (0,4)(1,5)(2,6)(3,7) → ของทั้งหมดขยับ +4 → |4⟩|5⟩|6⟩|7⟩ อย่างละ 25%
④ PHASE(180) 0x2: คู่ (0,2)(1,3)(4,6)(5,7) → วงขวา = |2⟩|3⟩|6⟩|7⟩ มีของแค่ |6⟩,|7⟩ → หมุน 180° (magnitude เท่าเดิม 25%)
⑤ READ 0x1: คู่ (0,1)(2,3)(4,5)(6,7) · ซ้าย |4⟩,|6⟩ = 50% · ขวา |5⟩,|7⟩ = 50% → ผล 1 → ลบ |4⟩,|6⟩ เหลือ |5⟩,|7⟩ อย่างละ 25% → renormalize

คำตอบ: เหลือ |5⟩ = 50% และ |7⟩ = 50% · วงที่มี phase 180° คือ |7⟩ (ติดมาจากสเต็ป ④)

🎓 จุดที่ข้อนี้เช็ค: (1) NOT ขยับของทั้งก้อน (2) PHASE หมุนแต่ไม่ขยับ + phase ติดตัววงไปด้วย (3) phase 180° ที่ |7⟩ ไม่มีผลต่อ P ตอน READ เลย (magnitude เท่าเดิม) (4) collapse + renormalize 25/25 → 50/50 — ถ้าได้ครบทุกจุดนี้ ถือว่าเก่งบท 0008 แล้วค่ะ! 🎉

🧠 ทบทวนเร็วจากความจำ (ปิดจอ พูดออกมาดังๆ ก่อนเปิดดู)
  1. register 7 qubit ใช้กี่วง? แล้ว |100⟩ ในนั้นเขียนเป็นเลขฐานสองว่าอะไร?
  2. ยิงใส่ 0x8 ใน register 4 qubit ได้กี่คู่ วงขวาเริ่มจากวงไหน?
  3. NOT ต่างจาก PHASE ยังไง — อันไหน "ขยับของ" อันไหน "ไม่ขยับ"?
  4. PHASE 180° ที่วงหนึ่ง เปลี่ยนโอกาส READ ของวงนั้น "ทันที" ไหม?
  5. หลัง READ แล้วเหลือวง 25/25 ต้องทำอะไรต่อ (คำเดียว) แล้วได้เท่าไร?

เฉลยย่อ: 1) 128 วง, 100 = 1100100   2) 8 คู่, วงขวาเริ่มที่ |8⟩   3) NOT ขยับของ (สลับวง) / PHASE ไม่ขยับ (หมุนวงขวา)   4) ไม่ทันที (magnitude เท่าเดิม)   5) renormalize → 50/50
