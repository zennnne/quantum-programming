Lesson 05 · QPU Instructions

HAD (Hadamard) — คำสั่งที่สร้าง superposition จริงๆ และความลับของ "เครื่องหมายลบ"

บทที่แล้วเราเจอ NOT / WRITE / READ ที่ยัง "เดาผลได้" อยู่ บทนี้คือ ก้าวแรกเข้าสู่ความควอนตัมของจริง — HAD เป็น gate ที่ ไม่มีคู่ในโลกคลาสสิก มันหยิบ qubit ที่แน่นอน (|0⟩ หรือ |1⟩) แล้วโยนเข้าสู่ superposition 50/50 ที่เราค้างไว้ตั้งแต่บท 3 และนี่คือบทแรกที่ "เลขจริง" จะโผล่ออกมา — หนูจะแทรก refresher คณิตให้ตรงจุดที่ต้องใช้ค่ะ

บทนี้ยาวหน่อย — จับหลักไว้ 3 อย่างพอ

เนื้อหา slide 34–47 อัดมาในบทเดียวตามที่พี่เลือก แต่ถ้าจำได้แค่ 3 อย่างนี้ก็ถือว่าได้แก่นแล้ว: (1) HAD เปลี่ยนสถานะแน่นอน → superposition เท่าๆ กัน (2) H|1⟩ มีเครื่องหมายลบ ต่างจาก H|0⟩ (3) เครื่องหมายลบนั้น ไม่ใช่ของประดับ — มันคือหัวใจที่ทำให้ควอนตัมทำงานได้ มี checkpoint แทรกกลางทางเป็นระยะ ค่อยๆ ไปนะคะ

1. HAD ทำอะไร? — จากเข็มเดียว สู่ "ครึ่งๆ"

ทวนจากบท 3: circle notation วาด qubit เป็นวงกลม โดย พื้นที่ทึบ = โอกาสวัดได้ค่านั้น (magnitude²) และ ทิศเข็ม = phase เดิมทีถ้า qubit เป็น |0⟩ แน่นอน วง |0⟩ ก็ทึบเต็ม วง |1⟩ ว่างเปล่า

HAD (ย่อจาก Hadamard อ่านว่า "ฮาดามาร์ด") ทำสิ่งเดียว: ทำให้ วง |0⟩ และ |1⟩ ทึบเท่ากันพอดี (ครึ่งๆ) → วัดแล้วมีโอกาสได้ 0 หรือ 1 เท่ากัน 50/50 นี่แหละคือ "superposition แบบสม่ำเสมอ (uniform superposition)"

แต่มีจุดพลิกสำคัญ: HAD กระทำกับ |0⟩ กับ |1⟩ ออกมา ไม่เหมือนกันเป๊ะ — ดูที่ ทิศเข็ม (phase) ของวง |1⟩:

input: |0⟩ แน่นอน
—[H]→
ทึบครึ่งเท่ากัน · เข็มชี้ขึ้นทั้งคู่
input: |1⟩ แน่นอน
—[H]→
ทึบครึ่งเท่ากัน · วง |1⟩ เข็มชี้ลง!
จุดสังเกตหัวใจของบท

ทั้งสองกรณี "โอกาสวัดได้ 0 หรือ 1" เท่ากันหมด (พื้นที่ทึบเท่ากัน) — ถ้าดูแค่ความน่าจะเป็น มันเหมือนกันเป๊ะ ต่างกันแค่ เข็มของวง |1⟩: มาจาก |0⟩ เข็มชี้ขึ้น, มาจาก |1⟩ เข็มชี้ลง (relative phase = 180°) เจ้า "เข็มชี้ลง" นี้แหละที่ภาษาเลขเรียกว่า เครื่องหมายลบ — ทั้งบทนี้จะวนอยู่รอบมัน

2. เขียนเป็นสูตร — และ √2 มาจากไหน

สิ่งที่เห็นในวงกลม เขียนเป็นสมการได้แบบนี้ (นี่คือสองสูตรที่ควรจำได้ขึ้นใจ):

H|0⟩ = |0⟩ + |1⟩√2
H|1⟩ = |0⟩ − |1⟩√2

เห็นไหมคะว่าต่างกัน แค่เครื่องหมายกลางวงเล็บ — บวกกับลบ นั่นคือ "เข็มชี้ขึ้น vs ชี้ลง" ในภาพเมื่อกี้เป๊ะๆ

Refresher: ทำไมต้องหารด้วย √2 (ไม่ใช่ 2)?

กฎเหล็กของ qubit (จากบท 3): เอา magnitude ของทุกช่องมายกกำลังสอง แล้วบวกกันต้องได้ 1 พอดี (โอกาสรวมทั้งหมด = 100%) ลองเช็คสูตร H|0⟩ ที่ทั้งสองช่องมีค่า 1/√2:

( 1√2 )² + ( 1√2 )² = 12 + 12 = 1 ✓

ถ้าหารด้วย 2 เฉยๆ จะได้ (1/2)² + (1/2)² = 1/4 + 1/4 = 1/2 ≠ 1 → ผิดกฎ! เจ้า √2 มีไว้ "ปรับสเกล" ให้โอกาสรวมเป็น 1 พอดี เราเรียกขั้นตอนนี้ว่า normalization (การทำให้เป็นบรรทัดฐาน) เจอบ่อยมากทั้งวิชา

✅ Checkpoint 1: ถ้าวัด (READ) qubit ที่อยู่ในสถานะ H|1⟩ = (|0⟩ − |1⟩)/√2 โอกาสได้ผลเป็น "1" คือเท่าไหร่?
เป๊ะค่ะ! magnitude ของช่อง |1⟩ คือ 1/√2 → ยกกำลังสอง = 1/2 = 50% เครื่องหมายลบ (phase) ไม่มีผลต่อโอกาสวัด เลย (ทวนจากบท 4: phase ไม่กระทบ READ)
ระวังกับดัก! เครื่องหมายลบคือ phase ซึ่ง ไม่กระทบความน่าจะเป็น โอกาส = magnitude² = (1/√2)² = 1/2 = 50% ค่ะ

3. HAD ในรูป matrix + ลองคูณให้เห็นกับตา

gate ทุกตัวเขียนเป็น matrix (เมทริกซ์) ได้ และการ "ทำ gate กับ qubit" ก็คือ เอา matrix คูณกับ vector ของ qubit matrix ของ Hadamard คือตัวที่ง่ายที่สุดที่สร้าง superposition ได้:

H = 1√2 111−1
Refresher: คูณ matrix 2×2 กับ vector ยังไง

qubit เขียนเป็น vector 2 แถว: |0⟩ = [1, 0] (บน=1 ล่าง=0) และ |1⟩ = [0, 1] การคูณ: เอาแต่ละแถวของ matrix ไป "จับคู่คูณแล้วบวก" กับ vector

abcd xy = a·x + b·yc·x + d·y

ลองกับ |0⟩ = [1, 0]:

= 1√2 111−1 10
= 1√2 1·1 + 1·01·1 + (−1)·0 = 1√2 11 = |0⟩ + |1⟩√2
➢ ทั้งสองช่องเป็น +1 → ไม่มีเครื่องหมายลบ ✓ (ตรงกับภาพเข็มชี้ขึ้นทั้งคู่)

ลองกับ |1⟩ = [0, 1]:

= 1√2 111−1 01
= 1√2 1·0 + 1·11·0 + (−1)·1 = 1√2 1−1 = |0⟩ − |1⟩√2
➢ ช่องล่างได้ −1 → เครื่องหมายลบโผล่! (phase = 180° = เข็มชี้ลง)
เชื่อมภาพเข้าหากัน

เห็นไหมคะว่า "เข็มชี้ลงของวง |1⟩" ในภาพ = "−1 ในช่องล่างของ vector" = "เครื่องหมายลบในสูตร" ทั้งสามอย่างคือเรื่องเดียวกัน เล่าคนละภาษา (รูป / เลข / สมการ) พอเห็นว่ามันคือสิ่งเดียวกัน HAD จะไม่น่ากลัวอีกเลยค่ะ

4. ทำไม "ต้อง" มีเครื่องหมายลบ? — 3 เหตุผล

คำถามที่อาจารย์ชอบถาม: ทำไม H|1⟩ ต้องเป็น (|0⟩ − |1⟩)/√2 ทำไมไม่ใช้บวกให้เหมือน H|0⟩ ไปเลย? slide ให้ 3 เหตุผล — จำเป็น ทั้งสามข้อ ไม่ใช่ของประดับ:

1. คงความตั้งฉากorthogonality — |0⟩ กับ |1⟩ ต้อง "แยกจากกันได้" ผลลัพธ์ก็ต้องแยกกันได้ด้วย
2. ย้อนกลับได้reversibility — ทำให้ H เป็นตัวย้อนของตัวเอง (ทำสองที = กลับที่เดิม)
3. เกิด interferenceการแทรกสอด — เปิดทางให้ amplitude "หักล้าง/เสริม" กันได้ หัวใจของอัลกอริทึมควอนตัม

เหตุผล 1 — คงความตั้งฉาก (orthogonality)

Refresher: "ตั้งฉาก" ในภาษา qubit คืออะไร

สองสถานะ "ตั้งฉาก (orthogonal)" แปลว่า แยกจากกันได้สนิท 100% — ถ้าเป็นอันหนึ่งแน่ๆ ก็ไม่มีทางเป็นอีกอันเลย วัดด้วยเครื่องมือชื่อ inner product (ผลคูณภายใน) เขียน ⟨a|b⟩ ถ้าได้ 0 = ตั้งฉากสนิท พื้นฐาน |0⟩ กับ |1⟩ ตั้งฉากกันอยู่แล้ว: ⟨0|1⟩ = 0 (กติกาที่ใช้: ⟨0|0⟩ = ⟨1|1⟩ = 1 ส่วน ⟨0|1⟩ = ⟨1|0⟩ = 0)

gate ควอนตัมที่ดี ต้องรักษาความตั้งฉากไว้ ลองเช็ค inner product ของผลลัพธ์ H|0⟩ กับ H|1⟩:

⟨H0 | H1⟩ = 12 ( ⟨0|0⟩ − ⟨0|1⟩ + ⟨1|0⟩ − ⟨1|1⟩ )
= 12 ( 1 − 0 + 0 − 1 ) = 12 ( 0 ) = 0 ✓ ตั้งฉาก!
➢ ถ้าใช้ บวก ทั้งคู่: จะได้ (1 + 0 + 0 + 1)/2 = 1 ≠ 0 → ไม่ตั้งฉาก → ผิดกฎ gate!

เหตุผล 2 — ย้อนกลับได้ (H เป็นตัวย้อนของตัวเอง)

ทวนจากบท 4: gate ควอนตัมแท้ๆ ต้อง reversible Hadamard เป็นแบบพิเศษ — เป็น ตัวย้อนของตัวเอง เหมือน NOT คือทำ H สองครั้ง qubit กลับสถานะเดิมเป๊ะ (H H |ψ⟩ = |ψ⟩)

ลองคิดแบบขัดแย้ง (ทำไมบวกถึงพัง)

สมมติ (ผิด) ว่า H|1⟩ = (|0⟩ + |1⟩)/√2 เหมือน H|0⟩ เป๊ะ → แปลว่า H|0⟩ กับ H|1⟩ กลายเป็น สถานะเดียวกัน ถ้าอย่างนั้น พอเราทำ H ซ้ำเพื่อย้อนกลับ เราจะ แยกไม่ออกว่าเดิมมาจาก |0⟩ หรือ |1⟩ → ย้อนกลับไม่ได้ → ผิดกฎ reversibility เครื่องหมายลบคือสิ่งเดียวที่ทำให้ H|0⟩ ≠ H|1⟩ จึงย้อนกลับได้

เหตุผล 3 — เปิดทางให้ interference (การแทรกสอด)

อันนี้คือเหตุผลที่ "ควอนตัมถึงเจ๋ง" เพราะมีทั้งบวกและลบ amplitude จึง หักล้างกันได้ เหมือนคลื่นน้ำสองลูกที่ยอดชนท้องแล้วราบไป ลองบวกสองสถานะ:

|0⟩ + |1⟩√2 + |0⟩ − |1⟩√2 = 2|0⟩√2 = √2 |0⟩
➢ ช่อง |1⟩ หักล้างกันหายเกลี้ยง (+|1⟩ กับ −|1⟩ ลบกัน) เหลือแต่ |0⟩!

การที่ amplitude หักล้าง/เสริมกันแบบนี้แหละที่ทำให้อัลกอริทึมดังๆ อย่าง Grover และ Shor เป็นไปได้ (เราจะเจอปลายคอร์ส) — ถ้าไม่มีเครื่องหมายลบ ก็ไม่มีการหักล้าง ก็ไม่มีความได้เปรียบเชิงควอนตัม

✅ Checkpoint 2: เหตุผลข้อไหน อธิบายผิด ว่าทำไม H|1⟩ ต้องมีเครื่องหมายลบ?
ใช่ค่ะ ข้อนี้ผิด! เครื่องหมายลบคือ phase ซึ่ง ไม่กระทบโอกาสวัด เลย (ยังคง 50/50) อีกสามข้อคือเหตุผลจริงทั้งหมด
ทบทวนนะ — เครื่องหมายลบเป็น phase ไม่เปลี่ยนความน่าจะเป็น (ข้อที่บอกว่า "วัดได้ |1⟩ มากกว่า" จึงเป็นข้อที่ผิด) ส่วน reversibility / orthogonality / interference คือเหตุผลจริง

5. HAD กับ qubit ที่อยู่ใน superposition อยู่แล้ว (worked example)

ถ้า qubit ไม่ได้เป็น |0⟩ หรือ |1⟩ เป๊ะ แต่เป็น superposition อยู่แล้วล่ะ? หลักการง่ายมาก: HAD ทำกับแต่ละส่วนแยกกัน แล้วถ่วงน้ำหนักด้วย amplitude เดิม ลองกับ |ψ⟩ = 0.6|0⟩ + 0.8|1⟩ (เช็คก่อน: 0.6² + 0.8² = 0.36 + 0.64 = 1 ✓ ถูกกฎ)

= H(0.6|0⟩ + 0.8|1⟩) = 0.6·H|0⟩ + 0.8·H|1⟩
= 0.6 |0⟩ + |1⟩√2 + 0.8 |0⟩ − |1⟩√2
= (0.6 + 0.8)|0⟩ + (0.6 − 0.8)|1⟩√2
= 1.4|0⟩ − 0.2|1⟩√2

เห็นพลังของบวก/ลบชัดๆ: ช่อง |0⟩ ถูก เสริม (0.6+0.8 = 1.4 ใหญ่ขึ้น) ส่วนช่อง |1⟩ ถูก หักล้าง (0.6−0.8 = −0.2 เล็กลง) → นี่คือ interference ในตัวอย่างจริง หลัง HAD โอกาสวัดได้ 0 มากกว่า 1 เยอะเลย

6. Reversibility: ทำ HAD สองที = ไม่ได้ทำ

เหมือน NOT ในบทที่แล้วเป๊ะ — HAD เป็นตัวย้อนของตัวเอง (its own inverse) ทำ HAD สองครั้งติดกัน qubit กลับสถานะเดิม จำง่ายๆ: superposition ที่ HAD สร้าง ถ้าโดน HAD อีกที มันจะ "หักล้างตัวเอง" กลับไปเป็น |0⟩ หรือ |1⟩ เดิม (เหตุผลข้อ 2 กับ 3 รวมกันพอดี)

กันสับสน: HAD ย้อนได้ ≠ READ ย้อนได้

อย่าปนกันนะคะ — HAD reversible (ทำซ้ำได้ของเดิม) แต่ READ ยัง irreversible เสมอ ถ้าเผลอ READ ตรงกลางไป superposition ก็ยุบทิ้ง ทำ HAD ย้อนกลับไม่ได้แล้ว การ "หวง READ ไว้ท้ายสุด" จากบท 4 จึงยังใช้อยู่

7. หน้าตาในวงจร — สัญลักษณ์ [H] (ออกสอบ!)

ในวงจร HAD วาดเป็น กล่องสี่เหลี่ยมมีตัว H อยู่ข้างใน วางบนเส้น qubit ตามปกติ (ยืนยันจาก slide 34/35 แล้ว — สไตล์ QCEngine/O'Reilly)

HAD (H)

ตัวอย่างวงจรที่จะเจอบ่อยสุด (บทหน้าเราจะเอาไปทำ QRNG — เครื่องสุ่มควอนตัมของจริง):

WRITE |0⟩ → [H] → READ  =  วัดได้ 0 หรือ 1 อย่างละ 50%
อัปเดต Cheat Sheet แล้ว

หนูย้าย [H] จากช่อง "จะเรียนทีหลัง" ไปอยู่ช่อง "เรียนแล้ว" ใน 📐 Cheat Sheet วงจร เรียบร้อย ตอนนี้พี่ท่องได้ 4 สัญลักษณ์แล้ว (WRITE, NOT, READ, HAD) พิมพ์ออกมาท่องก่อนสอบได้เลยค่ะ

8. ลองรันจริงใน QCEngine 🖥️

อย่าเพิ่งเชื่อหนู — ลองเองดีที่สุดค่ะ เปิด oreilly-qc.github.io แล้วพิมพ์โค้ดสั้นๆ นี้ (นี่คือวงจร WRITE→H→READ ข้างบนเป๊ะ):

qc.reset(1);  // เตรียม 1 qubit เป็น |0⟩
qc.write(0);  // WRITE ให้เป็น |0⟩
qc.had();    // [H] → superposition 50/50
qc.read();   // READ → ได้ 0 หรือ 1 สุ่ม

จ้องที่ circle notation ของ QCEngine หลังบรรทัด qc.had() — จะเห็นวงกลมสองวงทึบครึ่งเท่ากันตรงกับภาพในบทนี้ ลองกดรันซ้ำหลายๆ ที ดูว่าผล READ สลับ 0/1 มั่วจริงไหม (นี่แหละคือ QRNG ที่เราจะเจาะลึกบทหน้า!)

เช็คความเข้าใจ (รอบใหญ่)

1. HAD ต่างจาก NOT อย่างไร ตรงจุดที่สำคัญที่สุด?
ใช่เลยค่ะ! NOT มีคู่ในโลกคลาสสิก (แค่สลับค่า) แต่ HAD สร้าง superposition 50/50 ซึ่ง ไม่มีอะไรเทียบในคอมธรรมดา — นี่คือ "ประตู" เข้าสู่ควอนตัมจริงๆ
ทั้งคู่ reversible เหมือนกัน จุดต่างหัวใจคือ HAD สร้าง superposition ได้ (ไม่มีคู่คลาสสิก) ส่วน NOT แค่สลับ 0↔1
2. ทำ HAD กับ qubit ที่เป็น |0⟩ แล้วตามด้วย HAD อีกครั้งหนึ่ง ผลเป็นอย่างไร?
ถูกต้อง! HAD เป็น its own inverse ทำสองที = กลับที่เดิม (superposition ที่สร้างขึ้น ถูก HAD ที่สองหักล้างตัวเองกลับไปเป็น |0⟩)
HAD เป็นตัวย้อนของตัวเอง (เหมือน NOT) → ทำสองที qubit กลับไปเป็น |0⟩ เดิม ไม่ได้ค้างที่ superposition
3. "เครื่องหมายลบ" ใน H|1⟩ = (|0⟩ − |1⟩)/√2 มีผลต่อสิ่งใด?
เป๊ะค่ะ! เครื่องหมายลบ = relative phase ไม่กระทบโอกาสวัด (ยัง 50/50) แต่จำเป็นต่อ orthogonality + reversibility + interference ครบสามเหตุผล
ระวัง — เครื่องหมายลบไม่กระทบความน่าจะเป็น (โอกาสยัง 50/50) แต่ก็ไม่ใช่ของประดับ มันคือ phase ที่จำเป็นต่อ 3 เหตุผลหลัก (ตั้งฉาก/ย้อนได้/interference)
ลองก่อนเปิด: อธิบายด้วยคำพูดตัวเอง — "ทำไม H|1⟩ ต้องมีเครื่องหมายลบ ทั้งที่มันไม่ทำให้โอกาสวัดเปลี่ยนเลย?"

ตัวอย่างคำตอบที่ดี: "เครื่องหมายลบคือ relative phase มันไม่กระทบ magnitude² เลยไม่เปลี่ยนโอกาสวัด (ยัง 50/50) แต่จำเป็นเพราะ (1) ทำให้ H|0⟩ กับ H|1⟩ ตั้งฉากกัน — gate ต้องรักษาความตั้งฉาก (2) ทำให้สองผลลัพธ์ต่างกัน HAD จึงย้อนกลับได้ (its own inverse) และ (3) การมีทั้ง +/− ทำให้ amplitude หักล้าง/เสริมกันได้ = interference ซึ่งเป็นหัวใจของอัลกอริทึมควอนตัม"

นึกเองก่อนเปิดเฉลย (retrieval practice) ช่วยให้จำได้นานกว่าอ่านซ้ำเยอะค่ะ
