Lesson 03 · Amplitude & Phase

Amplitude & Phase — เปิดกล่องที่ค้างไว้: ทำไม qubit ถึง เหนือกว่า เหรียญสุ่มธรรมดา

บทที่แล้วหนูแอบพูดคำแปลกๆ ค้างไว้ว่า amplitude จริงๆ เป็น "จำนวนเชิงซ้อน มีทิศได้" แล้วรีบปิดกล่อง คราวนี้เราจะเปิดมันเบาๆ เพื่อตอบคำถามเดียว: ถ้าวัด qubit ทีได้แค่ 0/1 เหมือนโยนเหรียญ แล้วมันพิเศษกว่าเหรียญตรงไหน? คำตอบอยู่ที่ของที่ซ่อนอยู่ ชื่อ phase

หมายเหตุ: บทนี้ยังไม่มี slide

อาจารย์ลืมอัป slide บทนี้เหมือนบทที่แล้ว หนูเลยปูจาก ตำราหลักของวิชา — "Programming Quantum Computers" (O'Reilly) บทที่ 2 มีหัวข้อ magnitude & relative phase กับ circle notation พอดี — บวกความรู้มาตรฐานทั่วไป พอ slide จริงมาเราค่อยเทียบเพิ่มค่ะ

1. ทวน 20 วินาที: เราค้างอะไรไว้จากบทที่ 2

บทที่แล้วเราเขียน qubit เป็น a·|0⟩ + b·|1⟩ โดย a, b คือ amplitude (แอมพลิจูด, น้ำหนักของสถานะ) และกติกา Born rule บอกว่า:

โอกาสวัดได้ 0 = (ขนาดของ a)²   ·   โอกาสวัดได้ 1 = (ขนาดของ b)²

สังเกตคำว่า "ขนาด" — เราไม่ได้ใช้ตัว amplitude ตรงๆ ในการคิดความน่าจะเป็น เราใช้แค่ ขนาดของมัน นั่นเป็นเบาะแสว่า amplitude มี ข้อมูลมากกว่าแค่ "ขนาด" ซ่อนอยู่ — แล้วส่วนที่ Born rule มองข้ามไปนั้นแหละ คือพระเอกของบทนี้

2. amplitude มีสองส่วน: magnitude + phase

วิธีคิด amplitude ที่ง่ายที่สุด (และตรงกับที่หนังสือใช้) คือมองมันเป็น เข็มนาฬิกา 1 เข็ม เข็มหนึ่งเล่าได้ 2 อย่างพร้อมกัน:

  • ความยาวของเข็ม = magnitude (แมกนิจูด, ขนาด) → ยาวมาก = โอกาสโผล่มาตอนวัดสูง (นี่คือส่วนที่ Born rule ใช้)
  • ทิศที่เข็มชี้ = phase (เฟส, มุม/ทิศ) → เป็นมุมรอบวง 0°–360° ไม่มีผลต่อโอกาสตอนวัดครั้งเดียวเลย — มันคือของที่ซ่อนอยู่
Refresher จำนวนเชิงซ้อน (แบบ just-in-time พอใช้)

ที่บทก่อนบอกว่า amplitude เป็น จำนวนเชิงซ้อน (complex number) ก็แค่หมายความว่า มันเขียนเป็น "ลูกศรบนระนาบ" ได้ ซึ่งลูกศรมี ความยาว (= magnitude) กับ มุม (= phase) เป๊ะๆ เหมือนเข็มนาฬิกาข้างบน ยังไม่ต้องท่องสูตร a+bi หรือ eiθ ตอนนี้ ขอแค่จำภาพ "ลูกศร = ยาวเท่าไร + ชี้ไปทางไหน" ก็พอค่ะ

3. เห็นภาพด้วย circle notation

Circle notation (สัญกรณ์วงกลม) คือวิธีวาดสถานะที่หนังสือกับ QCEngine ใช้: หนึ่งวงกลม = หนึ่งสถานะพื้นฐาน (|0⟩ วงนึง, |1⟩ อีกวงนึง) ในแต่ละวง:

  • พื้นที่ทึบ ในวง = magnitude² = โอกาสวัดเจอสถานะนั้น (ทึบเต็ม = โอกาสสูง)
  • เข็มที่ชี้ออกจากกลางวง = phase ของสถานะนั้น (ชี้ขึ้น = 0°, หมุนตามเข็มนาฬิกา)
|0⟩
phase = 0° (เข็มชี้ขึ้น)
|1⟩
phase = 90° (เข็มชี้ขวา)

สองวงนี้ พื้นที่ทึบเท่ากัน → วัดครั้งเดียวได้ 0 หรือ 1 โอกาส 50/50 เท่ากันเป๊ะ ต่างกันแค่ ทิศเข็ม (phase) ซึ่งตอนวัดครั้งเดียว มองไม่เห็น

4. ถ้า phase มองไม่เห็น แล้วจะมีไว้ทำไม?

คำถามที่ต้องตอบให้ได้

qubit สองตัวที่ magnitude เท่ากัน (โอกาส 50/50 เหมือนกัน) ต่างกันแค่ phase — ถ้าวัดครั้งเดียวก็เหมือนกันทุกอย่าง งั้น phase มัน ไร้ประโยชน์ รึเปล่า?

ไม่ไร้ประโยชน์เลย — phase จะเผยตัวเมื่อเรา ทำ operation (gate) กับ qubit ก่อนวัด แล้วให้เส้นทางต่างๆ มา "เจอกัน" ปรากฏการณ์ตอนเจอกันเรียกว่า interference (การแทรกสอด) นี่แหละของจริงที่ทำให้ qubit เหนือกว่าเหรียญสุ่ม

amplitude มันคล้าย คลื่น: พอสองเส้นทางมารวมกัน amplitude จะบวกกันแบบลูกศร ทิศ (phase) เป็นตัวตัดสินว่าบวกกันแล้วเสริมหรือหักล้าง:

constructiveเสียง + เสียง เฟสตรงกัน = ดังขึ้น
vs
destructiveหูฟังตัดเสียง: ยิงคลื่นเฟสตรงข้าม = เงียบ

นึกถึง หูฟังตัดเสียงรบกวน (noise-cancelling): มันไม่ได้ "ปิด" เสียง แต่ยิงคลื่นเสียง ที่ phase ตรงข้ามพอดี ออกมาชนกับเสียงรบกวน สองคลื่นหักล้างกันจนเงียบ — นี่คือ destructive interference ตัวเป็นๆ ที่เจอได้ในชีวิตจริง

แก่นของทั้งบท

quantum algorithm เก่งเพราะมันจัด phase ให้ amplitude ของ คำตอบผิดหักล้างกันจนเหลือ ~0 และ คำตอบถูกเสริมกันจนพุ่ง พอวัดจึงมีโอกาสสูงที่จะได้คำตอบถูก — เหรียญสุ่มทำแบบนี้ ไม่ได้ เพราะมันมีแค่ "โอกาส" (magnitude) ไม่มี "ทิศ" (phase) ให้เอามาหักล้างกัน

5. เกร็ดสำคัญ: global phase ไม่นับ, relative phase ต่างหากที่นับ

ถ้าเราหมุน phase ของ ทั้งสถานะพร้อมกันทุกวง เท่าๆ กัน (เรียก global phase, เฟสรวม) — อันนี้ ไม่มีผลอะไรเลย วัดยังไงก็เหมือนเดิม มองข้ามได้

ที่สำคัญจริงคือ relative phase (เฟสสัมพัทธ์) = ความต่างของทิศเข็มระหว่าง |0⟩ กับ |1⟩ ความต่างนี้แหละที่รอดไปมีผลตอน interference เวลาเจอโจทย์/ข้อสอบ ให้โฟกัสที่ "เข็มสองวง ต่างมุมกันเท่าไร" ไม่ใช่ "แต่ละวงชี้ไปทางไหน" เดี่ยวๆ

เช็คความเข้าใจ

1. amplitude ของสถานะหนึ่ง เก็บข้อมูลอะไรบ้าง?
ใช่ค่ะ! เข็มหนึ่งเล่าสองอย่าง: ยาวเท่าไร (magnitude) และชี้ทางไหน (phase)
ยังไม่ใช่นะ — amplitude เหมือนเข็มนาฬิกา บอกทั้ง "ยาวเท่าไร" (magnitude) และ "ชี้ทางไหน" (phase) พร้อมกัน
2. qubit สองตัว magnitude เท่ากันเป๊ะ ต่างกันแค่ phase ถ้าวัดครั้งเดียวจะเป็นยังไง?
ถูกต้อง! การวัดครั้งเดียวใช้แค่ magnitude² phase จึงมองไม่เห็น ต้องรอ interference
ลองนึกภาพสองวงพื้นที่ทึบเท่ากันนะ — วัดครั้งเดียวใช้แค่ magnitude² ผลจึงแยกไม่ออก phase ยังซ่อนอยู่
3. อะไรทำให้ qubit ทำสิ่งที่ "เหรียญสุ่มธรรมดา" ทำไม่ได้?
ใช่เลยค่ะ — phase ทำให้เกิด interference จัดให้คำตอบผิดหักล้าง คำตอบถูกเสริมกัน
ยังไม่ใช่นะ — จุดต่างคือ phase ที่ทำให้ amplitude เสริม/หักล้างกันได้ (interference) เหรียญสุ่มมีแค่โอกาส ไม่มีทิศ
ลองก่อนเปิด: อธิบายด้วยคำพูดตัวเองใน 2–3 ประโยค — phase คืออะไร ทำไมวัดครั้งเดียวไม่เห็น แต่ยังสำคัญ?

ตัวอย่างคำตอบที่ดี: "phase คือ 'ทิศ' ของ amplitude (เหมือนทิศเข็มนาฬิกา) ส่วนความยาวเข็ม คือ magnitude ที่บอกโอกาส การวัดครั้งเดียวใช้แค่ magnitude² (Born rule) เลยมองไม่เห็น phase แต่พอเราทำ gate แล้วให้เส้นทางมารวมกัน phase เป็นตัวตัดสินว่า amplitude เสริมกัน (constructive) หรือหักล้างกัน (destructive) — การจัด interference แบบนี้แหละที่ทำให้ quantum algorithm ดันคำตอบถูกให้เด่นและลบคำตอบผิดทิ้ง"

นึกเองก่อนเปิดเฉลย (retrieval practice) ช่วยให้จำได้นานกว่าการอ่านซ้ำเยอะเลยค่ะ
