Lesson 04 · QPU Instructions

QPU เป็น "เครื่องรันคำสั่ง" — รู้จัก 3 คำสั่งแรก: NOT, WRITE, READ และแนวคิด reversibility

3 บทที่ผ่านมาเราเรียนว่า qubit เก็บอะไร (amplitude = magnitude + phase) แต่ยังไม่เคยลง "มือทำ" อะไรกับมันเลย บทนี้เปลี่ยนจากการ บรรยายสถานะ มาเป็นการ สั่งงาน qubit — เริ่มจากคำสั่งที่ง่ายที่สุด 3 ตัว พร้อมแนวคิดสำคัญที่จะติดตัวไปทั้งวิชา

ข่าวดี: บทนี้มี slide จริงแล้ว!

บทที่ 2–3 อาจารย์ยังไม่อัป slide หนูเลยปูจากตำรา O'Reilly ไปก่อน คราวนี้ slide Lec 02 มาแล้ว และพอเทียบดู — เนื้อหาบท 2–3 ตรงกับ slide หน้า 4–31 พอดี พี่ตามทันแล้วค่ะ 🎉 บทนี้เป็นต้นไป เราอิง slide Lec 02 โดยตรง (หัวข้อ "QPU Instruction")

1. ทำไมต้องมี "คำสั่ง"? — QPU ก็เหมือน CPU

คิดถึง CPU ธรรมดา: มันมี ชุดคำสั่ง (instruction set) เช่น ADD, MOV ที่เอาไปเรียงต่อกันเป็นโปรแกรม QPU ก็เป๊ะแบบเดียวกัน — มี QPU instruction (คำสั่งของ QPU) ที่ทำงานกับ qubit แทน bit ธรรมดา

ถ้า amplitude/phase ที่เราเรียนมาคือ "คำนาม" (สิ่งที่ qubit เป็น) คำสั่งพวกนี้ก็คือ "คำกริยา" (สิ่งที่เราทำกับ qubit) โปรแกรมควอนตัม = เอาคำกริยามาเรียงต่อกันนั่นเอง

ศัพท์: gate = operation = instruction

ในวิชานี้คำว่า gate (เกต, ประตูสัญญาณ), operation, และ instruction หมายถึงสิ่งเดียวกันหมด คือ "คำสั่งหนึ่งคำสั่งที่ทำกับ qubit" หนังสือ/อาจารย์สลับคำใช้ไปมา เจอคำไหนก็ให้นึกถึง "คำกริยาที่กระทำต่อ qubit" เหมือนกันค่ะ

2. NOT — คำสั่งสลับ 0 ↔ 1

NOT คือฝาแฝดควอนตัมของ NOT คลาสสิกที่พี่รู้จักอยู่แล้ว: 0 กลายเป็น 1, 1 กลายเป็น 0 แต่มีของแถมที่ NOT ธรรมดาทำไม่ได้ — มันทำกับ qubit ที่อยู่ใน superposition ได้ด้วย

ใน circle notation เข้าใจง่ายมาก: NOT แค่ สลับพื้นที่ทึบของวง |0⟩ กับ |1⟩ ให้กัน (ของในวง 0 ย้ายไปวง 1 และกลับกัน)

ก่อน: เป็น |0⟩ แน่นอน
— NOT →
หลัง: เป็น |1⟩ แน่นอน
แนวคิดใหม่ที่ 1: NOT เป็น "ตัวย้อนของตัวเอง"

ทำ NOT สองครั้ง qubit กลับมาที่เดิมเป๊ะ (0→1→0) เราเรียกว่า NOT เป็น its own inverse (ตัวย้อนของตัวมันเอง) — จำภาพ "กดสวิตช์ไฟสองที = กลับมาเหมือนเดิม" ก็ได้ค่ะ

3. WRITE — ตั้งค่าเริ่มต้นให้ qubit

ก่อนจะทำอะไรกับ qubit เราต้อง "ตั้งค่าเริ่มต้น" มันก่อน — นี่คือหน้าที่ของ WRITE มันบังคับ qubit ให้เป็น |0⟩ หรือ |1⟩ เหมือนการ set ตัวแปร bit ธรรมดาให้เป็น 0 หรือ 1

จุดสำคัญ 2 อย่าง:

  • WRITE เป็น deterministic (แน่นอน ไม่สุ่ม) — สั่งให้เป็น |0⟩ ก็ได้ |0⟩ เป๊ะทุกครั้ง
  • WRITE ตั้งได้ แค่ค่าพื้นฐาน |0⟩ หรือ |1⟩ เท่านั้น — เตรียม superposition หรือ phase แปลกๆ เองไม่ได้ ถ้าอยากได้ superposition ต้องใช้คำสั่งอื่น (เดี๋ยวเจอ HAD บทหน้า)

4. READ — การวัด (ตัวที่เราเจอแล้ว แต่คราวนี้ให้เป็นทางการ)

READ คือชื่อทางการของ "การวัด (measurement)" ที่เราเรียนไปตั้งแต่บท 2 ทวนสั้นๆ: READ ทำให้ superposition ยุบ (collapse) เหลือ 0 หรือ 1 ค่าเดียว บทนี้เติม 3 จุดที่ต้องเน้น:

  • READ เป็น คำสั่งเดียวในทั้งชุด ที่ผลลัพธ์ สุ่มได้ — คำสั่งอื่นแน่นอนหมด
  • โอกาสได้แต่ละค่า = magnitude² ของ amplitude ฝั่งนั้น (Born rule จากบท 3) — phase ไม่มีผลต่อ READ เลย
  • หลัง READ ได้ 0 → qubit กลายเป็น |0⟩, ได้ 1 → กลายเป็น |1⟩ (วัดซ้ำได้ค่าเดิม) — magnitude กับ phase เดิมหายเกลี้ยง
เกร็ดสอบ: WRITE สร้างจาก READ + NOT ได้

slide โชว์ทริกน่ารัก: ถ้าอยากบังคับ qubit ให้เป็น |0⟩ ก็ READ มันก่อน (ได้ 0 หรือ 1 มั่วๆ) ถ้าบังเอิญได้ค่าไม่ตรงที่อยากได้ ก็ NOT พลิกซะ — จบ ได้ค่าที่ต้องการเป๊ะ นี่แสดงว่า คำสั่งพื้นฐานเอามาประกอบกันเป็นคำสั่งใหม่ได้ (ธีมที่จะกลับมาในบท 8)

5. หน้าตาในวงจร — สัญลักษณ์ที่ต้องจำ (ออกสอบ!)

อาจารย์ออกสอบเรื่อง หน้าตาของวงจร (circuit diagram) ด้วย ทุกคำสั่งมี "สัญลักษณ์" ของมัน วางบนเส้น qubit อ่าน ซ้าย → ขวา ตามลำดับเวลา — บทนี้เก็บ 3 ตัวแรก:

WRITE
NOT (X)
READ (วัด)
ระวังกับดักข้อสอบ

เน็ตส่วนใหญ่ใช้สัญลักษณ์แบบ Qiskit (กล่องเหลี่ยมล้วน) แต่อาจารย์ใช้สไตล์ QCEngine/O'Reilly ที่เห็นข้างบน — READ เป็น "หน้าปัด detector" ครึ่งวงกลม, WRITE เป็นหัวลูกศร ท่องให้ตรงสไตล์นี้นะคะ หนูเก็บทุกสัญลักษณ์ไว้ใน 📐 Cheat Sheet วงจร ที่จะโตขึ้นทุกบท เอาไว้พิมพ์ท่องก่อนสอบได้เลย

6. แนวคิดใหญ่ของบท: reversible vs irreversible

นี่คือ แนวคิดที่จะโผล่ซ้ำทั้งวิชา ต้องแม่น: คำสั่งควอนตัมแบ่งเป็น 2 พวก

ประเภทความหมายคำสั่งในบทนี้
Reversible
(ย้อนกลับได้)		 มี "คำสั่งย้อน" ที่พา qubit กลับสถานะเดิมได้เป๊ะ → ไม่มีข้อมูลสูญหาย NOT (ย้อนด้วย NOT อีกที)
Irreversible
(ย้อนไม่ได้)		 ทำแล้วข้อมูลบางส่วน หายถาวร ย้อนกลับไม่ได้อีก READ, WRITE (ทำลาย superposition + phase)
ทำไม reversibility ถึงสำคัญ?

gate ควอนตัม "แท้ๆ" (ที่ไม่ใช่การวัด) เกือบทั้งหมด ต้องเป็น reversible — เป็นกฎของฟิสิกส์ควอนตัม ไม่ใช่แค่ความสะดวก เพราะข้อมูล amplitude/phase มีค่าเกินกว่าจะยอมให้หายกลางทาง เราถึง "หวง" การ READ ไว้ทำท้ายสุดเท่านั้น — เพราะพอ READ แล้ว ความเป็นควอนตัมก็จบ กลายเป็น bit ธรรมดาทันที

เช็คความเข้าใจ

1. ทำ NOT กับ qubit ที่เป็น |1⟩ สองครั้งติดกัน ผลเป็นอย่างไร?
ใช่ค่ะ! 1→0→1 กลับที่เดิม — NOT ทำสองทีเหมือนไม่ได้ทำ (its own inverse)
ลองไล่ทีละสเต็ปนะ 1→(NOT)→0→(NOT)→1 กลับมาที่เดิม เพราะ NOT เป็นตัวย้อนของตัวเอง
2. ข้อใดคือสิ่งที่ WRITE ทำไม่ได้?
ถูกต้อง! WRITE ตั้งได้แค่ |0⟩/|1⟩ พื้นฐาน superposition ต้องพึ่งคำสั่งอื่น (HAD บทหน้า)
ยังไม่ใช่ — สามข้อนั้น WRITE ทำได้หมด ที่มันทำไม่ได้คือเตรียม superposition/phase เอง
3. ทำไม READ ถึงต่างจากคำสั่งอื่นในชุดนี้อย่างชัดเจน?
ใช่เลยค่ะ — READ สุ่ม (ตาม magnitude²) และ irreversible ทำลาย superposition+phase ถาวร
ทบทวนนะ — จุดเด่นของ READ คือมันเป็นคำสั่งเดียวที่ผลสุ่มได้ และย้อนกลับไม่ได้ (irreversible)
ลองก่อนเปิด: อธิบายด้วยคำพูดตัวเอง — "reversible" กับ "irreversible" ต่างกันยังไง ยกตัวอย่างคำสั่งอย่างละตัว

ตัวอย่างคำตอบที่ดี: "reversible = ย้อนกลับไปสถานะเดิมได้ ไม่มีข้อมูลหาย เช่น NOT (ทำอีกทีก็กลับมา) ส่วน irreversible = ทำแล้วข้อมูลหายถาวร ย้อนไม่ได้ เช่น READ กับ WRITE ที่ทำลาย superposition และ phase ทิ้ง gate ควอนตัมแท้ๆ ส่วนใหญ่ต้อง reversible เราเลยเก็บ READ ไว้ทำท้ายสุด"

นึกเองก่อนเปิดเฉลย (retrieval practice) ช่วยให้จำได้นานกว่าอ่านซ้ำเยอะเลยค่ะ
