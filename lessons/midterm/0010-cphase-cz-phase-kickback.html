Lesson 0010 · Lec 03 ต่อ · conditional gate ที่ “ไม่ขยับวง แต่หมุนเข็ม”

CPHASE, CZ และ phase kickback: เงื่อนไขคือ “ตัวกรอง” ที่เลือกได้ว่าวงไหนจะโดนหมุน

บท 0009 เราได้ CNOT — conditional gate ที่ สลับวง บทนี้เจอญาติของมันที่ ไม่สลับอะไรเลย แค่หมุนเข็ม (phase) แบบมีเงื่อนไข คือ CPHASE กับ CZ แล้วครึ่งหลังจะเจอผลข้างเคียงสุดแปลกของมัน — phase kickback — ที่กลายเป็นฐานของอัลกอริทึม ดังๆ แทบทุกตัว (QFT, Grover, phase estimation) ค่ะ

จับหลัก 5 อย่างพอ
  1. CPHASE(θ) หมุน phase เฉพาะสถานะที่ ทั้งสอง qubit เป็น 1 เท่านั้น
  2. มัน สมมาตร — ไม่มีใครเป็น control ไม่มีใครเป็น target (ต่างจาก CNOT ชัดเจน)
  3. กฎตัวกรอง: k เงื่อนไข → กระทบ 1/2k+1 ของทุกวง
  4. CZ = CPHASE(180°) = พลิกเครื่องหมาย |11⟩ · สัญลักษณ์ ●—● · เท่ากับ H→CNOT→H
  5. Phase kickback: หมุน phase ของ register 2 โดยมีเงื่อนไขจาก register 1 → phase ไปโผล่ที่ register 1 แทน และไม่เกิด entanglement

CPHASE & CZ — เงื่อนไขในฐานะ “ตัวกรอง”

1. ต่อยอดจากของที่รู้แล้ว 2 อัน

บทนี้ไม่มีอะไรใหม่จากอากาศเลยค่ะ มันคือ สองอย่างที่พี่รู้แล้วเอามาต่อกัน:

PHASE(θ) จากบท 0006 หมุนเข็มของสถานะที่ qubit นั้นเป็น 1 ทั้งหมด → ในทะเบียน 3 qubit (8 วง) จะกระทบ ครึ่งหนึ่ง = 4 วง เสมอ
“เงื่อนไข” จากบท 0009 CNOT บอกว่า “ทำก็ต่อเมื่อ control เป็น 1” → ทำให้ operation เลือกได้ว่าจะกระทบวงไหน ไม่ใช่ทุกวงเหมือนเดิม

เอามารวมกัน: “หมุน phase — แต่ทำก็ต่อเมื่ออีก qubit เป็น 1 ด้วย” นั่นแหละคือ CPHASE

นิยามจากสไลด์ 63

CPHASE(θ) หมุน phase เฉพาะสถานะ |11⟩ เท่านั้น (คือทั้ง qubit เงื่อนไขและ qubit เป้าหมายต้องเป็น 1 พร้อมกัน) — ผลคือ |11⟩ ได้ตัวคูณ eiθ ส่วน |00⟩, |01⟩, |10⟩ ไม่ขยับ

ข้อที่คนพลาดบ่อย: CPHASE สมมาตร

CNOT มีบทบาทชัด — ● คือคนสั่ง, ⊕ คือคนถูกกระทำ สลับที่แล้วผลคนละเรื่อง แต่ CPHASE สลับที่แล้วผลเหมือนเดิมเป๊ะ เพราะเงื่อนไขของมันคือ “ทั้งคู่ต้องเป็น 1” ซึ่งเป็นประโยคที่สมมาตรอยู่แล้ว (สไลด์ 63 ย้ำเรื่องนี้เอง)

นี่คือเหตุผลที่สัญลักษณ์ของมันวาดเป็น จุดสองจุดเหมือนกันทั้งบนและล่าง ไม่ใช่จุดกับกากบาท — รูปวาดสะท้อนความสมมาตรตรงๆ ค่ะ

สไลด์ 71 หัวข้อ Symbol เขียนว่า CZ มีสัญลักษณ์ (●—⊕) — ผิดค่ะ ●—⊕ คือสัญลักษณ์ของ CNOT ส่วน CZ ของจริงคือ ●—● (จุดทึบทั้งสองข้าง)

ที่ยืนยันได้แน่นอนคือ สไลด์ 70 ของอาจารย์เองวาด ●—● ไว้ชัดเจน ในหัวข้อ “three representations of CPHASE(180)” — สไลด์สองหน้าติดกันขัดกันเอง แปลว่าหน้า 71 พิมพ์พลาด

วิธีรับมือตอนสอบ (เหมือนที่ตกลงกันไว้ตั้งแต่บท 0006): ถ้าโจทย์ให้วาด CZ → วาด ●—● ตามรูปสไลด์ 70 ซึ่งเป็นของถูกและเป็นมาตรฐานสากล ถ้าเจอตัวเลือกที่ลอกประโยคหน้า 71 มาเป๊ะๆ ค่อยว่ากันอีกที แต่ให้รู้ไว้ว่าอันไหนคือของจริง

“สามหน้าตา” ของ CPHASE(180) ตามสไลด์ 70 คือสิ่งเดียวกันหมด เขียนแบบไหนก็ได้:

●—●  =  φ—φ (180°)  =  H → ⊕ → H

5. CZ — กรณีพิเศษที่เจอบ่อยที่สุด

ถ้าตั้ง θ = 180° การหมุนจะกลายเป็น “หมุนครึ่งรอบ” ซึ่งก็คือ คูณด้วย −1 พอดี กรณีนี้เจอบ่อยมากจนได้ชื่อของตัวเอง: CZ (Controlled-Z)

CZ = CPHASE(180°)  →  พลิกเครื่องหมายของ |11⟩ ตัวเดียว

เขียนเป็นเมทริกซ์ (สไลด์ 71) ก็คือ identity ที่มุมล่างขวาเป็น −1:

|00⟩|01⟩|10⟩|11⟩
|00⟩1000
|01⟩0100
|10⟩0010
|11⟩000−1
CZ = diag(1, 1, 1, −1)

ความสัมพันธ์ที่ต้องจำคู่กัน

บท 0005/0006 พี่เจอมาแล้วว่า Z = H → X → H (Hadamard เปลี่ยน “การพลิกวง” ให้กลายเป็น “การพลิกเครื่องหมาย”) ระดับสอง qubit ก็ใช้ตรรกะเดียวกันเป๊ะ (สไลด์ 72):

CZ(q₀, q₁) = H(q₁) → CNOT(q₀, q₁) → H(q₁)

สังเกตว่า H สองตัวคร่อมอยู่บนเส้นเดียวกัน คือเส้น target ของ CNOT — ไม่ใช่คร่อมทั้งสองเส้น นี่คือจุดที่ข้อสอบชอบหลอกค่ะ

② สถานะ |++⟩ (คือ HAD ทั้งสอง qubit → ทั้ง 4 วงเท่ากันหมด) ถูกทำ CZ แล้วไป READ ทันที — โอกาสได้ผลแต่ละค่าจะเปลี่ยนไปไหม?
ใช่ค่ะ! phase ไม่แตะ ขนาด ของ amplitude เลย — −1 ยกกำลังสองก็ยังได้ 1 เท่าเดิม ผล READ จึงเหมือนเดิมเป๊ะ 25% ทุกค่า แต่สถานะนี้ entangled แล้วจริงๆ และความต่างจะโผล่เมื่อเอาไป interfere ต่อ (เช่นใน Grover)
ยังไม่ใช่ค่ะ — จำหลักจากบท 0003: phase ไม่มีผลต่อ probability โดยตรง |−1|² = 1 เท่าเดิม → ยัง 25% ทั้งสี่ค่า · phase จะ “ออกฤทธิ์” ก็ต่อเมื่อเอาไป interfere ต่อภายหลัง
ครึ่งหลัง

Phase kickback — ของที่เด้งกลับมาโดยไม่ได้ตั้งใจ

6. วงจรที่ทำให้ทุกคนงงครั้งแรก

สไลด์ 73 วางวงจรง่ายๆ ไว้ ตั้งใจจะ “หมุน phase ของ register 2 โดยมีเงื่อนไขจาก register 1”:

วาดตามสไลด์ 73 · Register 1 = 2 qubit เขียน 0 แล้ว HAD ทั้งคู่ · Register 2 = 1 qubit เขียน 1 (สำคัญมาก!)
qc.reset(3);
var reg1 = qint.new(2, 'Register 1');
var reg2 = qint.new(1, 'Register 2');
reg1.write(0);
reg2.write(1);          // ← ต้องเป็น 1 ไม่งั้นไม่เกิดอะไรเลย
reg1.had();             // reg1 = superposition ของ 0,1,2,3
// หมุน phase ของ reg2 โดยมีเงื่อนไขจาก qubit ของ reg1
qc.phase(45, 0x4, 0x1);
qc.phase(90, 0x4, 0x2);

อ่าน qc.phase(มุม, เป้าหมาย, เงื่อนไข) — ตรงนี้ 0x4 คือ qubit ของ reg2 (บิตที่ 3 ของทั้งเครื่อง) ส่วน 0x1 และ 0x2 คือ qubit สองตัวของ reg1 ที่ทำหน้าที่เป็นเงื่อนไข

7. ผลที่ออกมา — ผิดคาดตรงไหน

Register 1
|0⟩ 0°
|1⟩ 45°
|2⟩ 90°
|3⟩ 135°
Register 2
|0⟩ 0
|1⟩ 100%
วาดตามสไลด์ 74 — register 2 ไม่ขยับเลยสักนิด ทั้งที่เราตั้งใจจะหมุนมัน แต่ phase ไปโผล่ที่ register 1 ทั้งหมด

ไล่ดูทีละวงของ register 1 จะเห็น pattern ชัดมาก (สไลด์ 75):

|0⟩ = 00 → ไม่มีบิตไหนติด → 0°
|1⟩ = 01 → บิต 0x1 ติด → ได้ 45° → 45°
|2⟩ = 10 → บิต 0x2 ติด → ได้ 90° → 90°
|3⟩ = 11 → ติดทั้งคู่ → 45° + 90° = 135°

เห็นไหมคะว่า การหมุนที่เรา “สั่งใส่ register 2” ไปลงเอยที่ค่าใน register 1 ที่ตรงกับเงื่อนไข — นี่แหละที่เรียกว่า phase kickback (การเด้งกลับของเฟส)

8. ทำไมมันเป็นแบบนั้น — คำอธิบายสั้นที่สุด

กุญแจอยู่ที่ “CPHASE สมมาตร”

จำหัวข้อ 1 ได้ไหมคะว่า CPHASE ไม่มีใครเป็น control ไม่มีใครเป็น target — เงื่อนไขจริงๆ ของมันคือ “ทั้งสอง qubit เป็น 1 หรือเปล่า” เท่านั้น

ดังนั้นตอนที่เราคิดว่า “เอา reg1 มาคุม แล้วหมุน reg2” ธรรมชาติไม่ได้มองแบบนั้นเลย — มันแค่หมุน phase ของ สถานะร่วมที่ทั้งคู่เป็น 1 · พอ reg2 เป็น |1⟩ ตลอดเวลา เงื่อนไขก็เหลือขึ้นกับ reg1 ตัวเดียว → phase เลย “ไปเกาะ” ค่าใน reg1 แทน

และเพราะเหตุนี้ สไลด์ 79 จึงระบุ เงื่อนไขที่ขาดไม่ได้:

reg2 ต้องเป็น |1⟩ถ้าเขียน 0 ไว้ เงื่อนไข “ทั้งคู่เป็น 1” ไม่มีทางเป็นจริง → ไม่มีอะไรเกิดขึ้นเลย
reg2 ต้องไม่ superpositionเพราะมันคงที่ phase ที่มันได้จึงเป็น global phase ซึ่งมองไม่เห็น/ไม่มีผล
ไม่เกิด entanglementสถานะสุดท้ายยัง separable (แยกกันได้) สองทะเบียนยังคิดแยกกันได้ตามปกติ
กับดักความเข้าใจ

บท 0009 เพิ่งเรียนว่า CNOT + superposition → entanglement หลายคนเลยเหมาว่า “ใช้ two-qubit gate เมื่อไหร่ = ได้ entanglement” — ไม่จริงค่ะ สไลด์ 80 ยกเรื่อง phase kickback มาเป็นตัวอย่างค้านโดยตรง: ใช้ gate สอง qubit เต็มๆ แต่ผลลัพธ์ยังแยกกันได้ ไม่พัวพันเลย

③ ถ้าแก้โค้ดบรรทัดเดียว จาก reg2.write(1) เป็น reg2.write(0) แล้วรันวงจรเดิม — register 1 จะออกมาหน้าตายังไง?
ถูกต้องค่ะ! เงื่อนไขคือ “ทั้งสองต้องเป็น 1” พอ reg2 = 0 ตลอด เงื่อนไขไม่เคยเป็นจริง → CPHASE ไม่ทำอะไรเลย → reg1 ยังเป็น superposition เท่ากันหมด phase 0° นี่คือเหตุผลที่สไลด์ 79 บอกว่า “initialize เป็น |1⟩ is essential”
ยังไม่ใช่ค่ะ — ลองย้อนไปที่นิยาม: CPHASE หมุนเฉพาะตอน ทั้งสอง qubit เป็น 1 ถ้า reg2 ค้างที่ 0 ตลอด เงื่อนไขไม่เคยจริงสักครั้ง → ไม่เกิดอะไรเลย register 1 ยังเข็มชี้ขึ้นทุกวง
④ ถ้าเปลี่ยนสองบรรทัดท้ายเป็น qc.phase(90, 0x4, 0x3) บรรทัดเดียว (0x3 = ทั้ง 0x1 และ 0x2 เป็นเงื่อนไขพร้อมกัน) — วงไหนของ register 1 ที่จะได้ phase 90°? (ลองไล่ 00, 01, 10, 11 เองก่อนนะคะ)
เยี่ยมค่ะ! ตอนนี้มี 2 เงื่อนไข (k = 2) → กระทบ 1/2³ = 1/8 ของทะเบียน 3 qubit = 1 วง พอดี คือค่าที่ทั้ง 0x1, 0x2 (และ 0x4) เป็น 1 → ในสายตา reg1 คือวง |3⟩ (11) วงเดียว — สูตร 1/2k+1 จากครึ่งแรกใช้ได้ตรงๆ
ยังไม่ใช่ค่ะ — เงื่อนไขตอนนี้คือ “0x1 และ 0x2 และ 0x4 เป็น 1 พร้อมกัน” ในสายตา reg1 มีแค่ค่า 11 = |3⟩ ค่าเดียวที่ผ่าน · เช็กกับสูตรได้: k = 2 → 1/2³ ของ 8 วง = 1 วง

9. ทำไมเรื่องนี้ถึงสำคัญมาก

อ่านสไลด์ 77 กลับด้าน จะเห็นว่า phase kickback ไม่ใช่ “ผลข้างเคียงน่ารำคาญ” แต่เป็น เครื่องมือ: ถ้าเราอยากใส่ phase ให้ บางค่าที่เจาะจง ในทะเบียนที่เราสนใจ เราก็ไปหมุน phase ของทะเบียนอื่น โดยตั้งเงื่อนไขจาก qubit ของทะเบียนที่เราสนใจ — แล้ว phase จะเด้งกลับมาลงตรงที่เราต้องการพอดี

เหตุผลที่มันทรงพลัง: เราเลือก qubit เงื่อนไขได้ = เราเลือกได้ว่าค่าไหนจะโดน และเนื่องจากผลลัพธ์เป็น phase (ไม่ใช่ probability) มันจึงเป็นวัตถุดิบชั้นดีสำหรับ interference ในขั้นถัดไปของอัลกอริทึม

QFTQuantum Fourier Transform ใช้ CPHASE เป็นหัวใจ
QPEQuantum Phase Estimation = kickback แบบเต็มสูบ
Grover“ทำเครื่องหมาย” คำตอบด้วยการพลิก phase
Simon / oracleอัลกอริทึมกลุ่ม oracle ใช้หลักเดียวกัน

และสไลด์ 83 เพิ่มว่า kickback ไม่ได้จำกัดอยู่แค่ CPHASE — conditional operation ใดๆ ที่ทำให้เกิดการเปลี่ยน phase ก็ให้ผลแบบนี้ได้หมด

⑤ ข้อความไหนผิดเกี่ยวกับ phase kickback?
ถูกต้องค่ะ! ข้อนี้คือข้อที่ผิด — สไลด์ 79–80 ย้ำชัดว่า No Entanglement Is Created สถานะยัง separable (เขียนเป็น tensor product ได้) เป็นตัวอย่างค้านว่า “two-qubit gate ≠ entanglement เสมอไป”
ข้อที่พี่เลือกเป็นเรื่องจริงค่ะ · ข้อที่ ผิด คือ “ทำให้สอง register พัวพันกัน” — สไลด์ 79–80 บอกตรงข้ามเลยว่า ไม่เกิด entanglement สถานะยังแยกกันได้ (separable)

10. ลองรันเองบน QCEngine

เปิด oreilly-qc.github.io แล้ววางโค้ดข้างบน (หรือเปิดตัวอย่างบทที่ 3 ของหนังสือ) ลองสามอย่างนี้ดูค่ะ แล้วดู circle notation ที่มันวาดให้:

  1. รันตามโค้ดเดิม → ควรเห็น register 1 มีเข็มเอียง 0°/45°/90°/135°
  2. เปลี่ยนเป็น reg2.write(0) → เข็มควรตั้งตรงหมด (ตรงกับ quiz ③)
  3. เปลี่ยนมุมเป็น qc.phase(180, 0x4, 0x1) → ดูว่า |1⟩ กับ |3⟩ กลับหัว
🧠 ทดสอบความจำก่อนปิดหน้า (เปิดดูเฉลยทีหลัง)
  1. วาดจากความจำ: สัญลักษณ์ CPHASE(θ) และสัญลักษณ์ CZ — ต่างจาก CNOT ตรงไหน?
  2. ทะเบียน 4 qubit (16 วง) ทำ CPHASE 1 คู่ → กระทบกี่วง? แล้วถ้ามี 3 control ล่ะ?
  3. อธิบายด้วยคำพูดตัวเองใน 2 ประโยค ว่าทำไม phase ถึง “เด้งกลับ” มาที่ register 1
  4. เงื่อนไข 2 ข้อที่ทำให้ phase kickback ทำงานได้คืออะไร?
  5. ยกตัวอย่างค้านของประโยค “ใช้ gate สอง qubit = ได้ entanglement”

เฉลยย่อ: ① CPHASE = φ—φ, CZ = ●—● (สมมาตรทั้งคู่) ส่วน CNOT = ●—⊕ (ไม่สมมาตร) ② 1 คู่ → 16/4 = 4 วง · 3 control → 1/2⁴ = 1 วง ③ เพราะ CPHASE สมมาตร มันหมุน “สถานะร่วมที่ทั้งคู่เป็น 1” และ reg2 เป็น 1 ตลอด เงื่อนไขจึงเหลือแค่ reg1 ④ reg2 ต้องเป็น |1⟩ และต้องไม่อยู่ใน superposition ⑤ phase kickback นี่แหละ — ใช้ CPHASE แต่ไม่เกิด entanglement

11. สรุปก่อนไปบทหน้า

  • CPHASE(θ) หมุน phase เฉพาะ |11⟩ · สมมาตร ไม่มี control/target · สัญลักษณ์ φ—φ
  • เงื่อนไข = ตัวกรอง → k control กระทบ 1/2k+1 ของทุกวง
  • CZ = CPHASE(180°) = พลิกเครื่องหมาย |11⟩ · ●—● · = H → CNOT → H (คู่ขนานกับ Z = H→X→H)
  • Phase kickback: หมุน reg2 โดยมีเงื่อนไขจาก reg1 → phase ไปโผล่ที่ reg1 (ต้องมี reg2 = |1⟩ และไม่ superposition)
  • kickback ไม่สร้าง entanglement — แต่เป็นฐานของ QFT / QPE / Grover
บทหน้า (0011)

บทนี้เราเพิ่มเงื่อนไขให้ PHASE บทหน้าจะเพิ่มเงื่อนไขให้ NOT บ้าง → CCNOT (Toffoli) ที่มี 2 control แล้วต่อด้วย SWAP กับ CSWAP ปิดท้ายด้วย SWAP test — เทคนิคเทียบว่าสองสถานะเหมือนกันแค่ไหนโดยไม่ต้องอ่านมันค่ะ
