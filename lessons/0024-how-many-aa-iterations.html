วน AA กี่รอบดี? — ทำซ้ำได้ แต่ทำเกินแล้วร่วง

บทที่แล้ว (0023) flip + mirror 1 รอบดันค่าที่ mark จาก 6.25% ขึ้นไป 47.3% — ดีขึ้นมาก แต่ยังเกือบโยนเหรียญ · คำถามที่ค้างไว้คือ ทำซ้ำอีกได้ไหม? บทนี้ตอบว่า “ได้” แล้วตามด้วยคำถามที่สำคัญกว่า: ต้องหยุดตรงไหน

ทำไมต้องเรียนบทนี้ — ถ้าคิดว่า “วนยิ่งเยอะยิ่งดี” จะได้คำตอบผิดแบบไม่รู้ตัว · บทนี้จับหลัก 3 อย่าง: ① AA iteration = flip + mirror (ต้อง flip ใหม่ทุกรอบ) ② ความน่าจะเป็นแกว่งเป็นคลื่น ไม่ได้ขึ้นอย่างเดียว ③ สูตร NAA = ⌊π√(2ⁿ)/4⌋ บอกว่าหยุดรอบไหน — ทั้งสูตรและกรอบ “AA” ในวงจรออกสอบได้

ส่วนที่ 1 · ทำซ้ำ → AA iteration และ phase logic

ลองทายก่อน: ใส่ mirror ซ้ำเฉยๆ ได้ไหม?

ตอนนี้เราอยู่ที่ B₁ (หลัง flip + mirror 1 รอบ) — ∣3⟩ วงใหญ่ 47.3% ที่เหลือหด และเข็มทุกวงชี้ทางเดียวกันหมด (ไม่มีความต่างของเฟสเหลือ)

ถ้าที่ B₁ เราใส่ mirror อีกครั้งเลย โดยไม่ flip ก่อน จะได้อะไร? (ใบ้: mirror แปลงความต่างได้ทั้งสองทาง — บท 0023)
ถูกค่ะ — สไลด์ p11: mirror ซ้ำ = กลับไปที่เดิม เพราะมันแปลงความต่างของ magnitude กลับเป็นความต่างของเฟส (เหมือนกดสวิตช์ซ้ำ)
ยังไม่ใช่ค่ะ — ที่ B₁ ไม่มีความต่างของเฟสเหลือให้ mirror แปลงไปข้างหน้า มีแต่ความต่างของ magnitude → mirror จึงแปลงย้อนกลับเป็นเฟส = กลับไปสถานะ B (p11)

หลัง flip + mirror ครบ 2 รอบ (B₂) — ∣3⟩ ≈ 90.8% · ที่เหลือ ≈ 0.6% ต่อค่า

ตั้งชื่อ: 1 AA iteration = flip + mirror

สไลด์ p12 เรียกคู่นี้รวมกันว่า amplitude amplification iteration (AA iteration — รอบของการขยายแอมพลิจูด) · flip เล็งค่าเป้าหมายแล้วทำให้เฟสต่าง · mirror แปลงความต่างนั้นเป็นขนาด

หน้าตาในสไลด์ (เรื่องสอบ) — สไลด์วาด 8 คอลัมน์นี้ไว้ในกรอบมุมมนพื้นเทา มีป้าย “AA” ทั้งบนและล่าง (ไม่ได้แบ่งเป็นกล่อง flip/mirror แยกแบบรูปด้านบน — หนูแบ่งให้ดูว่าส่วนไหนเป็นอะไร) · เวลาวนหลายรอบ สไลด์วาดกรอบ AA ต่อกันเป็นขบวนที่เนื้อในเหมือนกันทุกกรอบ

“ต้องรู้คำตอบก่อนถึงจะ flip ได้ แล้วจะค้นหาไปทำไม?”

คำถามนี้สไลด์ p13 ตั้งไว้เองเลย — กล่อง flip ของเราเขียนเลข 3 ฝังไว้ในวงจร ถ้ารู้อยู่แล้วว่าคำตอบคือ 3 ก็ไม่ต้องใช้ QPU · คำตอบคือ flip เป็นแค่ตัวอย่างที่ง่ายที่สุดของ subroutine ที่พลิกเฟส

flip (ตัวอย่างในห้องเรียน)เหมือนครูติดสติกเกอร์ไว้ที่คำตอบข้อ 3 เอง — ใช้สาธิตว่าเครื่องทำงานยังไง แต่ในงานจริงไม่มีใครติดให้
→
phase logic (งานจริง)เหมือนกฎตรวจคำตอบ เช่น “ค่านี้ทำให้สมการเป็นจริงไหม” ใครผ่านกฎก็โดนพลิกเฟสเอง โดยที่เราไม่ต้องรู้ล่วงหน้าว่าเป็นค่าไหน

phase logic (ลอจิกบนเฟส) = การคำนวณที่ทำบนเฟสของรีจิสเตอร์ล้วนๆ พลิกเฟสหลายค่าตามตรรกะของโจทย์ (ต่อยอดจาก phase-encoded result ใน บท 0020)

ประโยคทองสไลด์ p13 — เอา subroutine แก้เฟสที่ซับซ้อนกว่า flip มาต่อกับ mirror ก็ยังแปลงการเปลี่ยนแปลงของเฟส → ความต่างของ magnitude ได้เหมือนเดิม
เปลี่ยนโจทย์จาก “หาเลข 3” เป็นโจทย์อื่น ต้องแก้ส่วนไหนของ AA iteration?
ถูกค่ะ — flip (หรือ phase logic) คือส่วนที่รู้จักโจทย์ ส่วน mirror = Grover() หน้าตาเดียวทุกงาน (บท 0023)
ยังไม่ใช่ค่ะ — mirror ไม่รู้เลยว่าโจทย์คืออะไร มันแค่แปลงเฟสเป็นขนาด · ส่วนที่ “รู้โจทย์” มีแค่ flip ซึ่งในงานจริงถูกแทนด้วย phase logic

ส่วนที่ 2 · วนต่อไปเรื่อยๆ → คลื่น และสูตร NAA

90.8% แล้ว — วนต่อก็น่าจะแตะ 100% สิ? สไลด์ p14 ลองด้วยโค้ดที่เปลี่ยนแค่ number_of_iterations:

var number_to_flip = 3;
var number_of_iterations = 4;

var num_qubits = 4;
qc.reset(num_qubits);
var reg = qint.new(num_qubits, 'reg');
reg.write(0);
reg.hadamard();                          // prep

for (var i = 0; i < number_of_iterations; ++i) {
  reg.not(~number_to_flip);              // ┐
  reg.cphase(180);                       // ├ flip
  reg.not(~number_to_flip);              // ┘
  reg.Grover();                          //   mirror
  var prob = reg.peekProbability(number_to_flip);   // แอบดู % ของค่า 3
}

peekProbability = แอบดูความน่าจะเป็นโดยไม่ READ · ทำได้เพราะรันบน simulator (บน QPU จริงแอบดูไม่ได้ — ดูได้ทางเดียวคือ READ ซึ่งทำลายสถานะ)

ลูกศรในสไลด์: B = กลางกรอบ AA แรก (หลัง flip ก่อน mirror) · B₁ B₂ B₃ B₄ = ท้ายกรอบที่ 1, 2, 3, 4

ไล่ผังทีละรอบ (สไลด์ p15–16)

B — หลัง flip · ทุกวง 6.25% · มีแต่ ∣3⟩ ที่เข็มชี้ลง

B₁ — 47.3% · เข็มชี้ลงทุกวง (เฟสตรงกันหมด)

B₂ — 90.8% · เข็มชี้ขึ้นทุกวง (เฟสตรงกันหมด)

B₃ — 96.1% · ∣3⟩ ชี้ลง แต่ที่เหลือชี้ขึ้น ← สวนเฟสกัน!

สไลด์ p15 · หนูซูมยืนยันทิศเข็มแถว B₃/B₄ แล้วตรงกับที่คำนวณเอง

ที่ B₃ ค่า ∣3⟩ เฟส 180° แต่ค่าอื่น 0° · รอบที่ 4 เริ่มด้วย flip ∣3⟩ อีกที — หลัง flip นั้นสถานะเป็นยังไง แล้ว mirror จะทำอะไรต่อ?
ถูกค่ะ — flip ทำให้ ∣3⟩ ชี้ขึ้นเหมือนเพื่อน (p16 “in alignment”) → เหลือแต่ความต่างของขนาด → mirror แปลงย้อนกลับเหมือนตอน mirror ซ้ำในส่วนที่ 1 · ร่วงเหลือ 58.2%
ยังไม่ใช่ค่ะ — flip ไม่แตะขนาดวงเลย มันแค่พลิกเข็ม ∣3⟩ จาก 180° → 0° ซึ่งตรงกับเพื่อนพอดี · ไม่มีความต่างเฟสให้แปลง mirror จึงทำงานย้อนทาง
เปิดดูผัง B₄ (ตอบข้อด้านบนก่อนนะคะ)

B₄ — ร่วงเหลือ 58.2% · ∣3⟩ ชี้ขึ้น ที่เหลือชี้ลง และวงเล็กๆ โตกลับมา

สไลด์ p15–16 · “the probability … has dropped to 58.2%”

จำรูปแบบเฟส — B₁, B₂ เฟสตรงกันหมด (ยังขาขึ้น) · B₃, B₄ ∣3⟩ สวนเฟสกับที่เหลือ · พอ marked “สวน” เมื่อไร flip รอบถัดไปจะหักล้างความต่างทิ้ง → AA เริ่มพาถอยหลัง

ความน่าจะเป็นแกว่งเป็นคลื่น (สไลด์ p17)

วนต่อไปอีก ค่าไม่ได้หายไปเฉยๆ แต่ขึ้นๆ ลงๆ แบบคาดเดาได้ (oscillate) · คาบราว 6 รอบ · กราฟนี้หนูคำนวณเองทุกแท่ง (ตรงกับตัวเลขที่สไลด์พิมพ์ไว้):

สไลด์ p17 พิมพ์ไม่เป๊ะ — สไลด์ว่ายอดสูงสุดคือ “รอบ 9 หรือ 15” ได้ 99.9563% → ตอบตามนี้ตอนสอบ · แต่ของจริงรอบ 15 = 99.956% ✓ ส่วนรอบ 9 = 99.22% (ใกล้ แต่ไม่เท่า)

หยุดที่ไหนดี? — ไม่ต้องไล่ล่ายอดที่สูงที่สุด

สไลด์ p18 เสนอว่าถ้าแต่ละรอบ “แพง” ให้หยุดที่ยอดแรก 3 รอบ (96.1%) แล้ว READ · ถ้าพลาดก็รันใหม่ทั้งโปรแกรม

① โอกาสพลาดต่อครั้ง = 1 − 0.961 = 0.039
② พลาดทั้งสองครั้ง = 0.039 × 0.039 ≈ 0.00152
③ สำเร็จอย่างน้อย 1 ใน 2 ครั้ง = 1 − 0.00152 = 99.848% · ใช้ AA รวมไม่เกิน 6 รอบ (เทียบรอยอด 15 รอบได้ 99.956%)

แถม: READ ได้เลขมาแล้วตรวจง่ายมากว่าใช่ไหม — จึงรู้ทันทีว่าต้องรันซ้ำหรือเปล่า

สูตรจำนวนรอบที่ดีที่สุด (สไลด์ p19)

NAA = ⌊ π √(2ⁿ) / 4 ⌋

n = จำนวน qubit · ⌊ ⌋ = ปัดลง (floor) · ได้จำนวนรอบที่ให้ยอดของลูกคลื่นแรก

① n = 4 → 2⁴ = 16 → √16 = 4
② π × 4 / 4 = π ≈ 3.14
③ ⌊3.14⌋ = 3 ✓ ตรงกับยอด 96.1% ในกราฟ
รีจิสเตอร์ 6 qubit mark ค่าเดียว — ควรวน AA กี่รอบ? (คิดตามสูตรเองก่อนนะคะ)
ถูกค่ะ — 2⁶ = 64 → √64 = 8 → π×8/4 = 2π ≈ 6.28 → ปัดลง = 6 (ยอดที่ได้ ≈ 99.7%)
ยังไม่ใช่ค่ะ — 2⁶ = 64 → √64 = 8 (อย่าลืมหาร 4) → π×8/4 ≈ 6.28 → ปัดลง ไม่ใช่ปัดขึ้น = 6
อยากรู้ว่าทำไมเป็น √ (เสริม · ไม่ออกสอบ)

มองแบบเรขาคณิต: สถานะเริ่มต้นเอียงจาก “ไม่ใช่คำตอบ” ไปหา “คำตอบ” เป็นมุมเล็กๆ θ โดย sin θ = 1/√(2ⁿ) · AA แต่ละรอบหมุนเพิ่ม 2θ · ความน่าจะเป็น = sin²((2k+1)θ) ซึ่งเป็นคลื่นจริงๆ · จะหมุนไปถึง 90° ต้องใช้ราว (π/2)/(2θ) ≈ π√(2ⁿ)/4 รอบ → นี่คือที่มาของ √ และสูตรข้างบน

ผลคือค้นใน 2ⁿ ค่าได้ด้วยราว √(2ⁿ) รอบ (คอมคลาสสิกต้องไล่ราว 2ⁿ ครั้ง) · อ่านเพิ่ม: Wikipedia: Grover's algorithm — geometric proof · ส่วนมุมมอง “mirror สะท้อนรอบค่าเฉลี่ย” ของสไลด์ เก็บไว้บท 0026 ค่ะ

ทดสอบความจำ (ตอบในใจก่อนเปิด)
  1. ที่ B₁ ใส่ mirror ซ้ำเลยโดยไม่ flip ได้อะไร เพราะอะไร?
    กลับไปสถานะ B — ไม่มีความต่างเฟสเหลือ mirror จึงแปลงขนาดย้อนกลับเป็นเฟส
  2. 1 AA iteration ประกอบด้วยอะไร?
    flip + mirror (สไลด์วาดเป็นกรอบมุมมนป้าย “AA” บน-ล่าง)
  3. % ของ marked value หลัง AA 0, 1, 2, 3, 4 รอบ (4 qubit)?
    6.25 → 47.3 → 90.8 → 96.1 → 58.2
  4. ถ้าต้องรู้คำตอบก่อนถึงจะ flip ได้ AA มีประโยชน์ตรงไหน?
    flip เป็นแค่ตัวอย่าง งานจริงใช้ phase logic ที่พลิกเฟสตามกฎของโจทย์ mirror ยังใช้ได้เหมือนเดิม
  5. ทำไมรอบที่ 4 ร่วง?
    ที่ B₃ marked สวนเฟส → flip ทำให้เฟสตรงกันหมด → mirror แปลงย้อนทาง
  6. ความน่าจะเป็นเมื่อวน AA ไปเรื่อยๆ มีหน้าตาแบบไหน?
    แกว่งเป็นคลื่นคาดเดาได้ คาบราว 6 รอบ (4 qubit)
  7. ตามสไลด์ ยอดสูงสุด 99.9563% อยู่รอบไหน · ของจริงล่ะ?
    สไลด์: 9 หรือ 15 · จริง: 15 = 99.956% ส่วน 9 = 99.22%
  8. หยุดที่ 3 รอบแล้วรันซ้ำถ้าพลาด ได้โอกาสเท่าไร ใช้กี่รอบ?
    99.848% ใน 2 ครั้ง ใช้ไม่เกิน 6 รอบ
  9. เขียนสูตร NAA แล้วแทน n = 8
    ⌊π√(2ⁿ)/4⌋ → √256 = 16 → 4π ≈ 12.57 → 12 รอบ

สรุปบทนี้

  • mirror ซ้ำเฉยๆ = ย้อนกลับ · ต้อง flip ใหม่ทุกรอบ → flip + mirror = 1 AA iteration
  • flip = ตัวอย่างง่ายสุด · งานจริงใช้ phase logic · mirror ไม่เปลี่ยน
  • 4 qubit: 6.25 → 47.3 → 90.8 → 96.1 → 58.2% · ร่วงเพราะ B₃ สวนเฟส แล้ว flip ทำให้ตรงกัน
  • ความน่าจะเป็นแกว่งเป็นคลื่น · หยุดยอดแรกแล้วรันซ้ำถ้าพลาดคุ้มกว่า (99.848% ใน ≤ 6 รอบ)
  • NAA = ⌊π√(2ⁿ)/4⌋ → n = 4 ได้ 3 · ⚠️ สไลด์ p17 “รอบ 9 หรือ 15” — รอบ 9 จริงๆ 99.22%
