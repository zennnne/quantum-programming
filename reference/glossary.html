Glossary — ศัพท์วิชา Quantum Programming

คำแปล/นิยามกลางที่ทุกบทเรียนยึดตาม ถ้าเจอศัพท์งงในบทไหน กลับมาดูที่นี่ (อัปเดตเรื่อยๆ ตาม slide ที่เข้ามา)

วิธีใช้

ครั้งแรกที่ศัพท์โผล่ในบทเรียน หนูจะใส่คำไทยกำกับในวงเล็บ ครั้งต่อๆ ไปใช้คำอังกฤษได้ ตารางนี้คือ "ความจริงกลาง" — ถ้าคำแปลไหนควรปรับ บอกหนูได้เลยค่ะ

คำหลักจาก Lec 01

QPU — Quantum Processing Unit (หน่วยประมวลผลควอนตัม)

อุปกรณ์ที่โค้ดควอนตัมของเรารันอยู่ มองเป็น co-processor (หน่วยประมวลผลร่วม) คล้าย GPU — CPU เป็นตัวสั่งงาน แล้วโยนงานเฉพาะทางมาให้ QPU ทำ

Qubit — Quantum bit (บิตควอนตัม)

หน่วยข้อมูลพื้นฐานของ QPU เทียบได้กับ bit ของคอมทั่วไป แต่ต่างตรงที่มันอยู่ใน superposition ได้ (จะลงรายละเอียดในบทเรื่อง qubit)

Superposition (การซ้อนทับสถานะ)

สถานะที่ qubit "เป็นทั้ง 0 และ 1 พร้อมกัน" ในเชิงความน่าจะเป็น จนกว่าจะถูกวัด (measure) เป็นแหล่งพลังหลักที่ทำให้ QPU ทำบางอย่างที่คอมปกติทำไม่ได้

Co-processor (หน่วยประมวลผลร่วม)

ชิปเสริมที่ CPU เรียกใช้สำหรับงานเฉพาะทาง (เช่น GPU ทำกราฟิก/ขนาน) QPU ก็เป็น co-processor แบบหนึ่ง ไม่ได้มาแทน CPU

Tractable problem (ปัญหาที่แก้ไหว)

ปัญหาที่คำนวณเสร็จได้ในเวลาที่ยอมรับได้ (ไม่ระเบิดเป็นล้านปี) จุดขายของ QPU คือ ขยายเซตของปัญหาที่แก้ไหว ให้กว้างขึ้น ไม่ใช่ทำของเดิมให้เร็วขึ้นเฉยๆ

Physical qubit vs Logical qubit (qubit จริง vs qubit เชิงตรรกะ)

Physical qubit = qubit จริงบน hardware มีน้อย(ปัจจุบัน ~70, บน Qiskit สาธารณะ ~16) และ "เปราะ" มาก รบกวนจาก environment นิดเดียวก็พัง ยังไม่มี error correction. Logical qubit = qubit ในอุดมคติที่ซ่อน noise ไว้ ให้เราคิด algorithm ได้โดยไม่ต้อง ห่วงข้อจำกัด hardware

Simulator (ตัวจำลอง)

โปรแกรมบนคอมปกติที่จำลองพฤติกรรม QPU ได้ (สำหรับปัญหาเล็กๆ) ใช้เรียน/prototype ก่อนมี hardware จริง เช่น QCEngine

QCEngine

quantum simulator ออนไลน์ (เขียนด้วย JavaScript) รันในเบราว์เซอร์ ไม่ต้องติดตั้งอะไร มี circle notation ช่วยเห็นภาพสถานะ qubit

Circle notation (สัญกรณ์วงกลม)

วิธี visualize สถานะของ register (ชุด qubit) เป็นวงกลม ช่วยให้เห็น amplitude/เฟส โดยไม่ต้องจ้องตัวเลขเชิงซ้อน — เครื่องมือหลักที่หนังสือ/QCEngine ใช้

Native QPU instructions (คำสั่งพื้นฐานของ QPU)

ชุดคำสั่งพื้นฐานที่ QPU ทุกยี่ห้อควรมี เทียบได้กับ MOV/ADD ของ CPU เป็นอิฐก้อนเล็กที่เอาไปประกอบเป็น algorithm

คำหลักจากบทที่ 2 (One Qubit)

Ket notation — |0⟩, |1⟩ (สัญกรณ์เค็ต)

ส่วนหนึ่งของ Dirac notation กล่องเอียง |…⟩ คือ "ป้ายชื่อของสถานะ" เฉยๆ ไม่ใช่คณิต ที่ซับซ้อน — |0⟩ = สถานะที่วัดแล้วได้ 0 แน่นอน, |1⟩ = สถานะที่วัดแล้วได้ 1 แน่นอน

Amplitude (แอมพลิจูด, น้ำหนักของสถานะ)

ตัวเลขที่ติดหน้าแต่ละสถานะใน superposition (เช่น a·|0⟩ + b·|1⟩) บอก "น้ำหนัก" ว่าฝั่งนั้น มีโอกาสโผล่มาแค่ไหน จริงๆ เป็น จำนวนเชิงซ้อน (complex number) ติดลบ/มีทิศได้ — จุดนี้เอง ที่ทำให้เกิด interference (รายละเอียดบทถัดไป)

Born rule (กติกา amplitude → ความน่าจะเป็น)

โอกาสที่จะวัดเจอสถานะหนึ่งๆ = (ขนาดของ amplitude)² และเพราะต้องวัดได้ค่าใดค่าหนึ่งเสมอ ผลรวมความน่าจะเป็นทุกฝั่งจึงเท่ากับ 1 (100%) เสมอ

Measurement / Read (การวัด) & Collapse (การยุบสถานะ)

การ "เปิดดู" qubit ทำให้ superposition ยุบ (collapse) ทันที เหลือค่าเดียว (0 หรือ 1) วัด qubit หนึ่งตัวได้ข้อมูลแค่ 1 bit ธรรมดา เท่านั้น วัดซ้ำได้ค่าเดิม — ข้อมูล "ระหว่างเป็น superposition" หายไปแล้ว

คำหลักจากบทที่ 3 (Amplitude & Phase)

Magnitude (แมกนิจูด, ขนาดของ amplitude)

"ความยาวเข็ม" ของ amplitude — ส่วนที่ Born rule ใช้: โอกาสวัดเจอสถานะนั้น = magnitude² ยาวมาก = โอกาสสูง เป็นส่วนของ amplitude ที่ วัดครั้งเดียวก็เห็นผล

Phase (เฟส, ทิศ/มุมของ amplitude)

"ทิศที่เข็มชี้" ของ amplitude เป็นมุมรอบวง 0°–360° วัดครั้งเดียวมองไม่เห็น (Born rule ใช้แค่ magnitude) แต่เผยตัวตอน interference — เป็นตัวตัดสินว่า amplitude เสริมหรือหักล้างกัน

Global phase vs Relative phase (เฟสรวม vs เฟสสัมพัทธ์)

Global phase = หมุน phase ทุกสถานะเท่าๆ กัน → ไม่มีผล มองข้ามได้. Relative phase = ความต่างของ phase ระหว่าง |0⟩ กับ |1⟩ → อันนี้แหละที่มีผลจริง ตอน interference เวลาทำโจทย์ให้โฟกัสที่ "ความต่างของเข็มสองวง"

Interference (การแทรกสอด)

ปรากฏการณ์ตอน amplitude หลายเส้นทางมารวมกัน — บวกกันแบบลูกศร (phase เป็นตัวคุม): phase ตรงกัน = constructive (เสริม โอกาสพุ่ง), phase ตรงข้าม 180° = destructive (หักล้าง โอกาสตกไปถึง 0). นี่คือสิ่งที่ทำให้ qubit เหนือกว่าเหรียญสุ่ม เทียบได้กับ หูฟังตัดเสียงรบกวน (ยิงคลื่นเฟสตรงข้ามมาหักล้างเสียง)

Circle notation (สัญกรณ์วงกลม)

วิธีวาดสถานะที่หนังสือ/QCEngine ใช้: 1 วง = 1 สถานะพื้นฐาน. พื้นที่ทึบในวง = magnitude² (โอกาส), เข็มจากกลางวง = phase (ชี้ขึ้น = 0° หมุนตามเข็มนาฬิกา)

คำหลักจากบทที่ 4 (QPU Instructions: NOT, WRITE, READ)

Gate / Operation / Instruction (เกต / คำสั่ง)

สามคำนี้ในวิชานี้หมายถึงสิ่งเดียวกัน = "คำสั่งหนึ่งคำสั่งที่กระทำต่อ qubit" (คำกริยา ที่ทำกับ qubit) โปรแกรมควอนตัม = เอา gate หลายตัวมาเรียงต่อกัน เทียบได้กับชุดคำสั่งของ CPU

NOT (คำสั่งสลับ 0↔1)

ฝาแฝดควอนตัมของ NOT คลาสสิก: |0⟩↔|1⟩ ใน circle notation = สลับพื้นที่ทึบของสองวง ต่างจาก NOT ธรรมดาตรงที่ทำกับ superposition ได้ด้วย เป็น its own inverse (ทำสองครั้งกลับที่เดิม) ภายหลังจะเห็นว่ามันคือ gate ชื่อ X

WRITE (คำสั่งตั้งค่าเริ่มต้น)

บังคับ qubit ให้เป็น |0⟩ หรือ |1⟩ เป็น deterministic (ไม่สุ่ม) ตั้งได้แค่ค่าพื้นฐาน เตรียม superposition/phase เองไม่ได้ เป็น irreversible

READ (การวัด — รูปแบบทางการ)

ชื่อทางการของ measurement: ยุบ superposition เหลือ 0/1 คำสั่งเดียวที่ผลสุ่มได้ (โอกาส = magnitude², phase ไม่มีผล) และ irreversible — magnitude/phase เดิมหายถาวร ดู Measurement / Read & Collapse ประกอบ

Reversible vs Irreversible (ย้อนได้ vs ย้อนไม่ได้)

Reversible = มีคำสั่งย้อนพากลับสถานะเดิมได้เป๊ะ ไม่มีข้อมูลสูญหาย (เช่น NOT). Irreversible = ข้อมูลหายถาวร ย้อนไม่ได้ (เช่น READ, WRITE). gate ควอนตัมแท้ๆ (ที่ไม่ใช่การวัด) เกือบทั้งหมดต้อง reversible ตามกฎฟิสิกส์ควอนตัม

คำหลักจากบทที่ 5 (HAD / Hadamard)

HAD / Hadamard gate (เกตฮาดามาร์ด)

คำสั่งที่สร้าง uniform superposition (superposition เท่าๆ กัน 50/50) จากสถานะแน่นอน — ไม่มีคู่ในโลกคลาสสิก. H|0⟩ = (|0⟩ + |1⟩)/√2, H|1⟩ = (|0⟩ − |1⟩)/√2 ต่างกันแค่ เครื่องหมายลบ (relative phase 180°). เป็น its own inverse (ทำสองที = กลับที่เดิม) สัญลักษณ์วงจร = กล่อง [H]

Uniform superposition (ซูเปอร์โพซิชันเท่าๆ กัน)

superposition ที่ทุกผลลัพธ์มีโอกาสวัดเจอ เท่ากันหมด (สำหรับ 1 qubit = 50/50) คือสิ่งที่ HAD สร้างขึ้น

Normalization (การทำให้เป็นบรรทัดฐาน)

การปรับสเกล amplitude ให้ ผลรวมของ magnitude² = 1 พอดี (โอกาสรวม = 100%) เป็นเหตุผล ที่ HAD ต้องหารด้วย √2 ไม่ใช่ 2: (1/√2)² + (1/√2)² = ½ + ½ = 1 ✓

Orthogonality (ความตั้งฉาก) & Inner product (ผลคูณภายใน)

สองสถานะ ตั้งฉาก (orthogonal) = แยกจากกันได้สนิท 100% วัดด้วย inner product เขียน ⟨a|b⟩ ถ้าได้ 0 = ตั้งฉาก. พื้นฐาน |0⟩, |1⟩ ตั้งฉากกัน: ⟨0|1⟩ = 0 (กติกา: ⟨0|0⟩ = ⟨1|1⟩ = 1). gate ควอนตัมต้อง รักษาความตั้งฉาก — เหตุผลหนึ่งที่ H ต้องมีเครื่องหมายลบ

Matrix ของ gate (เมทริกซ์)

gate ทุกตัวเขียนเป็นตาราง (matrix) ได้ การ "ทำ gate กับ qubit" = เอา matrix คูณ vector ของ qubit (|0⟩ = [1,0], |1⟩ = [0,1]). Hadamard: H = (1/√2)·[[1,1],[1,−1]]

คำหลักจากบท 6–7 (QRNG · PHASE · Rotation · Bloch sphere)

PRNG — Pseudo-Random Number Generator (ตัวสร้างเลขสุ่มเทียม)

อัลกอริทึมบนคอมปกติที่ให้ลำดับเลขที่ ดูสุ่ม แต่ถูกกำหนดไว้หมดแล้วโดย อัลกอริทึม + seed → รู้ทั้งสองอย่าง = ทำนายทุกเลขในอนาคตได้ จึงเรียกว่า pseudo (เทียม) ตัวอย่างในสไลด์: xn+1 = (a·xn + c) mod m

Seed (ค่าตั้งต้น)

เลขเริ่มต้นที่ป้อนให้ PRNG (x0) — จุดอ่อนสำคัญ: ใครเดา seed ได้ ก็ทำนายผลลัพธ์ทั้งลำดับได้

QRNG — Quantum Random Number Generator (ตัวสร้างเลขสุ่มควอนตัม)

โปรแกรม QPU ตัวแรกของวิชานี้ = WRITE |0⟩ → HAD → READ ให้ 0/1 อย่างละ 50% ความสุ่มมาจาก ฟิสิกส์ควอนตัม ไม่ใช่การคำนวณ — ข้างใน HAD ไม่มีอัลกอริทึม ไม่มี seed

True random (สุ่มแท้) vs Pseudo-random (สุ่มเทียม)

สุ่มแท้ = ทำนายไม่ได้เพราะ ไม่มีอะไรให้รู้ (แม้รู้ทุกอย่างในระบบก็ทำนายไม่ได้) สุ่มเทียม = ทำนายไม่ได้เพราะ เรายังไม่รู้ (รู้ seed เมื่อไหร่ก็จบ). ข้อควรระวัง: รัน QRNG บน simulator (เช่น QCEngine) ยังได้แค่สุ่มเทียม เพราะ simulator รันบนคอมปกติ — ต้องรันบน QPU จริง ถึงได้สุ่มแท้

PHASE(θ) — คำสั่งหมุนเฟส

gate ที่ หมุนเข็มของวง |1⟩ เท่านั้น ไปเป็นมุม θ (วง |0⟩ ไม่แตะ) · ไม่เปลี่ยนโอกาสวัด เลย · ไม่มีผลใดๆ กับ qubit ที่เป็น |0⟩ (วง |1⟩ ว่าง = ไม่มีเข็มให้หมุน) · ไม่มีคู่เทียบในคอมพิวเตอร์ปกติ · เป็น gate ตัวแรกที่ กินพารามิเตอร์ (มุม) · reversible แต่ไม่ใช่ its own inverse — ย้อนด้วย PHASE(−θ)

ทิศการหมุน (convention ของหนังสือเล่มนี้)

มุมบวก = หมุนทวนเข็มนาฬิกา เช่น PHASE(45) → เข็มวง |1⟩ ชี้ไปทาง บน-ซ้าย (สำคัญตอนสอบวาดรูป)

|+⟩, |−⟩, |+Y⟩, |−Y⟩ (สถานะที่มีชื่อ)

superposition ที่ magnitude เท่ากัน (50/50) เหมือนกันหมด ต่างกันแค่ phase: |+⟩ = HAD (เข็มขึ้น) · |−⟩ = HAD→PHASE(180) (เข็มลง) · |+Y⟩ = HAD→PHASE(90) (เข็มซ้าย) · |−Y⟩ = HAD→PHASE(−90) (เข็มขวา). ทั้ง 4 ตัววัดแล้วได้ 50/50 เท่ากันหมด

Bloch sphere (ทรงกลมบล็อค)

วิธีมองภาพ qubit 1 ตัวเป็น ลูกศร 1 อันบนผิวทรงกลม — |0⟩ = ชี้ขึ้น (ขั้วเหนือ), |1⟩ = ชี้ลง (ขั้วใต้), superposition = ชี้ข้างๆ/เฉียง. gate = การหมุนลูกศรรอบแกน. สูตร: |ψ⟩ = cos(θ/2)|0⟩ + eiφ·sin(θ/2)|1⟩ โดย θ คุม magnitude (ความสูง) และ φ คุม relative phase (ทิศที่หัน)

ROTX(θ) / ROTY(θ) — Rotation gate (เกตหมุน)

หมุนลูกศรรอบ แกน X / แกน Y (แกนนอนทั้งคู่) → ลูกศรไต่ขึ้นลงระหว่างขั้ว → เปลี่ยน magnitude → เปลี่ยนโอกาสวัด · สร้าง superposition จาก |0⟩ ได้เองโดยไม่ต้องใช้ HAD · ROTX(π/2) กับ ROTY(π/2) ให้ superposition 50/50 คนละตัวกัน (phase ต่างกัน)

ROTZ = PHASE

PHASE คือการหมุนรอบ แกน Z ซึ่งเป็นแกนตั้ง (จาก |0⟩ ลงไป |1⟩) — ลูกศรจึงอยู่ ละติจูดเดิม = สูงเท่าเดิม = magnitude เท่าเดิม = โอกาสวัดเท่าเดิม (หมายเหตุ: slide 71 พิมพ์ว่า Z เป็นแกนนอน — พิมพ์ผิดค่ะ Z คือแกนตั้ง)

Z gate = PHASE(180)

PHASE ที่มุม 180° มีชื่อเล่นว่า Z matrix = [[1,0],[0,−1]] เป็นมุมพิเศษที่ เป็น its own inverse (180×2 = 360 = ครบรอบ) จะได้ใช้เต็มๆ ในบท 8 ตอนสร้าง NOT = HZH

บท 8–9 — ประกอบ gate, no-cloning, RNOT, QKD

No-cloning theorem (ทฤษฎีบทห้ามโคลน)

กฎฟิสิกส์ที่ว่า ก๊อป qubit ที่ไม่รู้ค่าไม่ได้ (ทั้ง superposition และตัวที่กำลังคำนวณอยู่) — เพราะการดึงค่าออกมาต้อง READ ซึ่งยุบ state ทิ้ง ก๊อปได้เฉพาะค่าที่รู้อยู่แล้วว่าเป็น |0⟩/|1⟩ (ใช้ WRITE เขียนใหม่). ฟังดูเป็นข้อจำกัด แต่คือหัวใจที่ทำให้ QKD จับสปายได้

COPY — คำสั่งที่ควอนตัมไม่มี

คอมธรรมดาก๊อปบิตได้ง่ายๆ แต่ควอนตัมไม่มีคำสั่ง COPY (เพราะ no-cloning) — ต้องใช้ gate อื่น ที่ทรงพลังกว่าชดเชย

ประกอบ gate: X = HZH, Z = HXH (gate decomposition)

เอา gate มาต่อกันสร้างตัวใหม่ได้ เหมือน logic gate ธรรมดา · X = HZH = สร้าง NOT จาก HAD + PHASE(180) · Z = HXH = สร้าง PHASE(180) จาก HAD + NOT · จำง่ายๆ ว่า H เป็นตัวสลับแกน X ↔ Z บน Bloch sphere

RNOT / √NOT — Root-of-NOT (รากที่สองของ NOT)

gate ที่ทำสองครั้ง = NOT หนึ่งที (√NOT·√NOT = NOT) — เป็น op ที่ไม่มีในลอจิกธรรมดา (พลิกบิตครึ่งเดียวไม่มีความหมายในโลกคลาสสิก แต่ควอนตัมทำได้เพราะมี superposition) · สัญลักษณ์ = กล่องมี √ · เท่ากับ H → PHASE(90) → H · เมทริกซ์มี i: ½[[1+i,1−i],[1−i,1+i]] · reversible แต่ไม่ใช่ its own inverse (ย้อนด้วย H·PHASE(−90)·H)

Its own inverse (ตัวย้อนของตัวเอง)

gate ที่ทำสองครั้งติดกันแล้วกลับที่เดิม เช่น NOT, HAD, Z, PHASE(180) · ตัวที่ไม่ใช่: PHASE(θ) ทั่วไป (ย้อนด้วย −θ), RNOT (ทำสองที = NOT, ย้อนด้วยเฟสลบ)

QKD — Quantum Key Distribution (การแจกกุญแจเชิงควอนตัม)

วิธีส่งข้อมูล/กุญแจที่ พิสูจน์ได้ทางฟิสิกส์ว่าปลอดภัย ใช้ qubit ตัวเล็กๆ (แค่ตัวเดียวก็พอ) จึงมีขายเชิงพาณิชย์แล้วจริง ก่อน quantum computer ยักษ์จะมา

Quantum Spy Hunter (โปรแกรมจับสปาย)

ตัวอย่าง QKD ในวิชานี้: Alice ส่ง qubit เป็น 1 ใน 4 สถานะ (|0⟩,|1⟩,|+⟩,|−⟩) สุ่มด้วย 2 บิต (send_val, send_had) → Bob สุ่ม recv_had เพื่อถอด · กติกาจับสปาย: เทียบเฉพาะตาที่ HAD ตรงกัน (send_had==recv_had) ถ้าค่าไม่ตรง (send_val!=recv_val) = มีสปาย! · สปายก๊อปไม่ได้ (no-cloning) ทำได้แค่ READ แล้วเดาฐานผิด → ทิ้งร่องรอย · โอกาสจับได้ 25% ต่อ qubit

บท 0008 — register หลาย qubit (Lec 03 หน้า 2–33)

Multi-qubit circle notation (สัญกรณ์วงกลมหลาย qubit)

register N qubit ใช้ 2N วง — หนึ่งวงต่อหนึ่งค่าที่ READ ออกมาได้ (ไม่ใช่ 2 วงต่อ qubit!) แต่ละวงเก็บ magnitude + relative phase เหมือนเดิม · 3 qubit = 8 วง (|0⟩…|7⟩) · 8 qubit = 256 วง

Product state / separable state (สถานะแยกได้)

สถานะหลาย qubit ที่เขียนแยกเป็นสถานะของ qubit เดี่ยวๆ ได้ เช่นสถานะ |0⟩+|2⟩+|4⟩+|6⟩ = "qubit 0x1 อยู่ที่ |0⟩ · อีกสองตัวอยู่ใน superposition" · สร้างได้ด้วย single-qubit gate ล้วนๆ

Entanglement (การพัวพัน)

สถานะที่แยกเป็นสถานะของ qubit เดี่ยวไม่ได้ ไม่ว่าจะพยายามยังไง · มีอยู่ได้เฉพาะระดับ ทั้งระบบ · สร้างด้วย single-qubit gate ไม่ได้ ต้องใช้ gate ข้าม qubit (CNOT) · ประโยคออกสอบ: superposition = สมบัติของ qubit เดี่ยว / entanglement = สมบัติของทั้งระบบ

GHZ state · Bell pair

GHZ = (|000⟩+|111⟩)/√2 — 3 qubit ที่อ่านแล้ว "ตรงกันเสมอ" (000 50% / 111 50%) ตัวอย่าง entanglement ตัวแรกในวิชานี้ · เวอร์ชัน 2 qubit เรียก Bell pair (|00⟩+|11⟩)/√2

Qubyte (ควอนตัมไบต์) · การตั้งชื่อ qubit ด้วยน้ำหนักบิต

เลิกเรียก Q1 Q2 Q3 แล้วเรียกตามน้ำหนักบิตเป็นเลขฐานสิบหก: 0x1 (LSB), 0x2, 0x4, 0x8, 0x10, 0x20, 0x40, 0x80 (MSB) · ครบ 8 ตัว = qubyte · ในวงจรของอาจารย์ เส้นบนสุด = 0x1 ไล่น้ำหนักเพิ่มลงล่าง

Operator pairs (คู่ตัวดำเนินการ)

กลไกที่ทำให้ gate เดี่ยวทำงานในทะเบียนใหญ่ได้: จับคู่วงที่ค่าต่างกันเท่ากับน้ำหนักบิตของ qubit ที่ยิง (ยิง 0x4 → จับคู่วงที่ต่างกัน 4) วงซ้าย = บิตนั้นเป็น 0, วงขวา = เป็น 1 · แล้วทำกับแต่ละคู่ เหมือนเป็น qubit เดียว · NOT = สลับสองวงในทุกคู่ · PHASE = หมุนเฉพาะวงขวาของทุกคู่ · gate เดี่ยวจึงกระทบครึ่งหนึ่งของสถานะเสมอ

READ qubit เดียว + renormalize (ปรับมาตรฐานใหม่)

P(0) = ผลรวม magnitude² ของวงซ้ายทุกคู่ · P(1) = ของวงขวา · หลังอ่าน: ลบวงที่ขัดกับผลทิ้ง แล้ว renormalize ให้พื้นที่รวมกลับเป็น 100% · การอ่าน qubit เดียวไม่ได้ยุบทั้ง register — ตัวที่เหลือยังเป็น superposition ต่อได้

qint (QCEngine)

อ็อบเจกต์ที่ห่อกลุ่ม qubit ให้เขียนเหมือนตัวแปรปกติ · qc.reset(n) จองทะเบียน · qint.new(จำนวน, 'ชื่อ') หยิบ qubit มาตั้งชื่อ · .had() ยิง HAD ให้ทุก qubit ใน qint นั้น

บท 0009 — CNOT กับ entanglement

Multi-qubit operation (ตัวดำเนินการหลาย qubit)

operation ที่ต้องใช้ qubit มากกว่าหนึ่งตัวถึงจะทำงานได้ (slide 40) — ตรงข้ามกับ single-qubit gate (NOT/HAD/PHASE) ที่ยิงใส่เส้นเดียว · มีแต่ multi-qubit gate เท่านั้นที่สร้าง entanglement ได้

CNOT (Controlled-NOT)

"NOT ตัว target ก็ต่อเมื่อ control มีค่าเป็น 1" · สัญลักษณ์ ● (control) เชื่อมเส้นตั้งไป ⊕ (target) · ในภาษา operator pairs: คู่มาจาก target · เงื่อนไขมาจาก control → กระทบ 1 ใน 4 ของวงทั้งหมด (single-qubit gate กระทบครึ่งหนึ่ง) · เป็น inverse ของตัวเอง · โค้ด: b.cnot(a) = target b, control a

Control qubit / Target qubit (คิวบิตควบคุม / คิวบิตเป้าหมาย)

control = ตัวที่เป็นเงื่อนไข ไม่ถูกเปลี่ยนค่า วาดเป็นจุดทึบ ● · target = ตัวที่ถูกกระทำ วาดเป็น ⊕ · วาดสลับข้าง = คนละวงจร

Bell pair (คู่เบลล์)

(|00⟩+|11⟩)/√2 · สร้างด้วย HAD ที่ control แล้ว CNOT จากสถานะ |0⟩ (slide 45–50) · circle notation: วง |0⟩ 50% กับ |3⟩ 50% · อ่านแล้วได้ผลสุ่มแต่ตรงกันเสมอ (00 หรือ 11 เท่านั้น) · ถ้าเริ่มจากสถานะอื่นจะได้ Bell state ตัวอื่น เช่น |1⟩+|2⟩ ที่ผลอ่านตรงข้ามกันเสมอ

Local hidden variables (ตัวแปรซ่อนเร้นเฉพาะที่)

สมมติฐานคลาสสิกว่า "ค่าถูกกำหนดไว้ล่วงหน้าแล้ว เราแค่มองไม่เห็น" + "ไม่มีอะไรเร็วกว่าแสง" · เป็นหนึ่งในสองคำอธิบายคลาสสิกของบิตสุ่มที่ตรงกัน (อีกแบบคือ common cause กับ communication, slide 54)

Bell's theorem · Bell inequalities (อสมการเบลล์)

John Bell พิสูจน์ว่าทฤษฎีคลาสสิกแบบ local hidden variable ทุกทฤษฎีต้องให้สหสัมพันธ์อยู่ในกรอบหนึ่ง · การทดลองจริงกับอนุภาคพัวพัน ละเมิดกรอบนั้นเสมอ → สรุปว่าไม่มีทฤษฎีคลาสสิกใดอธิบาย entanglement ได้ · กับดัก: ไม่ได้แปลว่าส่งข้อมูลเร็วกว่าแสงได้ (slide 58)

Shared randomness (ความสุ่มที่แชร์กัน)

แยก qubit ของ Bell pair ไปคนละที่ (entanglement ไม่สนระยะทาง) แล้วต่างคนต่างอ่าน → ได้เลขสุ่มตัวเดียวกันโดยไม่ต้องส่งอะไรหากัน · ใช้เป็นฐานของ cryptography · ส่งข้อความไม่ได้ เพราะไม่มีใครเลือกได้ว่าผลจะออกอะไร

บท 0010 — CPHASE, CZ และ phase kickback

CPHASE(θ) (คอนดิชันนัลเฟส)

gate สอง qubit ที่หมุน phase ของสถานะ |11⟩ เท่านั้น ด้วยมุม θ (สถานะอื่นไม่ขยับ) — เป็น PHASE ที่ใส่เงื่อนไขเพิ่ม · สัญลักษณ์ φ—φ เชื่อมด้วยเส้นตั้ง (slide 63)

Symmetric gate (เกตสมมาตร)

gate ที่สลับที่ qubit สองตัวแล้วผลเหมือนเดิม — CPHASE และ CZ เป็นแบบนี้ เพราะเงื่อนไขคือ “ทั้งคู่เป็น 1” ซึ่งสมมาตรอยู่แล้ว จึงไม่มี control/target ต่างจาก CNOT ที่บทบาทต่างกันชัดเจน

CZ (Controlled-Z)

กรณีพิเศษของ CPHASE ที่ θ = 180° → พลิกเครื่องหมาย (คูณ −1) ให้ |11⟩ · matrix = diag(1, 1, 1, −1) · สัญลักษณ์ ●—● · สร้างได้จาก H → CNOT → H (คู่ขนานกับ Z = H → X → H)

Conditioning as filtering (เงื่อนไขในฐานะตัวกรอง)

หลักคิดจาก slide 67–68: control แต่ละตัวคือตัวกรองที่บีบให้เหลือสถานะน้อยลงครึ่งหนึ่ง — k control → กระทบ 1 / 2k+1 ของทุกวง (PHASE เดี่ยว = ครึ่ง, CPHASE = 1/4, CCPHASE = 1/8)

Phase kickback (การเด้งกลับของเฟส)

ปรากฏการณ์ที่ phase ซึ่งเราตั้งใจใส่ให้ register ที่สอง (โดยมีเงื่อนไขจาก qubit ของ register แรก) กลับไปปรากฏบนค่าใน register แรกแทน — เพราะ CPHASE สมมาตร และ register ที่สองคงที่ เงื่อนไข: register ที่สองต้องเป็น |1⟩ และต้องไม่อยู่ใน superposition (slide 73–79)

Separable state (สถานะที่แยกกันได้)

สถานะรวมที่เขียนเป็นผลคูณ (tensor product) ของสถานะแต่ละส่วนได้ = ไม่ entangled → คิดแยกทีละ register ได้ตามปกติ · ผลลัพธ์ของ phase kickback เป็นแบบนี้ — เป็นตัวอย่างค้านว่า “ใช้ gate สอง qubit ≠ ได้ entanglement เสมอไป” (slide 79–80)

Lesson พิเศษ — Majorana / Topological qubit (paper Microsoft 2025)

Topological qubit (คิวบิตเชิงทอพอโลยี)

qubit ที่เก็บข้อมูลไว้ใน คุณสมบัติเชิงโครงสร้างที่กระจายตัว ไม่ใช่ที่จุดเดียว → รบกวนเฉพาะจุดไม่ทำให้ข้อมูลหาย = ทน error ตั้งแต่ระดับฮาร์ดแวร์/ฟิสิกส์ (ต่างจาก physical qubit ปกติที่เปราะและต้องพึ่ง error correction ระดับซอฟต์แวร์)

Majorana zero mode — MZM (โหมดพลังงานศูนย์มาโยรานา)

quasiparticle (อนุภาคกึ่งๆ) พิเศษที่โผล่ที่ ปลายทั้งสองข้างของเส้นลวดตัวนำยิ่งยวด ชนิด topological · MZM หนึ่งคู่เก็บ qubit ได้ 1 ตัว โดยเข้ารหัสข้อมูลไว้ใน fermion parity ร่วมของทั้งคู่ · เป็นทฤษฎีมานาน แต่พิสูจน์ว่าเจอตัวจริง ยากมากเพราะ Andreev bound state ให้สัญญาณคล้ายกันได้

Fermion parity / Parity (พาริตี — คู่/คี่)

จำนวนอิเล็กตรอนรวมของระบบเป็น คู่หรือคี่ · เป็นที่เก็บข้อมูลของ topological qubit · quasiparticle 1 ตัวที่หลุดเข้ามา (poisoning) จะ flip parity = ทำให้ qubit ผิด

Single-shot parity measurement (การวัดพาริตีครั้งเดียวจบ)

อ่านค่า parity ได้ในการวัดครั้งเดียว (ไม่ต้องเฉลี่ยหลายรอบ) · เป็นก้าวจำเป็นของ topological qubit · paper วัดได้ที่ error ~1% — ⚠️ นี่คือ assignment error ของการอ่าน ไม่ใช่ gate error/logical error

Interferometry (การแทรกสอด) + Quantum dot

เทคนิคที่ paper ใช้อ่าน parity: ต่อเส้นลวดเข้ากับ quantum dot เป็นวง (loop) ให้ อิเล็กตรอนเดิน 2 เส้นทางมาแทรกสอดกัน · ความเข้มสัญญาณ (ผ่าน “quantum capacitance” ของ dot) ขึ้นกับ parity → อ่าน parity ทางอ้อมได้ · สัญญาณมีคาบตามฟลักซ์แม่เหล็ก = h/2e

Andreev bound state (ABS)

สถานะพลังงานต่ำที่เกิดจากความไม่สมบูรณ์/disorder ของวัสดุ · ให้สัญญาณ “หน้าตาเหมือน MZM” ได้ → ตัวการที่ทำให้แยก “Majorana จริง” ออกจาก “ของปลอม” ยากมาก · paper ยอมรับเองว่าการวัดนี้ โดยลำพัง ยังแยก MZM ออกจาก fine-tuned ABS ไม่ได้

บท 0011 — CCNOT, SWAP, CSWAP และ SWAP test

CCNOT / Toffoli (คอนดิชันนัลนอต 2 เงื่อนไข)

NOT ที่มี 2 control — พลิก target ก็ต่อเมื่อ control ทั้งสองเป็น |1⟩ พร้อมกัน (“if A AND B then flip C”) · สัญลักษณ์ ●●⊕ · 2 control → กระทบ 1 คู่วง · เป็น universal สำหรับ logic (ต่อกันสร้าง logic function อะไรก็ได้) (slide 85–87)

SWAP / exchange (สลับ)

gate ที่สลับที่กันของสอง qubit · สัญลักษณ์ ×—× · ประกอบขึ้นจาก 3 CNOT (สลับหัว-ท้าย-หัว) · เดี่ยวๆ บนสถานะฐานไม่สร้าง entanglement (slide 88–89)

CSWAP / conditional exchange (สลับแบบมีเงื่อนไข)

SWAP ที่เติม control — สลับก็ต่อเมื่อ control = |1⟩ · สัญลักษณ์ ● + ×—× · ประกอบจาก 3 CCNOT · ถ้า control อยู่ใน superposition จะได้ผลเป็น superposition ของ “สลับ” กับ “ไม่สลับ” พร้อมกัน (slide 90–91)

SWAP test

วงจรที่เทียบว่าสองสถานะ เหมือนกันแค่ไหน โดยไม่วัดทำลาย — โครง: ancilla |0⟩ → H → CSWAP (ancilla คุมการสลับ input1/input2) → H → READ ancilla · ใช้ interference ของสองเส้นทาง (สลับ/ไม่สลับ) · เวอร์ชัน 5 สเต็ป: ancilla = 0 → เหมือน · P(0) = (1 + |⟨a|b⟩|²)/2 · ระวัง: โค้ดสไลด์เติม output.not() ทำให้กลายเป็น 1 = เหมือน (slide 92–104)

Ancilla qubit (คิวบิตตัวช่วย)

qubit เสริมที่ใส่เข้ามาช่วยคำนวณ/อ่านผล ไม่ใช่ข้อมูลหลัก — ใน SWAP test คือ qubit ที่เรา H → คุม CSWAP → H → READ เพื่ออ่านผลการเทียบ (ผลลัพธ์ทั้งหมดออกมาที่ ancilla ตัวเดียว)

Fidelity (ความเที่ยง/ความเหมือน)

การย้ายสถานะควอนตัมที่แน่นอนของ qubit หนึ่งไปยัง qubit อีกตัว ครบทั้ง magnitude และ relative phase · ไม่ใช่การย้ายอนุภาค/สสาร — qubit ทั้งสองอยู่ที่เดิมตลอด · ใช้ 3 qubit + บิตคลาสสิก 2 บิต · ทำงานได้แม้ผู้ส่งไม่รู้ว่าสถานะคืออะไร (slide 8, 13)

Payload (สถานะที่จะส่ง)

เลขคณิตที่ถูกออกแบบใหม่ให้ operation ครั้งเดียวส่งผลต่อทุกค่าใน superposition พร้อมกัน · ยกวงจรบวกเลขของคอมพิวเตอร์เดิมมาใช้ตรงๆ ไม่ได้ เพราะวงจรเดิมออกแบบมาเพื่อ อินพุตชุดเดียวต่อครั้ง (slide 2–3)

Moving vs copying (ย้าย ≠ คัดลอก) · exchange instruction

กติกาข้อ 1 ของ operation บน QPU: qubit คัดลอกไม่ได้ · ย้ายได้ด้วย exchange instruction (คำสั่งสลับค่า) = SWAP ซึ่งค่าเดิมที่ต้นทางหายไป · ไม่มี QPU ตัวไหน implement คำสั่ง COPY → operator = ใช้กับ qubit ไม่ได้ (slide 8 · ต่อยอดจาก no-cloning บท 8–9)

Reversibility / irreversible (ย้อนกลับได้ / ย้อนกลับไม่ได้)

กติกาข้อ 2: operation พื้นฐานของ QPU ทุกตัวที่ไม่ใช่ READ ต้องย้อนกลับได้ — คือดูจากเอาต์พุตต้องบอกอินพุตได้เสมอ · READ เป็น operation เดียวที่ irreversible · gate แบบเดิมอย่าง AND (2 เข้า 1 ออก) ทำข้อมูลหาย จึงยกมาใช้ตรงๆ ไม่ได้ · วิธีย้ายวงจรคลาสสิกลง QPU = แทนที่ด้วยวงจรสมมูลที่ใช้เฉพาะ operation ย้อนกลับได้ เช่น Toffoli (slide 9) · ⚠️ ใช้ READ พร่ำเพรื่อเพื่อเลี่ยงกติกานี้ = quantum advantage หายหมด

บท 0018 — increment / decrement (Lec 05 หน้า 12–23)

Increment / decrement (เพิ่มค่าทีละ 1 / ลดค่าทีละ 1)

operation เลขคณิตที่ง่ายและใช้บ่อยที่สุดกับ quantum integer · บน qunibble 4 qubit วงจร increment = NOT ที่มี 3 control (→0x8) · CCNOT (→0x4) · CNOT (→0x2) · NOT เดี่ยว (→0x1) เรียงจาก control เยอะสุดไปน้อยสุด · decrement = วงจรเดิมที่เรียง gate ย้อนลำดับทั้งกล่อง · โค้ด QCEngine: a.add(1) / a.subtract(1) (slide 12–14)

ทำไมต้องเรียงแบบนั้น: เงื่อนไขการทดทุกข้ออ้างถึงค่าบิตล่างก่อนบวก ถ้าพลิกบิตต่ำสุดก่อน gate ที่เหลือจะอ่านค่าที่เปลี่ยนไปแล้ว → ผลผิด

① Reversibility — ย้อนกลับได้ (decrement คือ increment กลับลำดับ) · ② Superposition operation — ทำงานกับ input ที่เป็น superposition ได้ · พิสูจน์ด้วย circle notation: (∣1⟩ + ei45°∣5⟩)/√2 → (∣2⟩ + ei45°∣6⟩)/√2 = เลื่อนทุกวงพร้อมกันโดยพก magnitude และ phase ติดไปด้วย (slide 15–20)

บท 0019 — a += b และเลขติดลบ (Lec 05 หน้า 24–32)

+= operator บน quantum register (บวกทับ)

c = a + b แบบ CPU ใช้บน QPU ไม่ได้ เพราะละเมิดทั้งสองกติกา — ทับของเดิมใน c (ไม่ reversible) และเปิดช่องให้คำนวณ b = c − a ต่อ = คัดลอก superposition ของ a · ทางออกคือ a += b บวก b ลงบน a โดยตรง (b ไม่ขยับ ทำหน้าที่ control อย่างเดียว) → ย้อนด้วย a -= b ได้ (slide 24)

= increment chain ของบท 0018 ที่พ่วง ● จากบิตของ b เข้าไปในทุก gate · ทำซ้ำ 1 รอบต่อ 1 บิตของ b และจุดเริ่มของ chain เลื่อนขึ้นตามน้ำหนักของบิตนั้น (b·0x1 → เริ่มที่ a·0x1 · b·0x2 → เริ่มที่ a·0x2 และสั้นลง 1 gate) · ตัวอย่างในสไลด์: a 4 qubit + b 2 qubit = 7 คอลัมน์ มี gate ที่มีถึง 4 control · a.add(b) / a.subtract(b) (= ชุดเดิมเรียงย้อนลำดับ) · ข้อได้เปรียบสำคัญ: ไม่ต้องเปลี่ยน gate เมื่อ input เปลี่ยน ต่างจาก add(12) ของบท 0018 (slide 25–26)

Two's complement (ทูส์คอมพลีเมนต์ / เลขเติมเต็มฐานสอง)

วิธีแทนจำนวนเต็มลบที่ CPU และภาษาโปรแกรมสมัยใหม่ใช้กันหมด — แบ่งค่าครึ่งหนึ่งให้จำนวนลบ อีกครึ่งให้จำนวนบวก · register 3 บิต: 000..011 = 0,1,2,3 · 100..111 = −4,−3,−2,−1 · ข้อดี: วงจรเลขคณิตของจำนวนบวกใช้ได้ทันทีไม่ต้องแก้ (เช่น 111 + 1 = 000 คือ −1+1 = 0 พอดี) · ใช้กับ register ของ qubit ได้เหมือน register บิตธรรมดา · ⚠️ เป็นแค่ข้อตกลงในการตีความ — 111 จะแปลว่า 7 หรือ −1 ขึ้นกับข้อตกลง (slide 27–29)

ผลพลอยได้ของ two's complement: บิตน้ำหนักสูงสุดเป็น 0 = จำนวนบวก · เป็น 1 = จำนวนลบ เสมอ ไม่ต้องเก็บเครื่องหมายแยก · บท 0020–0021 จะยืมบิตนี้ไปทำเงื่อนไขและ scratch qubit (slide 28)

Negate (การกลับเครื่องหมาย) — a = -a

ใน two's complement = พลิกทุกบิต แล้วบวก 1 · วงจร = NOT พร้อมกันทุกสาย ตามด้วย increment chain เดิม · เช่น 4 บิต: 3 = 0011 → พลิก 1100 → +1 1101 = −3 ✓ · ข้อยกเว้น: ค่าลบสุดของช่วง (เช่น −4 ใน 3 บิต) negate แล้ว ได้ตัวเดิม เพราะ +4 อยู่นอกช่วง — เหมือน INT_MIN ในภาษาทั่วไป (slide 30)

addSquared (บวกกำลังสอง) — a += b*b

การคูณทำแบบย้อนกลับได้ยาก · b = b*b เป็นไปไม่ได้เลย เพราะ b และ −b ยกกำลังสองได้ค่าเดียวกัน → เสีย sign bit ถาวร (ปัญหาระดับทฤษฎีสารสนเทศ ไม่ใช่แค่หา gate ไม่เจอ) · แต่ a += b*b ทำได้ เพราะ b ยังอยู่ครบ ย้อนด้วย a -= b*b · วงจร 12 คอลัมน์ สร้างจาก b = b₀ + 2b₁ → b² = b₀ + 4·b₀b₁ + 4·b₁ (บวก 1 ถ้า b₀ · บวก 4 ถ้า b₀∧b₁ · บวก 4 ถ้า b₁) · a.addSquared(b) (slide 31–32)

บท 0020 — เงื่อนไขแบบควอนตัม และคำตอบในเฟส (Lec 05 หน้า 33–38)

Quantum-conditional execution (การทำงานตามเงื่อนไขแบบควอนตัม)

CPU ทำ if โดยอ่านค่าเงื่อนไขออกมาดูก่อน แล้วเลือกเส้นทางเดียว · QPU ไม่ต้องอ่าน — ค่าเงื่อนไขเป็นทั้งเซ็ตและไม่เซ็ตพร้อมกันได้ ดังนั้น logic ที่ขึ้นกับค่านั้น ทั้งรันและไม่รันพร้อมกันใน superposition · วิธีทำ: เอา ● ของ qubit เงื่อนไข ไปแปะเพิ่มในทุก gate ของ logic ก้อนนั้น (จำนวน gate เท่าเดิม แค่ control เพิ่มตัวละ 1 จุด) — วิธีคิดเดียวกับ a += b ของบท 0019 (slide 33–34)

ทริกยืมบิตเครื่องหมาย (เลื่อนค่าให้เงื่อนไขยุบเหลือบิตเดียว)

● เช็คได้แค่ “qubit เส้นนี้เป็น 1 ไหม” ไม่ใช่ช่วงตัวเลข → อยากได้เงื่อนไข a < 3 ก็ทำ a -= 3 ก่อน ค่าที่น้อยกว่า 3 จะติดลบ = บิตเครื่องหมาย 0x4 ติด 1 พอดี แล้วใช้บิตนั้นเป็น control · เสร็จแล้ว a += 3 คืนสภาพ (= uncompute) · เงื่อนไขจริงคือ a ∈ {7, 0, 1, 2} (คือ a < 3 หรือ a > 6) เพราะ register วนกลับ mod 8 · ⚠️ สไลด์ p35 เขียน “lowest-weight qubit” ขัดกับโค้ด a.bits(0x4) ที่เป็นบิตสูงสุด (slide 34–36)

b.not(~1) — แปลง “เท่ากับ 1” ให้เป็น “1 ทุกบิต”

เงื่อนไข b == 1 แปลว่า b·0x1 = 1 และ b·0x2 = 0 — แต่ ● อ่านได้แค่เลข 1 · จึงพลิกทุกบิตของ b ยกเว้นบิต 0x1 ด้วย X ก่อน เพื่อให้เงื่อนไขกลายเป็น “ทุกบิตเป็น 1” แล้วใช้ b.bits() ทั้งชุดเป็น control ได้ · เสร็จแล้วพลิกกลับ (uncompute ซ้อนอีกชั้น) (slide 37)

Phase-encoded result (ผลลัพธ์ที่เข้ารหัสในเฟส)

ใช้วงจรโครงเดิมของ conditional execution แต่เปลี่ยนไส้กลางจาก increment เป็น qc.phase(180, …) = CZ หลายขา → สถานะที่เข้าเงื่อนไขถูกพลิกเฟส 180° · magnitude ไม่ขยับเลยสักวง → READ แล้วได้ความน่าจะเป็นเท่าเดิมเป๊ะ มองไม่ออกว่ามี operation นี้เกิดขึ้น · คำตอบถูก “ทำเครื่องหมาย” ไว้ในเฟสเท่านั้น = ฐานของ oracle / phase kickback ที่ Grover และ Shor ยืนอยู่บน · ⚠️ ยังอ่านคำตอบไม่ได้จนกว่าจะมีขั้นตอนแปลงเฟส → magnitude (amplitude amplification, Lec 06) (slide 37–38)

บท 0021 — scratch qubit และ abs(a) (Lec 05 หน้า 39–45)

Scratch qubit (คิวบิตทด)

qubit ที่ไม่ได้ใช้เก็บอินพุตหรือเอาต์พุตที่เราสนใจ แต่ทำหน้าที่ชั่วคราว เพื่อให้ตรรกะที่เชื่อมอินพุต → เอาต์พุตเป็นไปได้ · เริ่มต้นที่ ∣0⟩ เสมอ · ใช้เป็นที่พักข้อมูลที่กำลังจะหาย ทำให้ operation ที่ irreversible กลายเป็น reversible · ⚠️ ใช้แล้วมันไม่กลับเป็น ∣0⟩ เอง และยัง entangled อยู่ → ต้อง uncompute (บท 0021b) (slide 39, 42–43)

abs(a) — ตัวอย่างมาตรฐานของ operation ที่ทำตรงๆ ไม่ได้

abs ไม่ใช่ฟังก์ชัน 1-ต่อ-1 (−3 กับ 3 ให้ 3 เหมือนกัน) → ข้อมูลเครื่องหมายหาย → ย้อนกลับไม่ได้ → ไม่มีชุด gate ไหนทำได้เลย · ประโยคที่สไลด์เน้น: “it’s not that we’ll receive a QPU compile or runtime error” — ไม่มี error ให้เห็น แต่หาวงจรไม่เจอ เพราะเป็นปัญหาระดับทฤษฎีสารสนเทศ ไม่ใช่ระดับเครื่องมือ (slide 40–41)

วงจร abs(a) 4 สาย (a 3 บิต + scratch 1 บิต)

① CNOT จากบิตเครื่องหมาย a·0x4 → scratch (“XOR sign bit into scratch”) ② negate a แบบ two’s complement โดยมี ● ที่ scratch พ่วงในทุก gate (= วงจร negate ของบท 0019 เป๊ะๆ แค่เติม control หนึ่งจุดต่อ gate) · เอาต์พุต: สาย a → abs(a) · สาย scratch → sign(a) · เครื่องหมายไม่ได้หาย แต่ย้ายที่ → เอาต์พุตรวมกลับมาเป็น 1-ต่อ-1 → reversible · ⚠️ abs(−4) ยังเป็น −4 เพราะ register 3 บิตเก็บได้แค่ −4 ถึง 3 (เหมือน abs(INT_MIN) ในภาษา C) (slide 42–44)

CNOT ที่ scratch = entangle ไม่ใช่ copy

สไลด์ย้ำตรงๆ ว่า CNOT ระหว่าง a·0x4 กับ scratch ไม่ได้คัดลอก qubit (QPU copy ไม่ได้ — no-cloning) แต่ทำให้ scratch พัวพันกับบิตเครื่องหมาย · ผลลัพธ์ดูเหมือน copy เฉพาะตอนที่ a เป็นสถานะฐานตัวเดียว — ถ้า a อยู่ใน superposition จะได้สถานะพัวพัน ไม่ใช่สำเนาสองชุด (slide 43)

ทำไม scratch แก้ irreversibility ได้ (อ่านจาก circle notation)

ผังกลายเป็น 2 แถว × 8 คอลัมน์ — คอลัมน์ = ค่าของ a (0,1,2,3,−4,−3,−2,−1) · แถว = ค่าของ scratch · ค่าลบถูกย้ายลงแถวล่างก่อน แล้วค่อยเลื่อนแนวนอนไปช่องค่าบวก → ไม่ไปทับของเดิมในแถวบน · ถ้าไม่มี scratch ผังจะมีแถวเดียว การเลื่อนจะทับทั้ง magnitude และเฟสของช่องปลายทาง → กู้คืนไม่ได้ · scratch = การเปิด “ชั้นที่สอง” ให้ย้ายลงไปโดยไม่ชนใคร (slide 44–45)

บท 0021b — uncomputing (Lec 05 หน้า 46–54)

ปัญหา 2 ข้อของ scratch qubit

① scratch แทบไม่เคยกลับไปเป็น ∣0⟩ เอง — แต่เราต้อง reset มันเพื่อเอาไปใช้ในขั้นถัดไป · ② จะ READ แล้ว NOT ทิ้งก็ไม่ได้ เพราะการใช้ scratch ทำให้มัน entangled กับ output register เกือบทุกครั้ง → การ READ มันจะทำลายครึ่งหนึ่งของ quantum state ของ a ไปด้วย · สองข้อนี้เกี่ยวโยงกัน และทั้งคู่มีต้นเหตุเดียวคือ entanglement (slide 46–47)

Uncomputing (การย้อนคำนวณ)

= รัน operation ที่ทำให้ scratch entangled ย้อนลำดับ เพื่อพามันกลับสู่ ∣0⟩ ที่ไม่ entangled เหมือนตอนเริ่ม · ทำได้เพราะ gate ทุกตัวของ QPU (ยกเว้น READ) reversible · ⚠️ ย้อนแล้วคำตอบก็หายไปด้วย — “เราได้ scratch คืน แต่ก็ล้างงานคำนวณ absolute value ทั้งหมดทิ้งไปด้วย” (slide 47–48)

สูตร compute → use → uncompute (คำนวณ–ใช้–ย้อน)

ทางออกคือ ใช้คำตอบเสียก่อน แล้วค่อย uncompute — แทรกขั้น “use” ไว้ตรงกลาง ผลลัพธ์จึงไปตกอยู่ที่ register อื่น (b) ที่กล่อง uncompute ไม่ย้อน · ตัวอย่างมาตรฐาน b += abs(a): วงจร 7 สาย 3 กล่อง — compute abs(a) (5 คอลัมน์) · b += abs(a) (6 คอลัมน์ ไม่แตะสาย scratch เลย) · uncompute abs(a) (5 คอลัมน์ = กล่องแรกกลับหลัง) · จบแล้ว b ถูก · a เท่าเดิม · scratch = ∣0⟩ disentangled พร้อมใช้ใหม่ · ก้อนใหญ่ทั้งก้อนกลายเป็น reversible ทั้งที่ abs เพียวๆ ไม่ reversible · เทคนิคนี้พบบ่อยมากใน quantum computation (slide 49–51)

ทางลัด: b ^= abs(a) ด้วย CNOT

ถ้ารู้ว่า b เริ่มต้นที่ 0 ไม่ต้องใช้วงจรบวก 6 คอลัมน์ — ใช้ CNOT 3 ตัว (a·0x1→b·0x1, a·0x2→b·0x2, a·0x4→b·0x4) ก็พอ เพราะ 0 + x = 0 XOR x = x · ⚠️ ไม่ใช่การ copy — ใช้ได้เฉพาะตอน b = 0 และผลที่ได้คือ b entangled กับ a ไม่ใช่สำเนาอิสระ กฎ no-copying ยังอยู่ครบ (slide 51–52)

phase(180) if abs(a)==1 — uncompute แบบเก็บผลไว้ในเฟส

วงจร 4 สาย (a 3 บิต + scratch) — compute abs(a) → Z if abs(a)==1 (NOT ที่ a·0x2 และ a·0x4 คร่อมหัวท้าย เพื่อแปลงเงื่อนไข 001 ให้เป็น “ทุกบิตเป็น 1” แล้ว CZ 3 ขา · ไม่แตะสาย scratch เลย) → uncompute abs(a) · ตราบใดที่กล่อง compute/uncompute ไม่ไปยุ่งกับ relative phase ของ output register เฟสที่ mark ไว้จะรอดออกมาครบ = ฐานของ oracle (slide 52–53)

Walkthrough 5 สแนปช็อต (ยืนยันจากสไลด์จริงแล้ว)

กริด 16 วง · คอลัมน์ = ค่า a (0,1,2,3,−4,−3,−2,−1) · แถว = scratch · ทุกวงมี magnitude เท่ากัน (1/√8) · ชมพู = เฟส 0 (เข็มชี้ขึ้น) · เขียว = เฟส 180° (เข็มชี้ลง) · ① หลัง H: แถวบนเต็ม 8 วง ② หลัง CNOT แรก: ค่าลบย้ายลงแถวล่าง (∣12⟩–∣15⟩) ③ จบ compute: แถวล่างกลายเป็น ∣9⟩–∣12⟩ (abs = 1,2,3,4) ④ จบ Z: ขนาดวงไม่ขยับเลย แต่ ∣1⟩ กับ ∣9⟩ กลายเป็นเขียว ⑤ จบ uncompute: แถวล่างว่างสนิท (scratch คืน ∣0⟩) แถวบนเต็ม 8 วง โดย ∣1⟩ (a=+1) และ ∣7⟩ (a=−1) เป็นเขียว · บทเรียน: เฟสติดไปกับ “กิ่ง” ไม่ได้ติดกับช่องเลข — uncompute ย้ายกิ่งกลับที่เดิม เฟสจึงเดินทางตามไปด้วย (slide 54)

บท 0022 — Toffoli คือ NAND ของโลกควอนตัม (Lec 05 หน้า 55–61)

universal gate (เกตครบชุด)

เกตที่ต่อกันเองแล้วสร้างฟังก์ชันลอจิกอะไรก็ได้ · ฝั่งดิจิทัลคือ NAND (มี NAND อย่างเดียวก็สร้าง AND, OR, NOT, XOR ได้ครบ) · NAND มีขาเข้ากี่ขาก็ได้ — ขาเดียว = NOT (slide 55–56)

multiple-condition CNOT = Toffoli gate

เกตอเนกประสงค์ฝั่งควอนตัม · เปลี่ยนจำนวน condition ได้เหมือน NAND เปลี่ยนจำนวนขาเข้า: 0 condition = NOT เดี่ยว · 1 condition = CNOT · 2 conditions = Toffoli (slide 57)

สมการของ Toffoli: c = c XOR (a AND b)

นี่คือตัวเทียบเท่าฝั่งดิจิทัลแบบเป๊ะๆ ของ multi-condition CNOT · ผังลอจิก: a, b วิ่งผ่านออกไปเป็น output ชื่อเดิม (มีจุดแยกสัญญาณ ● บนเส้น) → สัญญาณที่แยกออกมาเข้า AND → ผลของ AND เข้า XOR พร้อมกับเส้น c → ได้ c ตัวใหม่ · ต่างจาก NAND ตรงที่ NAND เขียนทับ output ทิ้ง (irreversible) แต่ Toffoli XOR ใส่ c เดิมและเก็บ a, b ไว้ครบ → ย้อนกลับได้ (slide 58)

ตาราง 6 ประตูลอจิกที่สร้างจาก Toffoli (ออกสอบ)

ทุกช่องเรียงสายบนลงล่าง a, b, c และ a, b ออกมาเหมือนเดิมทุกช่อง:
a = NOT a → X:0 · b = a XOR b → CNOT:0,1 · c = a AND b → WRITE:2; CCNOT:0,1,2 · c = a OR b → X:0 + X:1; CCNOT:0,1,2; X:0 + X:1 + X:2 · c = a NAND b → WRITE:2; CCNOT:0,1,2; X:2 · c = a NOR b → X:0 + X:1; CCNOT:0,1,2; X:0 + X:1
OR กับ NOR ต่างกันแค่ ⊕ ตัวเดียวบนสาย c ในคอลัมน์สุดท้าย (slide 59–60)

De Morgan ในวงจร OR / NOR

NOT a AND NOT b = NOT (a OR b) → พลิก a, b ก่อน แล้ว Toffoli จะได้ NOR ออกมา · ⊕ สองตัวคอลัมน์สุดท้ายคือ “คืนค่า a, b” (มีทั้ง OR และ NOR) ส่วน ⊕ ตัวที่สามบนสาย c คือ “พลิก NOR ให้เป็น OR” (มีเฉพาะฝั่ง OR)

ทำไม c ต้องเริ่มที่ ∣0⟩

วงจรพวกนี้ทำ c = c XOR f(a,b) เสมอ → จะเท่ากับ c = f(a,b) ตามป้ายก็ต่อเมื่อ c เริ่มที่ ∣0⟩ (เพราะ 0 XOR f = f) · นี่คือเหตุผลที่ 4 ช่องล่างวาด ▷∣0⟩ ที่หัวสาย c · ถ้าให้ c เริ่มที่ ∣1⟩ ช่อง AND จะกลายเป็น NAND ทันที · ช่อง NOT กับ XOR ไม่ต้องใช้ scratch เพราะเขียนผลทับสาย input ได้เลยโดยยังย้อนกลับได้ (slide 59–60)

ต้นทุน scratch qubit

สไลด์ p60: “หนึ่งในความท้าทายใหญ่ของ quantum computation คือการลดจำนวน scratch qubit ที่ต้องใช้ในการคำนวณหนึ่งๆ” — qubit บนเครื่องจริงแพงและมีจำกัด · uncomputing (บท 0021b) จึงไม่ได้มีไว้แค่ให้วงจรถูก แต่มีไว้คืน scratch ไปใช้ซ้ำ

ค่า pixel อยู่ใน phase ของ superposition: 0° (ชมพู ชี้ขึ้น) = ไม่ระบาย · 180° (เขียว ชี้ลง) = ระบาย · เลือกวิธีนี้เพราะเข้ากับ flip ของ amplitude amplification · ข้อแม้: READ ตรงๆ ได้แค่ qx, qy สุ่ม (p10, p14)

บท 0042 — วาดรูปลงใน phase (Lec 11 หน้า 15–21)

dither pattern (ลายจุดสลับ) · 50% gray

เรียงจุดระบาย/ไม่ระบายสลับกันถี่ๆ ให้เฉลี่ยแล้วเป็นสีเทา · Figure 11-6: flip เมื่อ qx ≥ 8 และ qy ≥ 8 และบิต 0x1 ของ qx ≠ qy → มุมขวาล่างเป็นลายหมากรุก (เขียว 32 จาก 64) เพราะ flip ซ้ำบนที่เขียวอยู่แล้ว · วงจร = CNOT – CZ 3 จุด – CNOT (p15–16)

subtractShifted / addShifted กับลายทางเฉียง

qx.subtractShifted(qy, 1) = qx ← qx − 2·qy (เลื่อน 1 บิต = คูณ 2 · mod 16) · ประกบ qc.phase(180, qx.bits(0x8)) แล้ว addShifted คืนค่า → flip เมื่อ (qx − 2·qy) mod 16 ≥ 8 = แถบกว้าง 8 เลื่อนขวาแถวละ 2 วนซ้ำทุก 8 แถว (Figure 11-7, p17)

qacc (accumulator · ตัวสะสมผลบวก) กับเสี้ยววงกลม

register แยกไว้ทดเลข (หน้าที่เดียวกับ scratch) · Example 11-2: qx 4 + qy 4 + qacc 10 = 18 qubit · addSquared(qx), addSquared(qy), subtract(r*r) → qacc.phase(180, 1 << (acc_bits - 1)) (flip ที่บิตเครื่องหมาย = ผลติดลบ = x² + y² < r²) → ย้อนกลับ 3 บรรทัด · รัศมี 13 → r² = 169 (Figure 11-8, p18–20)

overflow → curved bands (แถบโค้ง)

tile (ช่องย่อยของภาพ) · tx / ty (เลขช่องแบบ digital)

แบ่งผ้าใบ 16×16 เป็น 16 tile ขนาด 4×4 · 1 tile ย่อเหลือ 1 pixel ของภาพผลลัพธ์ · วาดทีละ tile: qx, qy เหลือ 2 qubit (ตำแหน่งในช่อง) · tx, ty เป็นเลขธรรมดา · x จริง = qx + 4·tx · qacc 4 qubit เก็บพิกัดจริง (p22–23, Figure 11-9) · ภาพจริง 256×256 = 4,096 tile × 16 subpixel (p29)

วาดเส้นด้วย accumulator · ทริก not(~N)

qacc.cnot(q) → add(t*4) → not(~N) → cphase(180) → ย้อน 3 ขั้น · not(~N) = NOT บิตที่ N เป็น 0 → "qacc == N" กลายเป็น "ทุกบิตเป็น 1" ให้ CZ เช็คได้ (~3 → 0x4, 0x8 · ~10 → 0x1, 0x4) (Figure 11-10, p25–27)
