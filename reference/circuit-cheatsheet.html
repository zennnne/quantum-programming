สัญลักษณ์ Quantum Circuit — ชุดที่ต้องท่องสอบ

รวมสัญลักษณ์ของแต่ละ gate ที่ใช้ในวงจรควอนตัม ออกแบบให้พิมพ์ใส่กระดาษท่องก่อนสอบได้ หน้านี้ โตขึ้นเรื่อยๆ ทุกครั้งที่เราเรียน gate ใหม่ในบทเรียน

สำคัญมากก่อนท่อง!

อาจารย์ใช้สัญลักษณ์สไตล์ QCEngine / หนังสือ O'Reilly — ไม่ใช่ แบบ Qiskit (กล่องเหลี่ยมล้วน) ที่เจอทั่วเน็ต ถ้าไปท่องผิดสไตล์จะงงในห้องสอบได้ ยึดตามหน้านี้ (เทียบกับ slide Lec 02 ได้ตามเลขหน้าที่กำกับไว้)

ความคืบหน้า: 8 สัญลักษณ์เดี่ยว (บท 4–9) + CNOT (บท 0009) + CPHASE/CZ + วงจร phase kickback (บท 0010) + CCNOT · SWAP · CSWAP · วงจร SWAP test (บท 0011) + สัญลักษณ์เชิงโครงสร้าง (write ▷ · ลูกศรประคลาสสิก · กล่องมีชื่อ) + วงจร teleportation + ผัง 8 วง (บท 0014) · สไตล์ IBM/Qiskit เทียบ QCEngine (บท 0016) + control หลายจุด / target หลายตัว · CZ 3 จุด · ประตูลอจิกดิจิทัล 6 ตัว (Lec 05)

วิธีอ่านวงจร (กติกาพื้นฐาน)

  • 1 เส้นนอน = 1 qubit เวลาไล่โปรแกรม อ่าน ซ้าย → ขวา (เหมือนอ่านหนังสือ)
  • สัญลักษณ์ที่วางบนเส้น = คำสั่ง (gate) ที่กระทำกับ qubit นั้น ตามลำดับเวลา
  • ปกติเริ่มด้วย WRITE (ตั้งค่า) ซ้ายสุด และจบด้วย READ (วัด) ขวาสุด

คำสั่งที่เรียนแล้ว (บท 4–9)

WRITE

ตั้งค่าเริ่มต้น qubit ให้เป็น |0⟩ หรือ |1⟩ (แน่นอน ไม่สุ่ม) ตั้ง superposition เองไม่ได้

IRREVERSIBLE

READ (วัด)

วัดค่า qubit → ได้ 0/1 (โอกาส = magnitude²) คำสั่งเดียวที่สุ่ม ยุบ superposition ทิ้ง

IRREVERSIBLE

slide 58 · qc.read()

NOT (X)

สลับ 0↔1 (สลับพื้นที่ทึบสองวง) ทำกับ superposition ได้ เป็นตัวย้อนของตัวเอง

REVERSIBLE

slide 33 · qc.not()

HAD (H)

สร้าง superposition 50/50 · H|0⟩=(|0⟩+|1⟩)/√2, H|1⟩=(|0⟩−|1⟩)/√2 (มีเครื่องหมายลบ) เป็นตัวย้อนของตัวเอง

REVERSIBLE

slide 34–35 · qc.had()

PHASE(θ) = ROTZ

หมุนเข็มของ วง |1⟩ เท่านั้น (วง |0⟩ ไม่แตะ) · ไม่เปลี่ยนโอกาสวัด · ไม่มีผลกับ |0⟩ เลย (ไม่มีเข็มให้หมุน) · มุมบวก = ทวนเข็ม · เขียนมุมกำกับข้างบนสัญลักษณ์

REVERSIBLE

แต่ไม่ใช่ its own inverse! ย้อนด้วย PHASE(−θ) · ยกเว้น PHASE(180)=Z ที่ย้อนตัวเองได้
slide 64–65 · qc.phase(45)

ROTX(θ)

หมุนลูกศรรอบ แกน X (แกนนอน) · เปลี่ยน magnitude → เปลี่ยนโอกาสวัด · สร้าง superposition จาก |0⟩ ได้เองโดยไม่ต้องใช้ HAD

REVERSIBLE

ย้อนด้วย ROTX(−θ) · slide 67–69 · qc.rotx(90)

ROTY(θ)

หมุนลูกศรรอบ แกน Y (แกนนอนอีกทิศ) · เปลี่ยน magnitude → เปลี่ยนโอกาสวัด · ได้ superposition คนละตัวกับ ROTX (phase ต่างกัน → interference ต่างกัน)

REVERSIBLE

ย้อนด้วย ROTY(−θ) · slide 67–70 · qc.roty(90)

RNOT (√NOT)

ครึ่งหนึ่งของ NOT — ทำสองที = NOT เต็ม (√NOT·√NOT = NOT) · เท่ากับ H → PHASE(90) → H · พา |0⟩ ไปครึ่งทาง (superposition 50/50) · เมทริกซ์มี i: ½[[1+i, 1−i],[1−i, 1+i]]

REVERSIBLE

แต่ไม่ใช่ its own inverse! ย้อนด้วย H → PHASE(−90) → H
slide 92–106 · qc.rootnot()

ตารางที่ออกสอบง่ายที่สุด (slide 68)

ROTX → แกน X → เปลี่ยนโอกาสวัด (เปลี่ยน magnitude)
ROTY → แกน Y → เปลี่ยนโอกาสวัด (เปลี่ยน magnitude)
PHASE → แกน Z (แกนตั้ง) → ไม่เปลี่ยนโอกาสวัด (เปลี่ยน phase อย่างเดียว)

เหตุผลจำง่าย: แกน Z คือแกนตั้งจาก |0⟩ ลงไป |1⟩ หมุนรอบมันแล้วลูกศรอยู่ ละติจูดเดิม = สูงเท่าเดิม = โอกาสเท่าเดิม

4 สถานะที่มีชื่อ (สร้างจาก HAD + PHASE)

ทั้ง 4 ตัว วัดแล้วได้ 50/50 เหมือนกันหมด ต่างกันแค่ทิศเข็มของวง |1⟩ เท่านั้น (มุมบวก = ทวนเข็ม) — slide 65–66

สถานะ เข็มวง |1⟩ สร้างยังไง
|+⟩ ขึ้น (0°) HAD
|−⟩ ลง (180°) HAD → PHASE(180)
|+Y⟩ ซ้าย (90°) HAD → PHASE(90)
|−Y⟩ ขวา (−90°) HAD → PHASE(−90)

ตัวอย่างอ่านวงจรจริง

อ่านว่า: WRITE ตั้งเป็น |0⟩ → NOT พลิกเป็น |1⟩ → READ วัดได้ 1 แน่นอน

QRNG (slide 58) — วงจรที่ต้องวาดได้แบบหลับตา: WRITE |0⟩ → [H] superposition 50/50 → READ ได้ 0/1 สุ่มแท้
qc.reset(1); qc.write(0); qc.had(); var result = qc.read();

เอกลักษณ์ประกอบ gate (บท 8)

เอา gate ที่มีมาต่อกันสร้างตัวอื่นได้ — H เป็นตัว "สลับ X ↔ Z"

ท่องคู่นี้ไว้

X = HZH → สร้าง NOT จาก HAD + PHASE(180) (slide 75–85)
Z = HXH → สร้าง PHASE(180) จาก HAD + NOT (slide 86–90)
RNOT = H·PHASE(90)·H → เหมือน X=HZH แต่ครึ่งมุม (180→90)

ตัวอย่างวงจรหลาย qubit: Quantum Spy Hunter (บท 9)

3 เส้น (alice/สาย/bob) qubit วิ่งจาก alice ลงสาย (สปายสีแดงดักตรงนี้) แล้วขึ้นไป bob
กติกาจับสปาย: if (send_had==recv_had) if (send_val!=recv_val) → "Caught a spy!" (slide 120)

การตั้งชื่อเส้นในวงจรหลาย qubit (บท 0008 · Lec 03 slide 17–20)

ไม่ใช่สัญลักษณ์ gate แต่ออกสอบแน่ — วางเส้นผิดคือตอบผิดทั้งข้อ

กติกา

ตั้งชื่อ qubit ตาม น้ำหนักบิต ไม่ใช่ลำดับที่วาด · เขียนเป็นเลขฐานสิบหก:
เส้นบนสุด = 0x1 (LSB) → 0x2 → 0x4 → 0x8 → 0x10 → 0x20 → 0x40 → 0x80 (MSB, ล่างสุด)
ครบ 8 เส้น = qubyte (ในสไลด์วาดปีกกาครอบทั้ง 8 เส้นแล้วเขียนว่า "one qubyte")
0x1 = 0001 · 0x2 = 0010 · 0xF = 1111

operator pairs — ใช้อ่านผลของ gate เดี่ยวในวงจรหลายเส้น

ยิง gate ใส่เส้นไหน → จับคู่วงที่ค่าต่างกันเท่าน้ำหนักบิตของเส้นนั้น
ยิง 0x1 → (0,1)(2,3)(4,5)(6,7) · ยิง 0x2 → (0,2)(1,3)(4,6)(5,7) · ยิง 0x4 → (0,4)(1,5)(2,6)(3,7)
NOT (⊕) = สลับสองวงในทุกคู่ · PHASE (วงกลมมี φ) = หมุนเฉพาะวงขวาของทุกคู่ · READ (ครึ่งวงกลม) = บวก magnitude² แยกฝั่งซ้าย/ขวา แล้วลบวงที่ขัดผล + renormalize

CNOT (บท 0009 · Lec 03 slide 40–42, 61)

gate ตัวแรกที่ "ข้าม qubit" ได้ — สัญลักษณ์นี้ออกสอบแน่

CNOT
● = control (จุดทึบ) · ⊕ = target · ต้องมีเส้นตั้งเชื่อม
สลับข้างกัน = ความหมายเปลี่ยนคนละเรื่อง

REVERSIBLE (inverse ของตัวเอง)

วงจร Bell pair (slide 45, 61)
HAD ที่ a → CNOT (control a, target b) → READ ทั้งคู่
ผล: |0⟩ 50% · |3⟩ 50% อ่านแล้วตรงกันเสมอ

CNOT ในภาษา operator pairs

คู่มาจาก target · เงื่อนไขมาจาก control
① จับคู่วงตามน้ำหนักบิตของ target → ② เอาเฉพาะคู่ที่บิตของ control เป็น 1 → ③ สลับคู่นั้น
ตัวอย่าง 3 qubit · target 0x1 + control 0x2 → สลับ (2,3) และ (6,7) เท่านั้น (slide 42)
→ NOT กระทบครึ่งหนึ่ง แต่ CNOT กระทบ 1 ใน 4 · CNOT เป็น inverse ของตัวเอง
โค้ด QCEngine: b.cnot(a) = target b, control a — ตัวหน้าจุดคือ target

CPHASE · CZ (บท 0010 · Lec 03 slide 63–72)

conditional gate ที่ ไม่ขยับวง แต่หมุนเข็ม — สังเกตว่าสัญลักษณ์ สมมาตร ทั้งคู่

CPHASE(θ)
φ ทั้งสองเส้น · มุมกำกับด้านบน · เชื่อมด้วยเส้นตั้ง
หมุน phase เฉพาะ |11⟩ — ไม่มี control/target (สมมาตร)

REVERSIBLE (ย้อนด้วย −θ)

CZ = CPHASE(180°)
จุดทึบ ● ทั้งสองข้าง (ไม่ใช่ ⊕!) · พลิกเครื่องหมาย |11⟩
matrix = diag(1, 1, 1, −1)

REVERSIBLE (inverse ของตัวเอง)

CZ สร้างจาก H + CNOT (slide 72)
CZ(q₀,q₁) = H(q₁) → CNOT(q₀,q₁) → H(q₁)
H คร่อมเส้นเดียว (เส้น target) — คู่ขนานกับ Z = H→X→H

วงจร phase kickback (slide 73)
reg1 (2 qubit) HAD ทั้งคู่ · reg2 เขียน |1⟩ · CPHASE ลงมาที่ reg2
ผล: reg1 ได้ phase 0° / 45° / 90° / 135° · reg2 ไม่ขยับ · ไม่ entangle

กฎตัวกรอง (slide 67–68) — ออกสอบง่ายมาก

k control → กระทบ 1 / 2k+1 ของทุกวง
PHASE เดี่ยว (k=0) → ครึ่งหนึ่ง · CPHASE (k=1) → 1/4 · CCPHASE (k=2) → 1/8
วิธีหาว่าวงไหนโดน: เขียนเลขฐานสองของทุกวง → เอาเฉพาะวงที่ บิตของ qubit ที่เกี่ยวข้องเป็น 1 ครบทุกตัว

CCNOT · SWAP · CSWAP (บท 0011 · Lec 03 slide 85–91)

เพิ่มเงื่อนไขให้ NOT (CCNOT) แล้วเอาไปทำ SWAP แบบมีเงื่อนไข (CSWAP)

CCNOT (Toffoli)
●● สอง control + ⊕ target · “ถ้า A และ B ค่อยพลิก C”
2 control → กระทบ 1 คู่วง (universal สำหรับ logic)

REVERSIBLE (inverse ของตัวเอง)

SWAP
×—× เชื่อมด้วยเส้นตั้ง · สลับสอง qubit
= CNOT:a,b → CNOT:b,a → CNOT:a,b (3 CNOT)

REVERSIBLE (inverse ของตัวเอง)

CSWAP (conditional exchange)
● control + ×—× · สลับก็ต่อเมื่อ control = |1⟩
= 3 CCNOT · control superposition → “สลับ+ไม่สลับ” พร้อมกัน

REVERSIBLE (inverse ของตัวเอง)

วงจร SWAP test (บท 0011 · Lec 03 slide 93–97)

เทียบว่าสองสถานะเหมือนกันแค่ไหน โดยไม่ต้องอ่านทำลาย

การอ่านผล — เรื่องออกสอบ

เวอร์ชัน 5 สเต็ป (ไม่มี NOT): ancilla = 0 → เหมือน · 1 → ต่าง · P(0) = (1 + |⟨a|b⟩|²)/2
ต่างสุดขั้ว (|0⟩ vs |1⟩) → 50/50 · เจอผล “ต่าง” ครั้งเดียว = ฟันธงว่าไม่เหมือนเป๊ะ

⚠️ สไลด์เขียนการอ่านผลไว้สองแบบ

หน้า 94 บอก 0 = เหมือน (วงจร 5 สเต็ป) แต่โค้ดหน้า 97 เติม output.not() ปิดท้าย → กลายเป็น 1 = เหมือน
ทั้งคู่ถูกในบริบทตัวเอง — ตอนสอบดูว่าโจทย์มี output.not() ไหม แล้วค่อยตอบ (มี NOT → 1 = เหมือน · ไม่มี → 0 = เหมือน)

จุดที่ข้อสอบชอบสลับ
