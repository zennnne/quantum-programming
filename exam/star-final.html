① วน Amplitude Amplification กี่รอบ
NAA = ⌊ (π/4) · √(2ⁿ / m) ⌋

n = จำนวน qubit · m = จำนวนค่าที่ mark (จำนวนคำตอบ) · ⌊ ⌋ = ปัดลง · π/4 ≈ 0.785

โจทย์แทนสูตรได้
n = 4, m = 10.785 × √16 = 3.14 3 รอบ (96.1%)
n = 4, m = 20.785 × √8 = 2.22 2 รอบ
n = 3, m = 10.785 × √8 = 2.22 2 รอบ
n = 2, m = 10.785 × √4 = 1.57 1 รอบ (100% พอดี)

จำง่าย: m อยู่ใต้รูท · mark มากขึ้น → ใช้รอบน้อยลง · รอบโตตาม √N ไม่ใช่ N · วนเกินกว่านี้ความน่าจะเป็นจะลดลง (เลยยอดคลื่นลูกแรกไปแล้ว)

② Square wave → QFT: สัญญาณจริงเป็นกระจก · จำแบบหั่นครึ่ง

สัญญาณจริงเป็นกระจก — PHASE 180° = แค่ติดเครื่องหมายลบ (บวก/ลบ ไม่มีเฟสอื่น) = สัญญาณจริง → หลัง QFT peak มาเป็นคู่กระจก k กับ 16 − k เสมอ (4 ↔ 12 · 2 ↔ 14 · 6 ↔ 10)

③ RAM vs QRAM: จำ 2 ประโยค

RAM กับ QRAM ต่างกันข้อเดียว คือ address ของ QRAM เป็น superposition ได้ ผลที่ได้ (output) เลยเป็น superposition ตามไปด้วย

QRAM ใช้อ่านค่าธรรมดาเท่านั้น เขียน superposition กลับลงไปไม่ได้

อธิบายแบบง่ายๆ: ตู้ล็อกเกอร์ 🔐

RAM ธรรมดา เหมือนตู้ล็อกเกอร์ที่ยื่นเลขตู้ได้ทีละ 1 เบอร์ แล้วได้ของคืนมา 1 ชิ้น → ยื่นเบอร์ 2 ก็ได้ของในตู้ 2

QRAM ก็เป็นตู้ล็อกเกอร์เหมือนกันเป๊ะ ต่างกันแค่ยื่นเลขตู้เป็น superposition ได้ → ยื่นเบอร์ “2 และ 3 พร้อมกัน” ก็ได้ของในตู้ 2 และตู้ 3 กลับมาพร้อมกัน

ตัวอย่างในสไลด์ (Example 9-2) ที่มี array a = [4, 3, 5, 1]

  1. ตั้ง addr = 2 แล้วใส่ H → addr กลายเป็น ∣2⟩ + ∣3⟩
  2. qram_load ดึงค่า a[2] = 5 กับ a[3] = 1 → qreg เป็น ∣5⟩ + ∣1⟩
  3. add(1) บวกทีเดียวได้ทั้งสองค่า → qreg = ∣6⟩ + ∣2⟩ (อย่างละ 50%)

RAM ธรรมดาทำแบบนี้ไม่ได้ เพราะ CPU เลือก address ได้ทีละอัน

⚠️ ระวัง XNOR ก็ใช้ kickback เหมือนกัน · XNOR = NOT XOR = ได้ 1 เมื่อ a กับ b เหมือนกัน (00, 11) · วงจร = phase XOR แล้วเติม X บน scratch หลัง CNOT 2 ตัว · XOR พลิก ∣1⟩ ∣2⟩ ส่วน XNOR พลิก ∣0⟩ ∣3⟩

ประโยคยาวๆ: คำนวณแบบปกติ (magnitude logic ลง scratch) ก่อน → ใช้ phase logic แค่ตัวสุดท้าย (ตัวนอกสุด) → จากนั้น uncompute

(a OR NOT b) AND c · a = 0x1, b = 0x2, c = 0x4, scratch = 0x8

⑤ แก้ SAT ด้วยสูตร 9 ขั้น

เขียนโจทย์ให้เป็นก้อนๆ ต่อกันด้วย AND → (clause 1) AND (clause 2) AND (clause 3) … (clause = ก้อนย่อยที่ต้องจริงพร้อมกันทุกก้อน) แล้วทำทีละช่วง

  1. เตรียม: HAD ทุกสาย input · ให้ scratch 1 ตัวต่อ 1 clause (เริ่มที่ ∣0⟩)
  2. คำนวณแต่ละ clause แบบปกติ (magnitude logic) เก็บผลลง scratch ของก้อนนั้น
  3. pAND scratch ทุกตัว = phase logic ตัวสุดท้าย → นี่คือการ flip
  4. uncompute ทุก clause คืน scratch เป็น ∣0⟩ (ต้องทำก่อน mirror)
  5. mirror บน input เท่านั้น
  6. วนข้อ 2–5 ทั้งหมด NAA รอบ แล้ว READ input

ถ้าไม่มีค่าไหนทำให้จริง → pAND ไม่พลิกใครเลย → mirror ไม่มีอะไรให้ขยาย → READ ได้ค่าสุ่ม → เอาไปแทนในสูตรแล้วได้ 0 → สรุปว่าสูตรนี้น่าจะ unsatisfiable (ไม่มีทางเป็นจริง)
