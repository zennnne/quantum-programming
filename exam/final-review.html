Amplitude Amplification

ประโยคแกนของคาบนี้

amplitude amplification (AA) แปลง ความต่างของ phase (READ มองไม่เห็น) ให้เป็น ความต่างของ magnitude (READ เห็น) · เป็น quantum primitive ตัวแรกของคอร์ส (ชื่อที่ตรงกว่าคือ “magnitude amplification” แต่วงการเรียก amplitude จนติดแล้ว)

โจทย์ตั้งต้น: phase ต่าง แต่ READ ไม่เห็นอะไรเลย

register 4 qubit = 16 ค่า ทุกวงขนาดเท่ากัน (6.25%) · มีค่าเดียวที่ถูก mark ด้วย phase 180° (ตัวอย่างหลักของสไลด์ mark ค่า 3) → READ ตอนนี้ได้ 3 แค่ 1/16 เท่ากับค่าอื่น · ข้อมูลอยู่ใน phase ล้วนๆ

สไลด์ p4–5 (สถานะ B) · ขนาดเท่ากันหมด มีแต่เข็มของ ∣3⟩ ที่ชี้ลง

AA 1 รอบ = flip + mirror

  • flip = พลิก phase ของค่าที่ mark · ทำโดย NOT บิตที่เป็น 0 ของค่านั้น (3 = 0011 → NOT สาย 0x4, 0x8) ให้มันกลายเป็น 1111 → CZ คร่อมทุกสาย (ติดเฉพาะ 1111) → NOT กลับ · เปลี่ยนตามโจทย์
  • mirror = H → NOT → CZ ทุกสาย → NOT → H · หน้าตาเหมือนเดิมทุกโจทย์ (ไม่ต้องจำว่าข้างในทำงานยังไง จำแค่ผลของมัน = “สะท้อนรอบค่าเฉลี่ย” ข้างล่าง)
  • หลัง 1 รอบ: ∣3⟩ 6.25% → 47.3% · ค่าอื่นเหลือวงละ 3.5% · และ phase ของ ∣3⟩ กลับมาเท่าค่าอื่นแล้ว (ความต่างของ phase ถูก “ใช้” ไปเป็นความต่างของ magnitude)
⚠️ ชื่อเรียก — ตอบตามสไลด์

สไลด์ p10 เขียนว่า mirror = “Grover iteration” → ตอนสอบตอบตามนี้ · แต่ตำราทั่วไปเรียก flip + mirror ทั้งชุดว่า Grover iteration และเรียก mirror เดี่ยวๆ ว่า diffusion operator · ส่วนสไลด์ p12 เรียก flip + mirror ว่า “AA iteration” (วาดเป็นกรอบป้าย AA)

🔴 ทำไม flip + mirror ถึงขยายได้ — สะท้อนรอบค่าเฉลี่ย

ลืมวงกลมไปก่อน ให้มองแต่ละค่าเป็น จุดบนเส้นจำนวน (phase 0° = บวก · phase 180° = ลบ) แล้ว mirror ทำแค่อย่างเดียว:

ค่าใหม่ = 2 × ค่าเฉลี่ย − ค่าเดิม

คือ “กระโดดข้ามค่าเฉลี่ยไปอีกฝั่ง ระยะเท่าเดิม” — ใครอยู่ไกลค่าเฉลี่ย ก็ถูกเหวี่ยงไปไกล · ไล่ตัวเลขรอบแรก:

① ก่อน flip: 16 ค่า = +0.25 ทุกตัว (0.25² = 6.25%)
② flip: ∣3⟩ กลายเป็น −0.25 · อีก 15 ตัวยัง +0.25
③ ค่าเฉลี่ย = (15×0.25 − 0.25)/16 = 0.21875 — พวกมาก 15 ตัวลากค่าเฉลี่ยเข้าหาตัวเอง
④ 15 ตัว: 2×0.21875 − 0.25 = 0.1875 (ขยับนิดเดียว เพราะอยู่ใกล้ค่าเฉลี่ยอยู่แล้ว)
⑤ ∣3⟩: 2×0.21875 − (−0.25) = 0.6875 → 0.6875² = 47.3% (อยู่ไกลค่าเฉลี่ยสุด = โดนเหวี่ยงไกลสุด)
ภาพจำ: หนังสติ๊ก (slingshot)

flip ทำให้ค่าที่ mark กลายเป็น ตัวแปลกแยก อยู่คนละฝั่งกับพวกมาก → mirror เหวี่ยงมันข้ามค่าเฉลี่ยไปไกล ส่วนพวกมากขยับนิดเดียว · flip รอบใหม่ทำให้มันกลับไปเป็นตัวแปลกแยกอีก → เหวี่ยงอีก → โตขึ้นเรื่อยๆ

AA เอาไปใช้ทำอะไร

  • “ต้องรู้คำตอบก่อนถึงจะ flip ได้?” — flip เป็นแค่ตัวอย่างง่ายสุด · งานจริงแทนด้วย phase logic (วงจรที่พลิก phase ของทุกค่าที่ “ผ่านเงื่อนไข” เอง) → ต่อยอดใน Lec10

Phase Estimation

แกนเดียวกับ teleport: คำตอบซ่อนอยู่ใน phase

ที่ teleport ครึ่งหลังยาก (ทวน Lec04) เพราะข้อมูลที่ต้องการไปอยู่ใน phase ซึ่ง READ มองไม่เห็น · Lec08 คือปัญหาแบบเดียวกันแต่หนักกว่า: คำตอบ (eigenphase) เป็น global phase ซึ่งไม่มีทางอ่านได้เลย · ทางออกมี 3 ขั้น จำเป็นประโยคเดียว:

ย้าย phase ไป register อื่น (kickback) → ทำให้มันเป็น “ความถี่” → invQFT แปลงความถี่เป็นตัวเลข → READ

eigenstate และ eigenphase — สิ่งที่ phase estimation หา

  • eigenstate (สถานะเฉพาะ) ของ operation U = state ที่ U ไม่เปลี่ยน ยกเว้นเติม global phase ให้ทั้ง state
  • eigenphase = มุม θ ของ global phase ก้อนนั้น (U∣u⟩ = eiθ∣u⟩)
  • เซตของ eigenstate + eigenphase เป็นเหมือนลายนิ้วมือ ของ operation — ไม่มี operation อื่นที่มีเซตเดียวกัน

  • H ทุกสายของ output → ทุก k อยู่ใน superposition เท่ากัน
  • บิตที่ j ของ output คุม U2ʲ บน eigenstate · U กับ eigenstate ให้แค่ phase θ แต่พอมี control phase นั้นเด้งกลับ (kickback) ไปติดที่ control qubit แทน → eigenstate ข้างล่างไม่เปลี่ยน
  • state ∣k⟩ โดน U รวม k ครั้งพอดี → หมุน kθ · เช่น k = 6 = 110₂ → บิต 1 กับ 2 ติด → U² · U⁴ = U⁶ → 6θ

ขั้น 3: invQFT ที่ output → READ ได้ R = θ/360 × 2m

⚠️ ป้ายกล่องสุดท้ายในสไลด์

สไลด์ p32/p44 เขียนกล่องสุดท้ายว่า U2ⁿ โดย n = จำนวน qubit ของ eigenstate → ตอบตามสไลด์ · แต่ของจริงเลขชี้กำลังผูกกับ output m qubit: กล่องแรก U = U2⁰ → กล่องสุดท้าย U2^(m−1) (m = 4 → U⁸ แบบในรูปข้างบน)

  • ทำ U2ʲ แบบซื่อๆ = เรียก cont_u ซ้ำ 2ʲ ครั้ง → รวม 2m − 1 ครั้ง (m = 4 → 15 ครั้ง) โตแบบ exponential · ทางแก้: ส่ง cont_u ที่ยกกำลังได้เร็วในตัว
  • สรุปวัตถุดิบ 3 อย่าง: H (กระจาย k) · controlled-U2ʲ + kickback (ฝัง θ เป็นความถี่) · invQFT (อ่านความถี่)
