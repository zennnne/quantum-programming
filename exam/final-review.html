Amplitude Amplification

ประโยคแกนของคาบนี้

amplitude amplification (AA) แปลง ความต่างของ phase (READ มองไม่เห็น) ให้เป็น ความต่างของ magnitude (READ เห็น) · เป็น quantum primitive ตัวแรกของคอร์ส (ชื่อที่ตรงกว่าคือ “magnitude amplification” แต่วงการเรียก amplitude จนติดแล้ว)

โจทย์ตั้งต้น: phase ต่าง แต่ READ ไม่เห็นอะไรเลย

register 4 qubit = 16 ค่า ทุกวงขนาดเท่ากัน (6.25%) · มีค่าเดียวที่ถูก mark ด้วย phase 180° (ตัวอย่างหลักของสไลด์ mark ค่า 3) → READ ตอนนี้ได้ 3 แค่ 1/16 เท่ากับค่าอื่น · ข้อมูลอยู่ใน phase ล้วนๆ

สไลด์ p4–5 (สถานะ B) · ขนาดเท่ากันหมด มีแต่เข็มของ ∣3⟩ ที่ชี้ลง

AA 1 รอบ = flip + mirror

  • flip = พลิก phase ของค่าที่ mark · ทำโดย NOT บิตที่เป็น 0 ของค่านั้น (3 = 0011 → NOT สาย 0x4, 0x8) ให้มันกลายเป็น 1111 → CZ คร่อมทุกสาย (ติดเฉพาะ 1111) → NOT กลับ · เปลี่ยนตามโจทย์
  • mirror = H → NOT → CZ ทุกสาย → NOT → H · หน้าตาเหมือนเดิมทุกโจทย์ (ไม่ต้องจำว่าข้างในทำงานยังไง จำแค่ผลของมัน = “สะท้อนรอบค่าเฉลี่ย” ข้างล่าง)
  • หลัง 1 รอบ: ∣3⟩ 6.25% → 47.3% · ค่าอื่นเหลือวงละ 3.5% · และ phase ของ ∣3⟩ กลับมาเท่าค่าอื่นแล้ว (ความต่างของ phase ถูก “ใช้” ไปเป็นความต่างของ magnitude)
⚠️ ชื่อเรียก — ตอบตามสไลด์

สไลด์ p10 เขียนว่า mirror = “Grover iteration” → ตอนสอบตอบตามนี้ · แต่ตำราทั่วไปเรียก flip + mirror ทั้งชุดว่า Grover iteration และเรียก mirror เดี่ยวๆ ว่า diffusion operator · ส่วนสไลด์ p12 เรียก flip + mirror ว่า “AA iteration” (วาดเป็นกรอบป้าย AA)

🔴 ทำไม flip + mirror ถึงขยายได้ — สะท้อนรอบค่าเฉลี่ย

ลืมวงกลมไปก่อน ให้มองแต่ละค่าเป็น จุดบนเส้นจำนวน (phase 0° = บวก · phase 180° = ลบ) แล้ว mirror ทำแค่อย่างเดียว:

ค่าใหม่ = 2 × ค่าเฉลี่ย − ค่าเดิม

คือ “กระโดดข้ามค่าเฉลี่ยไปอีกฝั่ง ระยะเท่าเดิม” — ใครอยู่ไกลค่าเฉลี่ย ก็ถูกเหวี่ยงไปไกล · ไล่ตัวเลขรอบแรก:

① ก่อน flip: 16 ค่า = +0.25 ทุกตัว (0.25² = 6.25%)
② flip: ∣3⟩ กลายเป็น −0.25 · อีก 15 ตัวยัง +0.25
③ ค่าเฉลี่ย = (15×0.25 − 0.25)/16 = 0.21875 — พวกมาก 15 ตัวลากค่าเฉลี่ยเข้าหาตัวเอง
④ 15 ตัว: 2×0.21875 − 0.25 = 0.1875 (ขยับนิดเดียว เพราะอยู่ใกล้ค่าเฉลี่ยอยู่แล้ว)
⑤ ∣3⟩: 2×0.21875 − (−0.25) = 0.6875 → 0.6875² = 47.3% (อยู่ไกลค่าเฉลี่ยสุด = โดนเหวี่ยงไกลสุด)

AA เอาไปใช้ทำอะไร

  • “ต้องรู้คำตอบก่อนถึงจะ flip ได้?” — flip เป็นแค่ตัวอย่างง่ายสุด · งานจริงแทนด้วย phase logic (วงจรที่พลิก phase ของทุกค่าที่ “ผ่านเงื่อนไข” เอง) → ต่อยอดใน Lec10

  • เร่งอัลกอริทึมคลาสสิกที่ต้อง “ตรวจคำตอบซ้ำๆ” ได้แบบ quadratic (เช่น boolean satisfiability, หา global/local minima) · ส่วน flip = ที่ใส่ตัวตรวจคำตอบ (เปลี่ยนตามโจทย์) · ส่วน mirror = เหมือนเดิมทุกงาน

แกนเดียวกับ teleport: คำตอบซ่อนอยู่ใน phase

ที่ teleport ครึ่งหลังยาก (ทวน Lec04) เพราะข้อมูลที่ต้องการไปอยู่ใน phase ซึ่ง READ มองไม่เห็น · Lec08 คือปัญหาแบบเดียวกันแต่หนักกว่า: คำตอบ (eigenphase) เป็น global phase ซึ่งไม่มีทางอ่านได้เลย · ทางออกมี 3 ขั้น จำเป็นประโยคเดียว:

eigenstate และ eigenphase — สิ่งที่ phase estimation หา

3. Vector: state encoding vs amplitude encoding

vector ยาว N เช่น v⃗ = [0, 1, 2, 3] (เจอบ่อยใน quantum machine learning) เก็บใน QPU ได้ 2 แบบ:

ประเด็นstate encodingamplitude encoding
เก็บยังไง component ละ 1 register เก็บค่าเป็นเลขฐานสองใน basis state เดียว (วงเต็มวงเดียว ไม่มี superposition) ทุก component อยู่ใน amplitude ของ superposition ใน register เดียว — component ที่ i = amplitude ของ ∣i⟩
ใช้กี่ qubit (vector ยาว N) N × (จำนวนบิตต่อ component) ⌈log₂ N⌉ — register k qubit มี 2k amplitude · N ไม่เป็นกำลังของ 2 ก็เติม 0 ให้ครบ
ต้องมี QRAM ไหม ไม่ต้อง — เก็บใน RAM ธรรมดาแล้วเตรียมทีละ register ต้องพึ่ง QRAM (ไม่มีก็ทำได้แต่ไม่ efficient)
อ่านค่าออกได้ไหม ได้ — แต่ละ register เป็น basis state ธรรมดา ไม่ได้ทีละ component (Caveat 1) — READ ได้ผลเดียวแบบสุ่มแล้ว state ยุบ · ได้แค่ global properties (คุณสมบัติภาพรวม)

4. Matrix encoding / quantum simulation

วิธีตรงๆ: matrix m × n → m register ยาว log₂(n) qubit แล้ว amplitude-encode ทีละ row — ใส่ข้อมูลเข้าได้ แต่ไม่ได้แทน “ในฐานะ matrix” (ไม่ชัดว่าจะ transpose หรือคูณกับ vector ยังไง) → เข้ารหัส matrix เป็น QPU operation ที่กระทำกับ register ที่เก็บ vector แทน

  • แทนได้ถูก = M·v ↔ U∣v⟩ ได้ผลตรงกันทุก v · เกณฑ์ที่ง่ายกว่า: eigen decomposition เดียวกัน — eigenstates ของ U = amplitude encoding ของ eigenvectors ของ M · eigenphases “สัมพันธ์กับ” eigenvalues (สไลด์ไม่ได้บอกว่าเท่ากัน)
  • แค่นั้น “เกือบพอ” — ต้องมี prescription (วิธีสร้างจาก gate พื้นฐาน) และต้อง efficient ด้วย = good matrix representation

Quantum simulation = คำเรียกรวมของวิธีหา QPU operation ที่ efficient เพื่อแทน Hermitian matrix (H = H† · † = transpose แล้ว complex conjugate) — ทุกเทคนิคอย่างน้อยต้องการ H ที่เป็น Hermitian เพราะ QPU operation ต้องเป็น unitary และ

U = exp(−iHt) เป็น unitary เสมอเมื่อ H เป็น Hermitian

t = เวลาที่ทำ operation (ถือเป็นรายละเอียด hardware) · ชื่อ “simulation” มาจากฟิสิกส์ — H ที่อธิบายระบบเรียกว่า Hamiltonian · matrix X ที่ไม่ Hermitian → ห่อเป็น block matrix ที่ใหญ่ขึ้น:

H = [ 0   X ; X†   0 ]

(บนซ้าย 0 · บนขวา X · ล่างซ้าย X† · ล่างขวา 0 → H† = H จึงเป็น Hermitian · overhead ทำครั้งเดียว มักไม่มีนัยสำคัญ)

3 ขั้น (เกือบทุกวิธี): ① Deconstruct — แตก H = H₁ + … + Hₙ ให้แต่ละชิ้น simulate ง่าย (เช่นมีแต่ diagonal หรือกระทำกับ qubit ไม่กี่ตัว) → ② Simulate components — หาวงจรของ Hᵢ แต่ละตัว → ③ Reconstruction — ประกอบกลับด้วย Lie product formula: ทำ U₁ = exp(−iH₁δt), …, Uₙ = exp(−iHₙδt) ต่อกันทีละช่วงสั้น δt แล้ววนทั้งชุดซ้ำ m รอบ

exp(−iHt) ≈ (U₁ U₂ … Uₙ)m

(สูตรบรรทัดนี้เป็นการสรุปเป็นสัญลักษณ์ — สไลด์พูดเป็นคำ ไม่ได้เขียนสูตรตรงๆ)
