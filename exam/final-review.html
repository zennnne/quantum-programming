1. Phase logic: เก็บคำตอบไว้ใน phase

Lec05 คือ magnitude logic: input เป็นค่าในรีจิสเตอร์ แล้ว output เขียนเป็นค่า 0/1 ลงบิต (มักเป็น scratch) · คาบนี้คือ phase logic: input ยังเป็นค่าในรีจิสเตอร์เหมือนเดิม แต่ output ไปอยู่ใน relative phase · นิยาม: พลิก phase ของทุกค่าที่ทำให้ operation ได้ 1 (ค่าพวกนี้เรียกว่าค่าที่ satisfy operation)

แบบทำอะไร
Conventional binary logicinput 1 ค่า → output 1 ค่า
Quantum magnitude logic (Lec05)superposition ของ input → superposition ของ output
Quantum phase logicพลิก phase ของทุก input ที่ให้ output = 1 · ใช้ได้ทั้งตอนรีจิสเตอร์เป็น superposition และเป็นค่าเดียว
  • ถ้าป้อนค่าเดียว (ไม่ใช่ superposition) การพลิก phase เป็นแค่ global phase ใช้ประโยชน์ไม่ได้ · ถ้าเป็น superposition จะกลายเป็น relative phase ที่ AA ดึงออกมาได้
  • ผลอยู่ใน phase จึง READ ตรงๆ ไม่ได้ · แต่ข้อดีคือ mark คำตอบได้หลายตัวพร้อมกันในรีจิสเตอร์เดียว แล้วใช้เป็น flip ของ AA

3. ลูกแมว/เสือ: รันครั้งเดียวต้องถูก

โจทย์: กล่อง A กับ B แต่ละใบมีลูกแมวหรือเสือ เปิดได้ใบเดียว · ป้ายกล่อง A: "อย่างน้อย 1 กล่องมีลูกแมว" · ป้ายกล่อง B: "อีกกล่อง (A) มีเสือ" · พระราชาเพิ่มว่า "ป้ายทั้งสองใบ จริงทั้งคู่ หรือ เท็จทั้งคู่" และ รันอุปกรณ์ได้ครั้งเดียว

ปริศนา → logic (0 = เสือ, 1 = ลูกแมว): ป้าย A = A OR B · ป้าย B = NOT A · กติกาพระราชา = XNOR → out = (A OR B) XNOR (NOT A)

4. สูตร 9 ขั้นแก้ SAT ด้วย QPU

SAT (boolean satisfiability) = ถามว่า "มี input ไหนทำให้ boolean statement เป็นจริงไหม" · ใช้จริงใน model checking, AI planning, software verification

  1. แปลง statement ให้เป็น AND ของ clause หลายตัวที่ต้องจริงพร้อมกัน
  2. แทนแต่ละ clause ด้วย magnitude logic · ใช้ scratch 1 ตัวต่อ 1 clause
  3. HAD ทุก qubit ของ input ให้เป็น uniform superposition · scratch ทุกตัวตั้งเป็น ∣0⟩
  4. คำนวณ clause ทีละตัวด้วย magnitude logic เก็บผลไว้ใน scratch ของมัน
  5. ทำ phase-logic AND (CZ) ระหว่าง scratch ทุกตัว เพื่อรวม clause ทั้งหมด
  6. uncompute magnitude logic ทั้งหมด คืน scratch กลับเป็นค่าเริ่มต้น
  7. รัน mirror บนรีจิสเตอร์ input
  8. ทำขั้นก่อนหน้าซ้ำตามจำนวนรอบจากสูตร AA (Equation 6-2)
  9. READ รีจิสเตอร์ input

NAA = ⌊ (π/4)·√(2n/m) ⌋  ·  n = จำนวน qubit ของ input · m = จำนวนคำตอบ

จำง่ายๆ เป็น 3 ช่วง: เตรียม (1–3) · 1 รอบ AA = compute → pAND → uncompute → mirror (4–7) · วนแล้วอ่าน (8–9)

7. AA เร่งอะไรได้บ้าง

  • บางกรณีได้ quadratic speedup (เร็วขึ้นแบบกำลังสอง) เทียบกับอัลกอริทึมคลาสสิกที่ดีที่สุด ไม่ใช่แค่เทียบกับ brute force
  • เร่งได้กับอัลกอริทึมที่มี one-sided error (ผิดได้ด้านเดียว): ถ้าคำตอบจริงคือ "no" จะตอบ "no" เสมอ · ถ้าคำตอบจริงคือ "yes" จะตอบ "yes" ด้วยความน่าจะเป็น p > 0 · 3-SAT ตอบ "yes" ก็ต่อเมื่อเจอ assignment ที่ทำให้เป็นจริงจริงๆ (นี่คือเหตุผลที่กรณีไม่มีคำตอบสรุปได้แค่ "น่าจะ")
  • ตัวอย่างอื่นที่ AA เร่งได้: element distinctness (มี i ≠ j ที่ f(i) = f(j) ไหม · ใช้หาสามเหลี่ยมในกราฟ, ผลคูณเมทริกซ์) · finding global minima (หา i ที่ f(i) ต่ำสุด)
