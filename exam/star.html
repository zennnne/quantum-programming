① 45 องศา → 85.4 / 14.6

HAD → PHASE(45°) → HAD แล้วอ่าน ได้ 85.4% ต่อ 14.6%

มาจาก cos²(22.5°) = 0.854 · sin²(22.5°) = 0.146 — ครึ่งของ 45 คือ 22.5

PHASE กี่องศาอ่านได้ 0 / 1จำว่า
0°100 / 0 HAD สองตัวหักล้างกัน กลับเป็น |0⟩
45°85.4 / 14.6 เลขของคาบนี้ · cos²(22.5°)
90° / −90°50 / 50 +90 กับ −90 ให้เลขเท่ากัน — READ แยกไม่ออก ต่างกันแค่ทิศเข็ม
180°0 / 100 |−⟩ · พลิกเป็น |1⟩ เต็มๆ

สูตรเดียวจบ: อ่านได้ 0 = cos²(θ/2) — หารสองก่อนเสมอ · PHASE(−θ) คือตัวย้อนของ PHASE(θ) (ต่อท้ายกันแล้วเข็มกลับที่เดิม)

② HAD ตอนที่ว่างวงนึง + เข็ม 90° → ได้ 90 กับ −90 หันหน้าชนกัน

วงเต็มอยู่วงเดียว (อีกวงว่าง) เข็มชี้ 90° · พอ HAD มันแตกเป็นสองวงครึ่งๆ — ถ้าวงที่เต็มคือ |1⟩ วงที่ออกมาจะได้เข็ม +90 กับ −90 คือชี้สวนทางกัน (หันหน้าชนกัน)

ทำไม: H|1⟩ = (|0⟩ − |1⟩)/√2 — มีเครื่องหมายลบติดที่วง |1⟩ = บวก 180° เข้าไป → 90 กับ 90+180 = −90 · ห่างกัน 180° เลยหันหน้าชนกันเป๊ะ

กรณี −90 ก็กลับด้านกันเป๊ะ — เข็มเริ่มที่ −90 (ชี้ขวา) พอ HAD ได้ −90 กับ +90 คราวนี้วง |0⟩ ชี้ขวา · วง |1⟩ ชี้ซ้าย = ชี้เข้าหากัน · ผลอ่านยัง 50/50 เท่ากับกรณี +90

กฎสั้น: HAD วง |0⟩ → เข็มเหมือนกัน · HAD วง |1⟩ → เข็มสวนกัน 180° เฟสเดิมที่ติดมาไม่หาย มันแค่ถูกก๊อบไปทั้งสองวง

③ ถ้ายังไม่ Hadamard ก็ phase ไม่ได้

PHASE เฉยกับ |0⟩ — หมุนเฉพาะฝั่งที่บิตเป็น 1 ถ้า qubit ยังเป็น |0⟩ ล้วน PHASE จะไม่เกิดอะไรขึ้นเลย ต้อง HAD ให้เข้า superposition ก่อน เฟสถึงจะมีของให้หมุน (และ READ ก็ยังไม่เห็นอยู่ดี ต้อง HAD ปิดท้ายอีกทีให้เฟสกลายเป็นขนาดวง)

⑤ Circle rotation ของ Remote-controlled randomness

← เลื่อนดูได้

อ่านเลขวงแบบนี้: เลขในวง = a + 2b → |0⟩ = (a0,b0) · |1⟩ = (a1,b0) · |2⟩ = (a0,b1) · |3⟩ = (a1,b1)

← เลื่อนดูได้

อ่านผลจากแถวสุดท้าย

a = 0 คือวง |0⟩+|2⟩ = 42.7 + 7.3 = 50% · a = 1 ก็ 50% → ตัวแรกสุ่ม 50/50 เสมอ
พออ่าน a = 0 แล้ว เหลือ |0⟩ : |2⟩ = 42.7 : 7.3 → b ได้ 85.4% / 14.6% (ตรงกับข้อ ①)
อ่าน a = 1 → |1⟩ : |3⟩ = 7.3 : 42.7 → b กลับด้านเป็น 14.6% / 85.4%
